## 摘要
视觉-语言对比预训练已成为3D医学基础模型的主流方法，它利用了临床实践中产生的大量配对扫描和报告。然而，医学图像通常涵盖数十个器官，而放射报告比典型的自然图像描述要长得多，并且由多个结构化部分组成。CLIP风格的预训练通过将每种模态编码为单个全局标记来压缩这种结构，这有可能丢失重要细节。我们提出了ConQuer（概念查询），一种图像-文本预训练方法，它通过一组局部对齐（每个概念一个）来增强CLIP的全局对齐。ConQuer将报告拆分为特定概念的部分，并学习交叉注意力查询，以聚合匹配的图像特征，而不使用任何分割掩码或空间监督。然后对每个概念独立应用对比学习。概念可以是任何语义局部化单元；在这里，它们是解剖区域，每个器官或大体身体区域一个查询。作为副产品，每个查询学习关注其概念的注意力图，提供内置的空间可解释性。我们使用ConQuer训练了Jolia，一个在胸部CT和腹部CT上的3D CT基础模型。在发现分类、报告生成和跨中心迁移方面，Jolia始终优于CLIP基线，并在多个公共基准上达到了新的最先进水平。Jolia的权重将在接收后发布。

## Abstract
Vision-language contrastive pretraining has become the dominant recipe for 3D medical foundation models, leveraging the large volumes of paired scans and reports produced in clinical practice. However, medical images usually span dozens of organs, and radiological reports are much longer than typical natural image captions and are composed of multiple structured sections. CLIP-style pretraining compresses this structure by encoding each modality into a single global token, at the risk of losing important details. We introduce ConQuer (Concept Queries), an image-text pretraining method that augments CLIP's global alignment with a set of localized alignments, one per concept. ConQuer splits the report into concept-specific sections and learns cross-attention queries that pool the matching image features without using any segmentation mask or spatial supervision. Contrastive learning is then applied independently for each concept. Concepts can be any unit of semantic localization; here, they are anatomical regions, one query per organ or gross body region. As a byproduct, each query learns attention maps focused on its concept, providing built-in spatial interpretability. We use ConQuer to train Jolia, a 3D CT foundation model on chest and abdominal CT. Jolia consistently outperforms a CLIP baseline on findings classification, report generation, and cross-center transfer, and sets a new state of the art across multiple public benchmarks. Jolia's weights will be released upon acceptance.

### 1. 论文的核心问题与整体含义（研究动机和背景）
- **核心问题**：标准的 CLIP 式视觉-语言对比学习将整个 3D CT 图像和长篇放射报告各自压缩为一个全局 token，导致多器官、长文本的结构信息丢失，无法捕捉局部的、器官级别的细节。
- **研究背景**：医学 CT 扫描常覆盖几十个器官，放射报告按器官分节描述（如“肺：无结节；肝：2cm 囊肿”）。现有方法要么仍使用全局对齐（CT-CLIP、Merlin 等），要么依赖分割掩码（fVLM、TotalFM、CT-GLIP）进行局部对齐，但分割监督限制了可覆盖的器官数量。
- **整体含义**：通过引入概念级（此处为解剖区域）的局部对齐，无需分割掩码即可保留多器官结构，提升下游任务性能，并自带空间可解释性。

### 2. 论文提出的方法论
- **核心思想**：ConQuer（Concept Queries）在全局 CLIP 损失之外，为每个概念（例如器官）添加独立的对比学习损失。文本侧利用 LLM 将报告拆分为概念对应的章节；图像侧引入一组可学习的跨注意力查询（query），每个查询负责聚合对应概念区域的图像特征。对比损失在同一概念的不同样本间独立计算。
- **关键技术细节**：
    - **图像编码器**：使用 3D Atlas 变压器（22M 参数）、3D ResNet-101（48M）或 3D ViT-B（120M）。输出多尺度 patch token 及全局 [CLS] token。
    - **概念级跨注意力池化**：为每个概念设置一个可学习查询 token，通过跨注意力模块从各尺度的 patch token 中提取该概念的视觉表征。不需要分割掩码，仅靠对比损失驱动查询定位。
    - **文本编码器**：冻结的 Qwen3-Embedding-8B，输出经线性投影至视觉特征维度。
    - **损失函数**：每个概念独立应用对称 InfoNCE，同时保留全局 CLIP 损失。总损失为 L = λ_CLIP L_CLIP_global + λ_ConQuer L_ConQuer（λ_CLIP=1.0，λ_ConQuer=0.5）。对于缺失某概念的样本，使用概念存在掩码屏蔽。
    - **数据预处理**：使用 GPT-5.2 将报告分解为原子观察，并映射到 102 个解剖概念（胸部+腹部）。

### 6. 论文的主要结论与发现
- ConQuer 在全局 CLIP 基础上增加概念级对比损失，显著提升了线性探测、零样本和跨中心迁移的 AUROC，尤其在外部 OOD 数据集上增益更大。
- 基于 ConQuer 训练的 Jolia 在多个公开基准上达到 SOTA，尤其在腹部 CT 的发现分类和报告生成任务中领先。
- 概念级查询无需空间监督即可学习到解剖区域注意力图，提供内置可解释性。
- 方法鲁棒于不同图像编码器架构（Atlas/ResNet/ViT）和不同概念粒度（即使使用无监督聚类分组也有改进）。
- 在报告生成任务上，Jolia 在 RadGraph-F1 和 GREEN 指标上优于 Merlin 等基线，但仍有“偏向正常描述”的不足。

### 7. 优点
- **无需分割标注**：完全依赖跨注意力查询从对比损失中学习定位，避免了分割工具限制，可覆盖更多概念。
- **内置可解释性**：每个概念查询的注意力图可直接显示模型关注的解剖区域。
- **概念灵活**：可适用于任何语义局部化单元（如病变亚型、器官），不限于解剖结构。
- **通用性强**：在多个架构（Atlas、ResNet、ViT）和多种概念分组（自然解剖、K-means）上均有效。
- **零样本评估精心设计**：提出多模板聚合和长报告原型方法，减少 prompt 敏感性，使比较更公平。
- **公开基准全面覆盖**：同时评估 ID 和 OOD 数据集，并进行了跨中心迁移测试，验证了泛化能力。

### 8. 不足与局限
- **胸部 CT 增益较小**：胸部报告通常较短、涉及的器官较少，概念级对齐的收益不如腹部明显。
- **依赖大语言模型**：报告拆分依赖 GPT-5.2，其准确性可能影响下游性能，且文中未充分讨论 LLM 选择的影响。
- **文本编码器冻结**：未对文本编码器（Qwen3-Embedding-8B）进行领域适应，使得放射报告对其仍有分布偏移，可能限制了检索和零样本性能。
- **报告生成偏向正常描述**：与 Merlin 等类似，Jolia 有未充分报告阳性发现的倾向，CRIMSON 得分仍为负值。
- **部分实验缺乏细节**：未披露具体训练时长和能源消耗；少量消融实验未展示种子方差（如检索结果中 Jolia 的 std 未列出，但其他表格有）。
- **检索性能不突出**：尤其在腹部 T→I 方向，Jolia 不如专门优化的 Merlin 或 Pillar-0-Abd，可能是冻结文本编码器的副作用。
- **仅涵盖胸腹 CT**：未扩展至全身 CT 或 MRI，概念方法在更广模态上未验证。
