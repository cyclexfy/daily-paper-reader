## 摘要
多模态大语言模型在视觉理解方面取得了显著成功，但由于语义感知与像素级重建之间的根本特征差异，其在视觉生成方面仍受到限制。弥合这一差距需要克服两个核心挑战：赋予语义编码器高保真重建能力，以及在不依赖外部教师的情况下有效对齐生成模型与语义空间。为此，我们提出了一种新颖的统一多模态框架，具有语义-像素自对齐与自适应路由（SPAR）。首先，为了协调语义感知与像素级重建，我们引入了一种非对称双流统一分词器。一个轻量级语义流锚定判别性特征，而一个Transformer增强的像素流将细粒度视觉细节恢复到统一的紧凑潜在空间中。其次，为了消除外部依赖，我们提出了一种自对齐生成范式，该范式原生利用这个优化后的分词器作为扩散模型的内部对齐教师。此外，为了促进这种统一空间内的灵活多模态交互，我们引入了动态令牌路由，使得每个令牌能够根据其特定的语义需求自适应地聚合多层的MLLM特征。大量实验表明，SPAR建立了统一架构的最先进水平，在保持基础视觉理解能力的同时，实现了卓越的生成和重建质量。

## Abstract
Multimodal Large Language Models (MLLMs) have achieved remarkable success in visual understanding but remain constrained in visual generation due to the fundamental feature discrepancy between semantic perception and pixel-level reconstruction. Bridging this gap requires overcoming two core challenges: endowing semantic encoders with high-fidelity reconstruction capabilities, and effectively aligning generative models with semantic spaces without relying on external teachers. To this end, we propose a novel unified multimodal framework featuring \textbf{S}emantic-\textbf{P}ixel self-alignment and \textbf{A}daptive \textbf{R}outing (\textbf{SPAR}). First, to reconcile semantic perception with pixel-level reconstruction, we introduce an asymmetric dual-stream unified tokenizer. A lightweight semantic stream anchors discriminative features, while a Transformer-augmented pixel stream recovers fine-grained visual details into a unified compact latent space. Second, to eliminate external dependencies, we propose a self-aligned generation paradigm that natively leverages this optimized tokenizer as an internal alignment teacher for the diffusion model. Furthermore, to facilitate flexible multimodal interaction within this unified space, we introduce Dynamic Token Routing, which enables each token to adaptively aggregate multi-layer MLLM features based on its distinct semantic demands. Extensive experiments demonstrate that SPAR establishes the state-of-the-art for unified architectures, achieving exceptional generation and reconstruction quality while preserving foundational visual understanding capabilities.

## 2. 论文提出的方法论
### 2.1 核心思想
- 提出 **SPAR** 框架，包含三个核心组件：
  1. **非对称双流统一分词器**：解耦语义保持与像素重建。
  2. **自对齐生成范式**：利用分词器自身作为扩散模型的内部对齐教师，消除外部依赖。
  3. **动态令牌路由（DTR）**：使每个令牌根据语义角色自适应聚合 MLLM 多层特征。

### 2.2 关键技术细节
#### 2.2.1 语义-像素自对齐统一分词器
- **结构**：输入图像经冻结的语义编码器 \(E_s\) 得到特征 \(f_v\)。  
  - **语义流（轻量级）**：通过残差块 + MLP 映射到紧凑潜在空间 \(z_s = P_s(f_v)\)，保持判别结构。  
  - **像素流（Transformer 增强）**：使用 6 层 Transformer \(T_p\) 建模长程依赖，再经映射得到 \(z_p = P_p(T_p(f_v))\)，旨在恢复高频细节。  
  - **融合与解码**：\(z_s\) 和 \(z_p\) 通道拼接后经融合层 \(F\) 得到 \(z_f\)，输入像素解码器 \(D_p\) 重建图像。

- **渐进式三阶段训练**（关键公式）：
  - **Stage I**：冻结编码器和解码器，训练双流模块。损失：\(\mathcal{L}_I = \mathcal{L}_{MSE} + \mathcal{L}_{LPIPS} + \lambda_p \mathcal{L}_p\)，其中 \(\mathcal{L}_p = \|z_p - z'_p\|_2^2\)（\(z'_p\) 为冻结像素编码器输出）引导像素流对齐像素潜在空间。
  - **Stage II**：冻结编码器，联合训练解码器，损失 \(\mathcal{L}_{II} = \mathcal{L}_{MSE} + \mathcal{L}_{LPIPS}\)。
  - **Stage III**：微调解码器，引入语义对齐损失 \(\mathcal{L}_s = \|f_v - f'_v\|_2^2\)（\(f'_v\) 为冻结编码器输出）防止遗忘，并加入 GAN 损失。损失：\(\mathcal{L}_{III} = \mathcal{L}_{MSE} + \mathcal{L}_{LPIPS} + \lambda_s \mathcal{L}_s + \lambda_{GAN}\mathcal{L}_{GAN}\)，编码器学习率降至全局的 0.1 倍。

#### 2.2.2 动态令牌路由 (DTR)
- 从 MLLM 的 \(L\) 层中均匀采样 \(K=4\) 层，收集隐藏状态 \(\mathbf{H} \in \mathbb{R}^{B\times N\times K\times D}\)。
- 以最深层特征 \(\mathbf{H}^{(K)}\) 作为查询，通过轻量路由网络 \(g(\cdot)\) 计算每层权重：\(w_i = \text{softmax}(g(\mathbf{H}_i^{(K)})/\tau)\)。
- 融合：\(\hat{\mathbf{H}}_i = W_p \sum_{k=1}^K w_i^{(k)} \cdot \alpha^{(k)} \cdot \mathbf{H}_i^{(k)}\)，其中 \(\alpha^{(k)}\) 为可学习缩放参数。
- 可视化可揭示不同令牌对层级的偏好（如边缘、纹理、文本指令）。

#### 2.2.3 自对齐生成范式
- 扩散模型（DiT）在训练时，将其中间层特征 \(f_{\text{dit}}\) 通过对齐投影头 \(\phi_a\) 与分词器编码器特征 \(f'_v\) 进行余弦相似度对齐：\(\mathcal{L}_{\text{align}} = -\frac{1}{N}\sum_i \cos(\phi_a(f_{\text{dit},i}), f'_{v,i})\)。
- 将分词器作为“内部教师”，避免使用外部特征网络（如 DINOv2）。

#### 2.2.4 统一模型训练流程
- 三阶段：
  - **Stage I**（连接器预训练）：冻结 MLLM 和 DiT，仅训练连接器、投影层、查询嵌入、DTR路由网络，使用流匹配损失 \(\mathcal{L}_{fm}\)。
  - **Stage II**（联合预训练）：冻结 MLLM，联合训练连接器和 DiT，损失 \(\mathcal{L}_{fm} + \lambda_a \mathcal{L}_{\text{align}}\)，使用生成和编辑数据。
  - **Stage III**（监督微调）：高质量指令数据，损失同上。
