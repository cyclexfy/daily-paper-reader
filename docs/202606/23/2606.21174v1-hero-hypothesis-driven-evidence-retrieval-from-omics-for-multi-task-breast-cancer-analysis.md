## 摘要
匹配的多组学数据可以改善基于WSI的生物标志物和预后预测，但大多数现有流程将组学作为并行特征流或文本上下文而非显式的检索约束。HERO探究观察到的组学是否可作为一种可检验的形态学假设：一个稀疏的路径到形态学先验将DNA甲基化和miRNA映射为K维意图向量m（K=16），对结构化10个标题进行TF-IDF检索选择终点相关区域，余弦门控c=cos(m,v)在c<τc时触发确定性缺陷驱动的修复。这种闭环设计限制了VLM调用，减少了对基于嵌入的语义匹配的依赖，并使每个检索和验证步骤在词汇上可审计。在TCGA-BRCA（930张WSI，患者级5折交叉验证）上，HERO在ER、PR、HER2、亚型和风险预测方面均创下新纪录，优于多模态融合和基于VLM的基线方法。

## Abstract
Matched multi-omics can improve WSI-based biomarker and prognosis prediction, but most existing pipelines use omics as a paral lel feature stream or textual context rather than as an explicit retrieval constraint. HERO asks whether observed omics can be a testable mor phology hypothesis: a sparse pathway-to-morphology prior maps DNA methylation and miRNA into a K-dimensional intent vector m (K=16), TF-IDF retrieval over structured 10 captions selects endpoint-relevant regions, and a cosine gate c=cos(m,v) triggers deterministic deficit driven repair when c<τc. This closed-loop design bounds VLM calls, reduces reliance on embedding-based semantic matching, and makes every retrieval and verification step lexically auditable. On TCGA-BRCA (930WSIs, patient-level 5-fold CV), HERO sets new state-of-the-art across ER, PR, HER2, subtype, and risk prediction, outperforming both multimodal fusion and VLM-based baselines.

## 1. 论文的核心问题与整体含义（研究动机和背景）
- **核心问题**：现有基于全切片图像（WSI）的预后预测系统，在处理匹配的多组学数据（DNA甲基化、miRNA）时，通常将组学视为**并行特征流**或**文本上下文**，而非一种可检验的形态学假设。这导致两个不足：(1) 组学未显式控制哪些组织区域被检索，易受视觉显著性偏差影响；(2) 缺乏分子-视觉对齐的验证机制，证据链不可审计。
- **整体含义**：HERO提出**假设驱动的证据检索**框架，将多组学转化为一个可检验的形态学假设（“意图向量”），通过词法匹配（TF-IDF）和一致性门控实现分子-形态的闭环验证，使得每个检索和判断步骤都可审计，从而提升多任务乳腺癌分析（ER/PR/HER2/亚型/风险）性能。

## 2. 论文提出的方法论：核心思想、关键技术细节
### 核心思想
- **三步闭环**：组学→形态意图（假设生成）→关键区域检索（证据收集）→一致性验证与缺陷驱动修复（假设检验），最终由VLM做出诊断。
- **关键创新**：基于稀疏的**通路-形态先验矩阵 W** 将组学映射为 K=16 维意图向量 m；利用**词法检索（TF-IDF）** 而非嵌入相似度来选择区域；设计**余弦门控 c=cos(m,v)** 判断分子-视觉是否对齐，若低于阈值则触发一次确定性修复。

### 关键技术细节
1. **Stage 1：组学到意图与关键词**
   - 对 DNA 甲基化、miRNA 进行 z‑归一化，通过 MSigDB Hallmark 通路掩码计算 50 维通路得分。
   - 使用固定的稀疏先验矩阵 **W**（16×50，基于 WHO 术语和已知生物学关联构建，未用标签优化）将通路得分映射为意图向量 m = ℓ2-normalize(ReLU(W·s))。
   - 通过 LLM 委员会生成关键词集 Q（15–40 个术语）和分子叙述。

2. **Stage 2：10× 层级的检索（300 → Top-64）**
   - 从 WSI 提取 300 个代表性组织块（基于 UNI 嵌入的 MiniBatchKMeans 聚类，保证全局多样性）。
   - 每个组织块在 10× 放大倍数下被 Qwen2.5-VL-7B 结构化描述，得到 300 个标题。
   - 对每个标题进行 TF-IDF 向量化，与关键词集 Q 计算余弦相似度，取 Top-64 区域作为证据。

3. **Stage 3：20× 一致性门控与缺陷驱动修复**
   - Top-64 区域在 20× 下排列为 8×8 马赛克，再次结构化描述得到 64 个标题。
   - 根据预定义的 16 轴形态清单（如核分裂活性、核多形性、坏死等）统计视觉证据向量 v（词汇边界匹配）。
   - 计算余弦门控 c = cos(m, v)。若 c ≥ τc=0.5，则接受；否则计算缺陷向量 m−v，根据缺陷权重重新检索 Top-32 修复候选，与原先 64 个合并后重新选出 Top-64，并额外进行一次 20× 描述。**仅一轮修复**。

4. **Stage 4：诊断模块**
   - 将最终 20× 马赛克（图片）、分子叙述（文本）与一致性摘要（c 值和修复状态）输入 Qwen2.5-VL-7B，经 LoRA 微调（rank=64, α=128, q/k/v/o_proj）输出 ER/PR/HER2/亚型/风险的 JSON 预测。

## 6. 论文的主要结论与发现
- HERO 在所有任务上均达到 **SOTA**，比最强多模态融合基线（SurvPath）在 HER2 上 +0.050 AUC、Risk 上 +0.030 C-index。
- 与相同 VLM 诊断头的控制基线相比，HERO 比 VLM+TransMIL Top-64 在 HER2 上高 +0.090，提升主要来自分子引导的检索与验证。
- 词法检索（TF-IDF）优于单纯视觉嵌入选取；缺陷驱动的修复是性能提升的关键（门控+修复比仅门控或无修复显著更优）。
- 先验矩阵 W 的生物学结构是有效的：W 洗牌（随机打乱通路-形态对应）导致性能明显下降（HER2 AUC 降 0.033、Risk C-index 降 0.032），而随机扰动影响很小。

## 7. 优点
- **可审计性**：整个证据链（意图向量、词汇匹配、门控分数、修复原因）在词法层面可审查，摒弃了隐式的黑盒融合。
- **计算效率**：闭环设计只需一次（至多两次）VLM 调用，相比多轮 agent 方法更可控；37% 的修复触发比例平衡了性能与开销。
- **生物可解释性**：将组学显式映射到已知的形态学轴，并利用通路-形态先验，使模型决策可关联到生物学通路。
- **实验严谨性**：统一了多模态基线输入，消融设计全面，参数敏感性分析覆盖主要超参数。

## 8. 不足与局限
- **外部泛化缺失**：仅在 TCGA-BRCA 内做交叉验证，未验证在不同医院、扫描仪、染色条件下的鲁棒性，存在过拟合与分布偏移风险。
- **任务特异性**：16 轴形态清单是针对乳腺癌手工设计的，其他肿瘤类型需重新审计和构建。
- **VLM 可靠性**：标题生成与诊断共享同一 VLM（Qwen2.5-VL-7B），可能引入“同模型偏差”；词汇边界匹配不能保证病理学正确性。
- **推理代价**：每张 WSI 平均 57 秒（2×A100），仍显昂贵，临床部署需进一步加速多阶段 VLM 推理。
- **组学输入限制**：仅使用了 DNA 甲基化和 miRNA，未纳入基因表达、蛋白质组等，可能遗漏其他分子信息。
