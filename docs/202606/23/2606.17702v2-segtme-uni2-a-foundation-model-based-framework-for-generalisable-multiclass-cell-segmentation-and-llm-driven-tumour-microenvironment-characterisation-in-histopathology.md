## 摘要
从常规H&E染色组织学图像中表征肿瘤微环境(TME)需要同时进行细胞分割、特征提取和可解释的临床报告。我们提出了SegTME-UNI2，一个统一框架来满足这些需求。其核心是UNI2-UperHoVeR，一个双头分割模型，将UNI2-h病理基础模型(ViT-Giant，在来自10万张切片的超过1亿个图块上预训练)与两个并行的UperNet解码器配对：一个用于六类语义分割，另一个用于水平-垂直梯度回归，从而实现基于分水岭的细胞核实例分离。为解决大型真实世界数据集中像素级标注的缺乏，UNI2-UperHoVeR经历了三阶段渐进式伪标签课程。每个阶段在不进行权重迁移的情况下训练新模型，完全通过提高伪标签质量来驱动改进：第1阶段：使用人工标注的PanNuke(7,901张图像，189,744个细胞核，0.25微米/像素)。第2阶段：使用第1阶段模型在271,711个TCGA-UT尺度0图块(0.5微米/像素)上的熵过滤伪标签。第3阶段：使用第2阶段模型在全部1,608,060个TCGA-UT图块(跨越六个分辨率尺度，0.5-1.0微米/像素)上的伪标签。分割输出输入一个结构化的TME特征提取流水线，计算20多个每图块组成、形态、空间熵和细胞间距离指标。这些指标被编码为JSON并传递给一个微调的NVIDIA BioNeMo GPT模型，以生成临床可解释的TME叙述。在保留的PanNuke和TCGA-UT分区上的初步验证证明了框架的可行性和内部一致性。公开释放了伪标注的TCGA-UT数据集和UNI2-UperHoVeR检查点，以支持大规模TME分析和空间生物学研究。

## Abstract
Characterising the tumour microenvironment (TME) from routine H&E-stained histology images requires simultaneous cell segmentation, feature extraction, and interpretable clinical reporting. We present SegTME-UNI2, a unified framework addressing these requirements. Its core is UNI2-UperHoVeR, a dual-head segmentation model pairing the UNI2-h pathology foundation model (ViT-Giant, pretrained on >100M tiles from 100K slides) with two parallel UperNet decoders: one for six-class semantic segmentation and one for horizontal-vertical gradient regression enabling watershed-based nuclear instance separation. To address the lack of pixel-level annotations in large real-world repositories, UNI2-UperHoVeR undergoes a three-stage progressive pseudo-label curriculum. Each stage trains a fresh model without weight transfer, driving improvement entirely via increased pseudo-label quality: Stage 1: Uses human-annotated PanNuke (7,901 images, 189,744 nuclei, 0.25 um/pixel). Stage 2: Uses entropy-filtered pseudo-labels from the Stage 1 model on 271,711 TCGA-UT scale-0 patches (0.5 um/pixel). Stage 3: Uses pseudo-labels from the Stage 2 model on all 1,608,060 TCGA-UT patches across six resolution scales (0.5-1.0 um/pixel). Segmentation outputs feed a structured TME feature extraction pipeline computing 20+ per-patch compositional, morphological, spatial entropy, and intercellular distance metrics. These are encoded as JSON and passed to a fine-tuned NVIDIA BioNeMo GPT model to generate clinically interpretable TME narratives. Preliminary validation on held-out PanNuke and TCGA-UT partitions demonstrates framework feasibility and internal consistency. The pseudo-labelled TCGA-UT dataset and UNI2-UperHoVeR checkpoint are publicly released to support large-scale TME profiling and spatial biology research.

### 2. 论文提出的方法论：核心思想与关键技术
*   **核心框架**: SegTME-UNI2，包含三个主要模块：分割模型、TME特征提取、LLM叙述生成。
*   **分割模型: UNI2-UperHoVeR**
    *   **核心思想**: 采用**双头解码器**架构，共享一个强大的UNI2-h (ViT-Giant) 病理基础模型编码器，同时输出语义分割和实例分割所需的信息。这避免了为不同任务训练两个独立模型。
    *   **关键技术细节**:
        1.  **编码器**: UNI2-h (ViT-Giant)，从Transformer块5, 11, 17, 23提取多尺度特征，形成特征金字塔(FPN)。
        2.  **双头解码器**: 两个独立的**UperNet**解码器头。
            *   **语义头**: 输出六类语义分割图 (肿瘤、炎症、结缔、坏死、上皮、背景)，使用交叉熵损失。
            *   **HV回归头**: 输出水平-垂直梯度图，用于后续基于分水岭算法的实例分离。使用MSE损失和梯度匹配损失。
        3.  **动态HV目标合成**: 创新点之一。无需实例级标注，而是通过**对语义掩码进行连通域分析**，为每个连通域计算其到质心的距离，从而动态生成HV回归目标的伪标签。这使得仅依赖语义标注就能训练实例分割分支。
*   **训练策略：三阶段渐进式伪标签课程**
    *   **核心思想**: 一种自训练方法，逐步扩大训练数据的规模和分辨率，同时提高伪标签的质量。**每个阶段都从头开始训练一个新模型**，不以权重继承来传递信息，而是通过上一阶段模型产生的更高质量的伪标签作为下一阶段训练的起点。
    *   **三阶段流程**:
        1.  **阶段1**: `θ1` 在人工标注的PanNuke (0.25 µm/px) 上训练作为监督种子。
        2.  **阶段2**: `θ1` 在TCGA-UT Scale 0 (0.5 µm/px)上生成伪标签，经过熵过滤后用于从头训练 `θ2`。
        3.  **阶段3** `θ2` 在所有6个尺度的TCGA-UT (0.5-1.0 µm/px)上生成伪标签，用于从头训练最终的 `θ3`。
*   **TME特征提取流水线**
    *   从分割结果中计算**20多种**每图块特征，包括：细胞计数与比例、形状特征、肿瘤-基质比、免疫浸润分数、**基于cKDTree的免疫细胞到肿瘤细胞最小/平均距离**、以及**基于K近邻香农熵的空间混合度**。输出为结构化JSON。
*   **LLM驱动叙述生成**
    *   **核心思想**: 利用LLM将结构化的量化TME特征转化为自然语言报告。这比直接从像素生成叙述更可控、更可验证，降低了幻觉风险。
    *   **关键技术细节**:
        1.  **生物标记翻译**: 首先通过硬编码规则将量化特征转化为6个维度的表型标签（如肿瘤纯度、免疫状态）和一个扁平的生物标记列表。
        2.  **模型微调**: 使用NVIDIA BioNeMo框架，在160万个合成的（由规则生成）(结构化提示, 临床叙述) 数据对上，对 **LLaMA-3.2-1B** 模型进行监督微调。
        *   **输入提示**: 包含METADATA, RAW_FEATURES, SCENARIO, KEYWORDS四个信息块。
        *   **输出**: 生成临床风格的图块TME描述。

    *   **动态HV目标合成**: 巧妙地解决了实例分割对昂贵人工标注依赖的难题，使得仅用语义标注就能训练实例分割分支。
    *   **三阶段渐进式伪标签课程**: 阶段性的、从头开始的训练策略很新颖，有效避免了单步自训练的误差积累和灾难性遗忘问题。
    *   **LLM与量化特征结合**: 这种方法相比端到端的图像-语言模型（如PathChat）更可控，可验证，显著降低了幻觉风险，是一个实用且有见地的设计。
3.  **开源贡献大**: 公开了160万张伪标注的TCGA-UT数据集和模型检查点，这为社区提供了宝贵的大规模基准数据，将极大地推动该领域的研究。
4.  **清晰的失败分析**: 对阶段3模型性能下降的原因（放大率不匹配）进行了清晰的诊断和分析，并给出了有建设性的改进方向，体现了严谨的科研态度。

### 8. 不足与局限
1.  **实验严重不足**:
    *   **缺失关键基准测试**: 未在任何公开权威基准（如MoNuSeg, CoNSeP）上与主流方法（HoVer-Net, CellPose等）进行量化的指标对比（如DSC, PQ, AJI）。
    *   **缺乏统计严谨性**: 所有结果是单次运行，没有报告置信区间、标准差或进行显著性检验。
    *   **缺乏消融实验**: 没有量化HV头、FPN、熵阈值等各组件对最终性能的贡献。
    *   **缺乏临床验证**: 没有将TME特征与临床结局/生存数据关联，以证明其临床价值。
    *   **忽略LLM评估**: LLM生成的叙述质量未经过任何定量或定性的路径学家评估。这大大削弱了“LLM驱动”这一核心贡献的说服力。
2.  **技术缺陷与不一致**:
    *   **阶段3模型失效**: 由于放大率不匹配，理论上最强的阶段3模型（θ3）性能反而不如阶段2模型（θ2）。论文不得不使用θ2进行关键定性分析，这暴露了当前训练策略的脆弱性和对尺度变化的敏感性。
    *   **伪标签质量不确定性**: 无人工标注的TCGA-UT伪标签的质量是未知的，表7中的PL-val self-consistency仅能验证自洽性，不能代表真实精度。
    *   **叙述质量可信度**: 所有生成TME叙述的LLM训练数据本身是合成（由规则生成）的，可能存在系统性偏差和缺乏临床真实感。模型的真实泛化能力存疑。
3.  **应用限制**:
    *   **图块级别分析**: 整个流水线目前是图块级别的，距离处理完整WSI还有一定距离（虽然作者提到了图块拼接）。
    *   **规则化阈值依赖**: 生物标记翻译中的20多个阈值依赖于领域知识且是针对当前数据集校准的，在不同染色/放大条件下可能需要重新调整，泛化性待验证。
