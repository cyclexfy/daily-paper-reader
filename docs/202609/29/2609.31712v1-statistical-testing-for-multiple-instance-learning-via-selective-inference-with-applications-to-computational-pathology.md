## 摘要
多示例学习（MIL）广泛应用于计算病理学，因为它能够对全切片图像（WSIs）进行弱监督分析，而无需图像块级标注。在基于注意力的 MIL 中，注意力分数高的示例通常被解释为诊断上重要的区域，并用作可视化解释。然而，仅凭注意力分数无法确定所选的高注意力示例是否与正常示例显著不同，这限制了基于注意力的解释的可靠性。在本文中，我们将高注意力示例的评估形式化为一个统计假设检验问题。具体来说，我们评估一个选定的高注意力示例是否显著偏离基于特征相似性选出的具有代表性的正常参考示例。一个主要挑战是，目标示例和参考示例都是通过数据依赖的过程选出的，这使得标准假设检验失效。为了解决这个问题，我们引入了一个选择性推断（SI）框架，该框架明确考虑了由基于注意力的示例选择和自适应参考选择所引发的选择事件，从而能够计算以这些事件为条件的有效选择性 p 值。实验证明了在合成数据和基于 MNIST 的数据上的 I 类错误控制，以及对病理 WSIs 的实际适用性，并且比传统的过度条件化方法具有更高的统计功效。

## Abstract
Multiple instance learning (MIL) is widely used in computational pathology because it enables weakly supervised analysis of whole-slide images (WSIs) without requiring patch-level annotations. In attention-based MIL, instances with high attention scores are often interpreted as diagnostically important regions and used as visual explanations. However, attention scores alone cannot determine whether selected high-attention instances are significantly different from normal instances, limiting the reliability of attention-based explanations. In this paper, we formulate the evaluation of high-attention instances as a statistical hypothesis testing problem. Specifically, we assess whether a selected high-attention instance significantly deviates from a representative normal reference instance selected based on feature similarity. A major challenge is that both the target instance and the reference instance are selected through data-dependent procedures, rendering standard hypothesis testing invalid. To address this issue, we introduce a selective inference (SI) framework that explicitly accounts for the selection events induced by attention-based instance selection and adaptive reference selection, thereby enabling the computation of valid selective $p$-values conditional on these events. Experiments demonstrate Type-I error control on synthetic and MNIST-based data and practical applicability to pathological WSIs, with higher statistical power than the conventional over-conditioning approach.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：多示例学习（MIL）是计算病理学中分析全切片图像（WSI）的主流弱监督范式，其中基于注意力的 MIL（ABMIL）因简单、可解释而被广泛使用。ABMIL 给每个图像块（instance）分配注意力分数，高注意力块通常被当作"诊断重要区域"用于可视化解释，并越来越多地用于下游临床分析与候选异常区域定位。
- **核心痛点**：
  - 近期研究（Jain & Wallace 等）质疑注意力分数是否真能对应因果或临床上有意义的证据；
  - 高注意力块可能源于数据集偏置、染色伪影或优化效应，而非真实的病理异常；
  - **仅凭注意力分数无法回答"该高注意力块是否显著偏离正常样本"这一统计问题**，导致注意力解释的可靠性缺乏量化保证。
- **论文的整体含义**：将"高注意力示例的评估"重新形式化为一个**统计假设检验问题**——检验某个被选中的高注意力示例是否显著偏离一个按特征相似性自适应选出的正常参考示例。
- **统计挑战**：目标示例（由注意力分数选出）与参考示例（由 k-NN + medoid 自适应选出）**都是数据依赖地选出的**，标准检验（假定假设独立于数据预先指定）会因"选择偏差/双重 dipping"（Kriegeskorte 等）而失效。
- **解决思路**：引入**选择性推断（Selective Inference, SI）**，对选择事件条件化，计算有效的选择性 p 值。作者称这是**首次**在假设检验框架下量化 MIL 模型所选实例的统计显著性。

## 2. 方法论

### 2.1 核心思想

- 把 MIL 算法诱导的**数据依赖实例选择**视为"选择事件"，并在 SI 框架内对该事件条件化，从而在保持第一类错误控制的同时获得比过条件化更高的统计功效。
- 以 ABMIL 作为概念验证架构（因其注意力机制显式、可刻画），但原理不限于 ABMIL。

### 2.2 问题设定与假设

- 测试包 $X_{\text{test}}=\{x^i_{\text{test}}\}$，参考集 $X_{\text{ref}}=\{x^j_{\text{ref}}\}$（正常实例，独立于训练集与测试包）。
- 高注意力集合 $C(X_{\text{test}})=\{i \mid a^i_{\text{test}}>\tau\}$，$\tau$ 为预先固定或由独立数据估计的注意力阈值（本文操作于 **sigmoid 前的注意力 logit**）。
- **信号加噪声模型**：$X_{\text{test}}=s_{\text{test}}+\epsilon_{\text{test}}$，$X^j_{\text{ref}}=s^j_{\text{ref}}+\epsilon^j_{\text{ref}}$，噪声 $\epsilon\sim N(0,\sigma^2 I_d)$ 相互独立；信号向量 $s$ 为**任意未知固定向量**（不对信号分布作假设，仅对扰动作高斯假设）。
- 假设：$H_0: s_{\text{test}}=s^{j_{\text{med}}}_{\text{ref}}$ vs. $H_1: s_{\text{test}}\neq s^{j_{\text{med}}}_{\text{ref}}$。

### 2.3 检验统计量

- 欧氏距离统计量 $T=\frac{1}{\sqrt{2}}\|X_{\text{test}}-X_{j_{\text{med}}^{\text{ref}}}\|_2$，标准化后 $\tilde T=T/\sigma$。
- **朴素做法**：固定参考下 $\frac{1}{\sqrt{2}\sigma}\|X_{\text{test}}-X^j_{\text{ref}}\|_2\sim\chi_d$，据此得 $p_{\text{naive}}=P(\chi_d\ge \tilde T_{\text{obs}})$——在自适应选择下**无效**。

### 2.4 选择性推断框架

- **向量化**：$y=\mathrm{vec}(x_{\text{test}},x^1_{\text{ref}},\dots,x^{M_{\text{ref}}}_{\text{ref}})$，统计量写成 $T(Y)=\|PY\|_2$，$P$ 为仅涉及测试实例与所选代表参考实例的**正交投影矩阵**（rank $d$）。
- **选择映射**：
  - 注意力选择 $A(Y)=I\{f_{\text{att}}(f_{\text{enc}}(X_{\text{test}}))>\tau\}$；
  - k-NN 检索 $K(Y)=\mathrm{Top}_k\{\|\cdot\|_2^2\}$——**不纳入条件事件**（仅作为局部划分）；
  - 自适应参考选择 $M(Y)=\arg\min_{j\in K}\sum_{j'\in K}\|f_{\text{enc}}(X^j)-f_{\text{enc}}(X^{j'})\|_2^2$（k-NN 集合的 medoid）；
  - 总体选择映射 $E=(A,M)$，条件化为 $E(Y)=E(y)$。
- **冗余统计量条件化**：$Q(Y)=\big(PY/\|PY\|_2,\ (I-P)Y\big)$，固定投影方向与正交分量后，随机性只剩一维路径 $Y(z)=a+bz$（$z=\tilde T(Y)$）。
- **定理 4.1**：在 $H_0$ 下，$\tilde T(Y)\mid E(Y)=E(y),Q(Y)=Q(y)$ 服从**截断 χ 分布**（自由度 $d$，截断区域由条件事件决定）。
- **定理 4.2**：$P_{H_0}(p_{\text{selective}}\le\alpha\mid E,Q)=\alpha$，即精确控制条件第一类错误率。

### 2.5 选择事件的刻画（参数规划）

- 沿一维路径，编码器/注意力网络的**分段仿射**性质使注意力 logit 在每个激活区域内对 $z$ 仿射。
- k-NN 排序条件 $\Rightarrow$ **二次不等式**（距离差 $D_j(z)-D_{j'}(z)\le 0$），得到局部区域 $Z_K(K)$；
- medoid 选择条件 $\Rightarrow$ 二次不等式（medoid 得分差），得到 $Z_{M|K}(K)$；
- **总体参考选择区域** $Z_M=\bigcup_{K\ni j_{\text{med}}^{\text{obs}}}\big(Z_K(K)\cap Z_{M|K}(K)\big)$：k-NN 集合**可以变化**，只要最终 medoid 不变；
- 总体截断区域 $Z=Z_A\cap Z_M$，通常为若干不相交区间 $\bigcup_r[\ell_r,u_r]$；选择性 p 值按式 (9) 计算为截断 $\chi_d$ 的上尾概率。

### 2.6 对比方法

- **Proposed**：条件化于 $A$ 与 $M$，用参数规划刻画**整个**截断区域；
- **Ablation 1**：忽略注意力选择事件；
- **Ablation 2**：忽略自适应参考选择事件；
- **Over-conditioning (OC)**：只用包含观测统计量的局部截断区间（过度条件化，功效更低）；
- **Bonferroni**：$p_{\text{Bonf}}=\min\{1,\lambda_{\text{att}}M_{\text{ref}}\,p_{\text{naive}}\}$，$\lambda_{\text{att}}=N_{\text{sample}}/N_{\text{att}}$；
- **Naive**：直接用固定选择零分布（仅用于合成实验，说明忽略选择过程的后果）。
