## 摘要
基于注意力的多实例学习（ABMIL）使用病理学基础模型嵌入对于幻灯片级任务有效，但详尽推断需要对每个前景图块应用大型图像编码器，尽管后续的注意力分布通常集中在少数信息丰富区域上。我们引入了ADMIL（注意力蒸馏多实例学习），这是一种选择性计算框架，将ABMIL教师的注意力蒸馏到一个轻量级的图块选择模型PriorNet中。PriorNet采用EfficientNet架构，通过KL散度从原始图块像素学习教师注意力分布；在推断时，它对前景池进行评分，选择前K个图块，并且仅在该子集上调用昂贵的基础模型，然后由所选包ABMIL学生模型预测幻灯片标签。在BRACS、PANDA和CAMELYON16上，ADMIL在K=4、8和128个图块时分别达到了完整教师模型的领先性能，避免了超过98%的基础模型（Virchow2）图块嵌入和模型推断FLOPs。随机和教师注意力神谕控制表明，这一结果依赖于任务相关的选择，而非仅仅减少图块数量。定量和定性分析表明，PriorNet在关注任务相关形态学区域的同时，以高保真度恢复了教师的图块排序。ADMIL表明，几乎可以移除所有昂贵的图块编码而不牺牲幻灯片级性能，为在延迟和计算成本是关键考虑的临床环境中更高效部署提供了潜在途径。

## Abstract
Attention-based multiple instance learning (ABMIL) using pathology foundation model embeddings is effective for slide-level tasks, but exhaustive inference requires applying a large image encoder to every foreground tile despite the subsequent attention distribution often concentrating over a small subset of informative regions. We introduce ADMIL (Attention-Distilled Multiple Instance Learning), a selective-compute framework that distills an ABMIL teacher's attention into a lightweight tile-selection model, PriorNet. Using an EfficientNet architecture, PriorNet learns the teacher attention distribution from raw tile pixels with KL divergence; at inference, it scores the foreground pool, selects the top-K tiles, and invokes the expensive foundation model only on that subset before a selected-bag ABMIL student predicts the slide label. Across BRACS, PANDA, and CAMELYON16, ADMIL matches full-teacher headline performance at K=4, 8, and 128 tiles, respectively, avoiding >98% of foundation model (Virchow2) tile embeddings and model inference FLOPs. Random and teacher-attention oracle controls show that this result depends on task-relevant selection rather than tile-count reduction alone. Quantitative and qualitative analyses suggest that PriorNet recovers the teacher's tile ordering with high fidelity while focusing on task-relevant morphological regions. ADMIL shows that nearly all expensive tile encodings can be removed without sacrificing slide-level performance, providing a potential path for more efficient deployment in clinical settings where latency and compute costs are key considerations.

### 1. 论文的核心问题与整体含义（研究动机和背景）

- **背景**：病理学基础模型（如 Virchow2）结合基于注意力的多实例学习（ABMIL）已成为全切片图像（WSI）分析的标准范式。该流程通常将每张 WSI 划分为成千上万个前景 tile，使用基础模型对所有 tile 进行嵌入，再由 ABMIL 聚合得到幻灯片级预测。
- **核心问题**：一次性 WSI 可能包含数千至数万个前景 tile，对全部 tile 执行昂贵的基础模型推理会主导延迟、计算成本和吞吐量，严重制约临床部署。然而，训练好的 ABMIL 模型的注意力分布往往高度集中在少数具有形态学信息的关键区域，这意味着大量 tile 编码是冗余的。
- **核心思想**：这种"全量编码但稀疏关注"的不匹配，催生了一种**选择性计算（selective-compute）**策略——先用轻量级模型筛选出高价值 tile，再仅对这些 tile 调用昂贵的基础模型，从而大幅降低推理成本而不牺牲性能。

### 2. 论文提出的方法论

#### 2.1 总体框架：ADMIL（Attention-Distilled Multiple Instance Learning）

ADMIL 是一种两阶段的蒸馏-选择-预测框架，与传统的模型压缩不同，它并不替代基础模型或 ABMIL 架构，而是**作为访问昂贵编码器的"门控"机制**。

#### 2.2 阶段一：注意力蒸馏（Attention Distillation）

- **教师模型**：使用全量前景 bag 训练的标准 ABMIL（Virchow2 嵌入 + 非门控注意力聚合器），训练后冻结。
- **注意力计算**：教师对每个 tile 计算注意力 logit \(a_i = w_a^\top \tanh(W_a z_i + b_a)\)，经 softmax 归一化得到注意力权重 \(\alpha_i\)。
- **PriorNet（学生选择器）**：采用 **EfficientNet-B0** 架构（ImageNet-1K 预训练），以原始 tile 像素作为输入，输出一个标量分数 \(s_i = p_\phi(x_i)\)，经 softmax 得到归一化分布 \(q_i\)。
- **蒸馏损失**：通过 **KL 散度** 对齐 PriorNet 的分布 \(q\) 与教师的注意力分布 \(\alpha\)：
  \[
  \mathcal{L}_{prior} = D_{KL}(\alpha \| q) = \sum_{i=1}^{N} \alpha_i \log \frac{\alpha_i + \epsilon}{q_i + \epsilon}
  \]
- **注意力引导采样（Attention-Guided Sampling）**：为降低训练成本并增强对高注意力 tile 的表示，仅使用每张 WSI 中 Z% 的前景 tile 进行训练（默认 Z=10%），其中前 M/2 个为教师注意力最高的 tile，其余 M/2 从剩余前景池中均匀采样。评估和部署时 PriorNet 对完整前景池评分。

#### 2.3 阶段二：Top-K 选择与 Selected-Bag ABMIL

- **Tile 选择**：PriorNet 对全部前景 tile 评分后，按分数降序取前 K 个 tile 作为选定集合 \(S_K(X)\)。
- **条件嵌入**：仅对选中的 K 个 tile 调用基础模型 \(z_i = f_\theta(x_i)\)，大幅减少基础模型调用次数。
- **学生模型**：训练一个独立的 selected-bag ABMIL 学生模型，仅基于这 K 个 tile 的嵌入进行注意力聚合和幻灯片级预测（使用原始任务损失函数）。
- **部署流程**：推理时 PriorNet 扫描全部前景 → 选出 top-K → 基础模型仅嵌入选定 tile → 学生 ABMIL 输出预测。

### 3. 实验设计

#### 3.1 数据集与任务

#### 3.2 对比方法（Baselines and Controls）

- **Full teacher（全量教师）**：对所有前景 tile 嵌入的原始 ABMIL，作为全计算量的性能参考。
- **Random top-K（随机选择）**：随机均匀采样 K 个 tile 训练/评估 selected-bag ABMIL，用于控制"减少 tile 数量"这一因素本身的影响。
- **Teacher top-K oracle（教师注意力神谕）**：使用教师真实注意力选择 top-K tile（实际不可部署，因为需要全量推理才能获得注意力），用于估计"完美恢复教师证据"时的性能上限。

#### 3.3 评估指标

- CAMELYON16：AUROC 和 AUPRC
- PANDA：二次加权 Kappa（QWK）和 within-1 准确率
- BRACS：平衡准确率和宏平均 one-vs-rest AUROC
- 每个数据集使用 3 个随机种子（0, 1, 2）分别运行，报告平均结果，置信区间通过 1,000 次分层 bootstrap 估计。

#### 3.4 消融与敏感性分析

- **PriorNet 监督预算敏感性**：比较 Z = 5%、10%、20% 三种训练 tile 采样比例。
- **注意力保真度分析**：计算 PriorNet 与教师注意力之间的 Pearson / Spearman 相关系数，以及教师支持检索率（teacher-support retrieval）指标。

### 6. 论文的主要结论与发现

1. **性能保持**：ADMIL 在极小的 tile 预算下即可达到全量教师的性能——BRACS 只需 K=4 个 tile、PANDA 需 K=8、CAMELYON16 需 K=128，对应避免 **98.5%–99.8%** 的基础模型 tile 嵌入和 **98.3%–99.6%** 的模型推理 FLOPs。
2. **选择性优于随机性**：随机 top-K 在低预算区间性能显著较差，而 ADMIL 和教师 oracle 性能接近，证明性能保持依赖于**任务相关的 tile 选择**而非单纯的数量缩减。
3. **注意力蒸馏有效性**：PriorNet 能较好地恢复教师的 tile 排序（Spearman 相关系数 0.579–0.839），排名保真度优于精确数值校准。
4. **形态学合理性**：定性分析显示教师和学生关注的重叠 tile 包含与诊断一致的形态学特征（如肿瘤细胞、高级别癌形态）。
5. **超参数鲁棒性**：PriorNet 训练采样比例 Z 在 5%–20% 范围内变化时，性能轨迹基本一致，说明方法对该超参数不敏感。

### 7. 优点

- **问题定位精准**：准确识别了基础模型 ABMIL 流程中"全量计算、稀疏关注"的核心效率瓶颈，切入点具有现实意义。
- **方法设计简洁有效**：蒸馏教师注意力到轻量级选择器的思路直观且实现简单，与结构复杂的高效 MIL 方法（如多分辨率方法、特征蒸馏方法）相比更具实用性。
- **计算不对称性利用充分**：PriorNet 与 Virchow2 之间约 442 倍的单 tile FLOPs 差距，使得全池扫描成本仅占全量推理的约 0.226%，这是方法高效性的关键支撑。
- **控制实验设计严谨**：随机选择基线和教师 oracle 的设计使得结论具有较强说服力，有效排除了"仅因 tile 数量减少而性能不变"的混淆解释。
- **评估全面**：同时包含性能指标、计算效率、注意力相关性、检索保真度（多个维度）和定性形态学分析。

### 8. 不足与局限

- **依赖教师注意力的质量**：ADMIL 的前提是教师注意力集中在少量任务相关区域。若教师注意力分散或关注到混淆因素（confounders），PriorNet 的筛选可靠性将下降。论文对"低质量教师"情况缺乏讨论和实验。
- **K 的选择缺乏前瞻性**：Kcrit 是测试集上的事后最优值，实际部署时需要预先在验证集上确定 K，论文未提供明确的验证集选 K 策略和相应的性能预期。
- **数据集与基础模型覆盖有限**：仅在 3 个数据集和单一基础模型（Virchow2）上验证，未测试在其他基础模型（UNI、CONCH、GigaPath 等）或其他任务类型（如突变预测、生存分析）上的表现。
- **训练开销增加**：ADMIL 需要额外训练 PriorNet 和每个 K 值对应的学生 ABMIL，虽然推理成本大幅降低，但训练阶段的负担被加重。
- **FLOPs 统计口径局限**：效率计算仅涵盖模型前向传播 FLOPs，未包含 I/O、预处理、数据加载等环节，因此实际墙钟时间（wall-clock latency）的改善幅度可能低于 FLOPs 节省所暗示的水平。
- **BRACS 上的注意力蒸馏质量相对较低**（Spearman 0.579），虽然性能仍能匹配教师，但也提示该方法在不同任务上的适用性存在差异，论文对此的解释较为初步。
