## 摘要
前列腺癌是全球最常见的恶性肿瘤之一，对每个活检核心进行结构化报告给病理学家带来了沉重负担。现有工具将此视为分类问题，让病理学家自行整合连贯报告，而许多切片级视觉语言模型依赖于以英语为中心的编码器，这些编码器迁移到其他临床语言时效果不佳。我们提出了一种切片级框架，用于生成前列腺活检报告，该框架在结构上独立于语言：分词器和模型从头开始训练，在此以德语演示。为了解决配对数据稀缺问题，自动化流水线使用本地部署的大型语言模型将复合报告拆分为核心特定的图像-文本对，从2,402个历史病例中生成17,344对，无需人工标注。在临床属性而非语言相似性上评估，模型在恶性肿瘤检测中达到96.2%的F1分数，在Gleason分级中达到65.2%，与FDA批准的分类器相当。通过潜在空间增强，在三个外部队列上进一步验证了分级。因此，机构可以在自己的档案上训练母语报告模型。

## Abstract
Prostate cancer is among the most frequently diagnosed malignancies worldwide, and structured reporting of each biopsy core burdens pathologists. Existing tools frame this as classification, leaving pathologists to assemble coherent reports, while many slide-level vision-language models rely on English-centric encoders that transfer poorly to other clinical languages. We present a slide-level framework generating prostate biopsy reports that is language-independent by construction: tokenizer and model are trained from scratch, demonstrated here in German. To address paired-data scarcity, an automated pipeline uses a locally deployed large language model to split composite reports into core-specific image-text pairs, yielding 17,344 pairs from 2,402 historical cases without manual annotation. Evaluated for clinical attributes rather than linguistic similarity, the model achieves 96.2% F1 for malignancy detection and 65.2% for Gleason grading, competitive with an FDA-cleared classifier. Grading is further validated on three external cohorts with latent-space augmentation. Institutions can thus train native-language reporting models on their own archives.

## 2. 提出的方法论

### 2.1 总体框架
- 采用 **CoCa（Contrastive Captioner）** 架构，包含三个主要部分：**切片编码器**、**文本编码器**和**多模态解码器**。
- 整体训练目标为对比损失与标题生成损失的加权和：`L = λ_con * L_con + λ_cap * L_cap`，本文中 `λ_con = λ_cap = 1`。

### 2.2 数据流水线：报告拆分与标签提取
- 使用本地部署的 LLM（`gpt-oss-120b`，4-bit 量化）在院内安全环境中运行，避免数据外泄。
- 采用 few-shot prompting：
  1. 将复合报告拆分为“显微镜检查”和“关键发现”两个主要章节；
  2. 根据标本编号，进一步提取每个活检核心对应的专门文本；
  3. 将提取到的文本与对应 WSI 配对，形成 WSI-text 对。
- 使用同一 LLM 从文本中提取结构化标签：恶性状态、Gleason 分级、浸润百分比或长度（毫米）。
- 人工审计 200 个随机样本，未发现提取差异，验证了流水线的准确性。

### 2.3 图像预处理
- 使用 TRIDENT 工具包，基于 GrandQC 分割模型将组织区域分割出来。
- 将组织切成 512×512 像素的块（0.26 μm/px），再下采样到 224×224 像素输入。
- 使用冻结的病理基础模型 **UNI2-h** 提取每个 patch 的 1536 维嵌入。
- 训练时每张 WSI 最多动态采样 4,800 个 patch。

### 2.4 文本分词器
- 训练了**领域特定的 BPE 分词器**，仅在德语病理文本语料上训练，不依赖任何预训练语言模型。
- 保留大小写和变音符号，数字拆分为独立数字。
- 词汇表仅 **10,142 个 token**（含 8 个特殊 token），中位每个文本 95 个 token（原始中位词数为 47），相比 BioGPT 的 42,384 词汇表更具效率。
- 使用专用章节控制 token 保留报告结构（如显微镜、关键发现），并在报告开头预置 Gleason 分数 token，使生成过程先预测分级再生成其余文本。

### 2.5 模型架构细节
- **切片编码器**：6 个 transformer block，12 个注意力头，768 维；使用可训练的 CLS token 作为切片级表示。
- **位置编码**：提出二维 ALiBi 扩展，根据 patch 在切片上的欧氏距离对注意力 logits 施加惩罚：
  `attn_h(p1, p2) = q_p1^T k_p2 / sqrt(dk) − γ m_h d(p1, p2)`，其中 `d` 为归一化后的二维距离，`m_h` 为头相关斜率（固定几何调度），`γ` 为全局因子，CLS token 不加入空间惩罚。
- **文本编码器**：12 个 transformer block，768 维，因果掩码；末尾 CLS token 用于对比损失。
- **多模态解码器**：12 个 transformer block，通过交叉注意力从切片表示中获取信息，输出下一个 token 的概率分布。

### 2.6 训练与推理
- 优化器：AdamW（beta=0.9/0.999，权重衰减 0.2）。
- 学习率：10,000 步 warm-up 至 5×10⁻⁵，随后余弦退火至 0，共训练 200 epochs，batch size 32。
- 使用 **基于分级分布的过采样** 缓解类别不平衡，每个样本被采样的概率与类别频率成反比。
- 推理时使用 **贪心解码（k=1）** 以保证确定性、可复现性和临床可审计性。

### 2.7 域偏移缓解：双层增强策略
- **像素级颜色增强**：每张训练 WSI 生成两种额外颜色变体（更亮/低饱和、更暗/高饱和），模拟 H&E 染色差异，分别通过冻结编码器得到三种嵌入集。
- **潜空间增强**：训练一个轻量辅助模型（单 transformer block），输入原始 patch 嵌入和增强参数向量，预测增强后的嵌入；该辅助模型在 380 万个 patch 上训练后冻结，训练报告生成模型时每 epoch 随机采样增强参数，为每张切片提供不同的潜空间表示。
- 验证和测试时不进行任何增强。

## 6. 主要结论与发现

1. **语言无关的端到端训练可行**：从零训练分词器和模型，无需预训练文本编码器，即可生成德语前列腺病理报告。
2. **诊断性能接近或媲美商业工具**：
   - Munich 测试集：恶性检测准确率 97.6%，F1 = 96.2%；分级准确率 87.2%，宏 F1 = 65.2%。
   - ABMIL 基线：恶性 F1 = 96.0%（差 0.2%），分级 F1 = 63.5%（低 1.7%）。
   - FDA 工具：恶性 F1 = 95.1%，分级 F1 = 68.8%（分级略高但恶性略低）。
   - PRISM：恶性 F1 = 94.5%，分级 F1 = 44.9%（低 20.3% 个百分点）。
3. **外部泛化能力**：
   - Heidelberg：恶性 F1 = 91.9%，分级 F1 = 41.3%。
   - Karolinska：恶性 F1 = 95.0%，分级 F1 = 50.1%。
   - Radboud：恶性 F1 = 95.4%，分级 F1 = 46.2%。
   - 错误以相邻等级误分为主，与病理医师间观察者差异模式一致。
4. **增强策略有效**：潜空间增强在四个队列上均提升分级 F1（Karolinska +8.7、Radboud +1.6、Heidelberg +1.5、Munich +4.2）。
5. **模型学习到浸润定量信息**，但绝对误差较大（毫米中位误差 1.4 mm，百分比中位误差 10.0%），仅适合作为粗略估计。
6. **可解释性良好**：注意力图与肿瘤区域高度吻合，UMAP 显示良性/恶性及分级过渡结构，生成的报告包含 Gleason 比例、IHC 提示等附加临床上下文。

- **域适应技术**：双层增强（像素级 + 潜空间）方法轻量且通用，对低数据场景具有推广价值。

## 8. 不足与局限

- **高分级性能薄弱**：Gleason ≥ 9 样本极少（仅占 2.6%），模型对该类别识别能力不足，外部队列亦然。
- **浸润估计精度有限**：R² 低于 0.5，绝对误差较大，不能作为精确临床测量值，只能作为辅助估计。
