## 摘要
多模态大语言模型（MLLMs）可以从组织学图像生成病理描述，但十亿像素的全切片图像（WSIs）超出了其视觉上下文限制。标准的平铺处理使WSIs变得可处理，却切断了定义肿瘤-间质界面和形态的组织邻域。我们提出了空间语言消息传递（SLMP），这是一个完全在语言空间中进行空间推理的框架，其输出天然可读。SLMP将WSI区域表示为空间文本图：平铺块作为节点，初始化为MLLM描述，边编码空间邻接关系。对于每个平铺块，LLM在共享聚合策略下，通过整合来自相邻平铺块的语言消息来细化其描述；该策略在平铺网格上充当作用于文本而非学习嵌入的自适应局部核。该策略是一个可检查的提示，可以通过文本梯度从模型观察到的组织表型中优化，实现从局部细胞上下文到更广泛组织形态的自动语义优化，而无需微调MLLM权重。在代表性的HER2和CAMELYON16区域上，SLMP在通用和病理专用骨干网络设置中提升了平铺级肿瘤描述准确性，提升幅度为+3.3至+19.6个百分点。随机邻居消融实验证实，这些提升源于空间上下文而非单纯额外文本；检查优化后的策略揭示了可解释的、组织特异的决策规则。此外，无需任何权重更新或微调骨干MLLM，SLMP显著提升了通用MLLM的性能，并缩小了其与病理专用模型的差距，为将空间推理融入基于MLLM的病理分析提供了一种透明且灵活的机制。

## Abstract
Multimodal Large Language Models (MLLMs) can generate pathological descriptions from histological images, but gigapixel Whole Slide Images (WSIs) exceed their visual context limits. The standard tiling workaround makes WSIs tractable yet severs the tissue neighborhoods that define tumor-stroma interfaces and morphology. We introduce Spatial Language Message Passing (SLMP), a framework that performs spatial reasoning entirely in language space, human-readable by construction. SLMP represents a WSI region as a spatial text graph: tiles are nodes initialized with MLLM descriptions, and edges encode spatial adjacency. For each tile, an LLM refines its description by integrating language messages from adjacent tiles under a shared aggregation policy that, on the tile grid, acts as an adaptive local kernel operating on text rather than learned embeddings. This policy is an inspectable prompt that can be refined from model-observed tissue phenotypes via textual gradients, enabling automatic semantic optimization from local cellular context to broader tissue morphology without fine-tuning MLLM weights. On representative HER2 and CAMELYON16 regions, SLMP improves tile-level tumor description accuracy in settings spanning general-purpose and pathology-specialized backbones, with gains of +3.3 to +19.6 percentage points. Random-neighbor ablations confirm that these gains stem from spatial context rather than additional text alone, and inspecting the optimized policies reveals interpretable, tissue-specific decision rules. Besides, without any weight updates or fine-tuning the backbone MLLM, SLMP substantially improves general-purpose MLLMs and narrows its gap to pathology-specialized counterparts, offering a transparent and flexible mechanism for incorporating spatial reasoning into MLLM-based pathology analysis.

### 2. 论文提出的方法论

#### 2.1 核心思想：空间语言消息传递（SLMP）

论文提出 **Spatial Language Message Passing (SLMP)** 框架，核心是将病理图像的空间推理完全转移到**语言空间**进行：

- 将 WSI 区域表示为**空间文本图（spatial text graph）**：节点为切块（tile），存储该切块的 MLLM 生成的自然语言形态学描述；边编码 4-连通（上下左右）的空间邻接关系。
- 每个中心节点的描述通过 LLM 在其邻居描述的参与下更新，更新过程由**共享聚合策略（prompt）**控制。
- 在规则网格上，这个共享策略的行为类似于卷积核滑动窗口，但**表示、消息和聚合规则都用自然语言而非数值特征向量表达**——是可读取的“语言空间卷积核”。

#### 2.2 三阶段流程

**阶段一：WSI 切块与初始描述生成（Encoding）**
- 将 ROI 划分为 N×N 的非重叠切块网格。
- 每个切块独立送入 MLLM，生成初始描述 $d_i^{(0)}$，仅反映该切块的局部证据，不包含邻域信息。
- 支持通用型和病理专用型 MLLM 骨干。

**阶段二：空间语言消息传递（Spatial Language Message Passing）**
- 构建空间文本图 $G=(V, E)$，边编码 4-连通邻接。
- 对中心节点 $v_c$，LLM 在共享提示 $p$ 的控制下，整合中心描述与四个邻居描述，生成更新后的描述：

$$d_c^{(t+1)} = \text{LLM}_p\left(d_c^{(t)}, d_{top}^{(t)}, d_{bot}^{(t)}, d_{left}^{(t)}, d_{right}^{(t)}\right)$$

- 边界切块只使用 2–3 个可用邻居，同一提示处理，边界处理规则本身也是优化对象。
- LLM 作为生成式局部算子，进行：权衡重复证据、抑制孤立离群值、调和矛盾邻居信号、重写中心描述以捕捉跨切块形态（如间质浸润前沿、腺体连续性、核多形性）。

**阶段三：通过文本梯度进行提示优化（Prompt Optimization）**
- 所有模型权重冻结，仅优化控制聚合策略的提示 $p$。
- 目标函数：

$$p^* = \arg\min_p \;\mathcal{L}(p), \quad \mathcal{L}(p) = \sum_{i \in T} \text{Eval}\left(d_i^{(1)}(p), \mathcal{N}_i, y_i\right)$$

- 使用 **TextGrad** 框架：由 LLM 生成的文本反馈作为类梯度信号，反向传播经过管线优化提示。
- 前向传播被分类为命名类别：`no passing`（无邻居证据）、`helpful context`、`confirmation`、`hallucination`、`wrong neighbor focus`、`over-interpretation`、`under-interpretation`。
- 错误归因策略将错误分为：**策略错误**（编码规则错误）、**措辞错误**（歧义措辞导致误解）、**边界情况缺口**（提示缺乏对稀有输入类型覆盖），每种触发针对性的修订（更明确的规则、改写措辞、加入特定病学术语）。
- 由于所有评估结果和错误归因都是离散、命名的类别，**每次优化步骤都有可审计的理由**——可读取为什么做出某个提示修订，以及策略如何跨迭代演化。

### 6. 论文的主要结论与发现

1. **空间语言消息传递有效**：在所有 8 组模型-数据集配置上，SLMP 均提升了切块级肿瘤分类准确率，增益 +3.3 到 +19.6 个百分点。C16 上增益最大（Patho-R1 提升最多，+19.64 pp）。
2. **增益源于空间上下文而非额外文本**：随机邻居替换后，准确率显著下降（C16 上甚至低于无消息传递基线 0.6250 vs. 0.7358），证实真实空间邻接关系是关键。

4. **组织特异策略自动涌现**：从相同的初始提示出发，HER2 和 C16 优化收敛到不同的病理词汇和决策规则——HER2 策略关注梭形细胞形态、双相模式；C16 策略强调重复证据阈值、上皮/腺体结构覆盖淋巴样外观。
5. **缩小通用与专用模型差距**：无需权重更新，SLMP 显著提升通用 GPT-4.1 的性能，缩小了与病理专用模型的差距。
6. **空间推理可审计**：优化后的提示可直接阅读，揭示组织特异的决策规则；错误归因过程可追溯。

### 7. 优点

- **创新性强**：将空间推理从数值特征空间迁移到语言空间，利用 LLM 的生成能力实现可读的邻域信息聚合，这一思路具有新颖性。
- **无需微调、成本低**：所有 MLLM 权重冻结，仅优化一个提示，轻量高效。
- **天然可解释**：中间状态（切块描述、消息、聚合策略）全部为自然语言，空间推理过程“构建即可检查”（inspectable by construction），而非从事后 saliency map 或注意力权重中恢复——对病理医生而言这是重要的信任基础。
- **自动化语义优化**：通过 TextGrad 的文本梯度，从局部细胞上下文到更广泛组织形态的语义优化是自动完成的，且优化轨迹每个步骤都有审计理由。
- **消融设计严谨**：随机邻居消融和提示消融设计合理，清晰分离了空间上下文和提示优化两个因素的各自贡献。
- **骨干模型覆盖广**：涵盖通用/专用、不同规模的 4 种 MLLM，结论的普适性更强。

### 8. 不足与局限

- **实验范围有限**：仅评估了选定的 ROI 区域（7×7 网格），而非完整 WSI；ROI 选择本身可能引入选择偏差（都包含肿瘤和正常组织，但未披露具体的组织学类型分布）。
- **单轮消息传递**：仅执行 T=1 的消息传递轮次，未探索多轮传播的累积效应和潜在收益。
- **计算开销未摊销**：与基于嵌入的池化方法不同，每轮消息传递需要每切块一次额外的生成式 LLM 调用，计算成本线性增长且不可摊销。
- **优化区域数量极少**：提示优化仅使用 5 个（HER2）和 7 个（C16）区域，优化统计功效有限，存在过拟合风险。
