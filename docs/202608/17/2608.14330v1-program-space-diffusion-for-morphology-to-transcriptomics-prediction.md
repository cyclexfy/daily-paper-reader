## 摘要
空间转录组学（ST）能够在保留组织架构的同时实现全基因组基因表达谱分析，但其成本和有限的可扩展性仍是主要瓶颈。这促使了直接从常规组织学图像预测空间表达的模型的发展。尽管结果令人鼓舞，但大多数现有方法在基因水平上运作，未利用既定的转录组建模实践，并依赖异质的基因选择策略，这使不同方法之间的公平比较变得复杂。我们提出将形态学到转录组学的预测重新表述为转录程序空间中的条件生成，从而利用协调的转录变异而非独立预测基因。通过共识非负矩阵分解（cNMF），我们提取一组低维转录程序，捕获训练数据中的协调表达变异，并训练条件扩散模型从组织学图像生成程序激活。这一表述利用了协调的转录变异，并显著降低了条件生成任务的维度。

## Abstract
Spatial transcriptomics (ST) enables genome-wide gene expression profiling while preserving tissue architecture, but its cost and limited scalability remain major bottlenecks. This has motivated models that predict spatial expression directly from routine histology. Despite promising results, most existing approaches operate at the gene level without leveraging established transcriptomic modeling practices and rely on heterogeneous gene selection strategies, which complicates fair comparison across methods.   We propose to reformulate morphology-to-transcriptomics prediction as conditional generation in transcriptional program space, thereby exploiting coordinated transcriptional variation instead of predicting genes independently. Using consensus non-negative matrix factorization (cNMF), we extract a low-dimensional set of transcriptional programs capturing coordinated expression variation in the training data, and train a conditional diffusion model to generate program activations from histology. This formulation exploits coordinated transcriptional variation and substantially lowers the dimensionality of the conditional generative task.

- **整体含义**：本文主张将预测任务从“基因空间”重构到“转录程序空间”，在低维结构化的程序激活中做条件生成，从而同时提升预测的生物学一致性和计算可扩展性。

## 2. 论文提出的方法论

### 2.1 核心思想

- 使用**共识非负矩阵分解（cNMF）** 从训练数据中提取 K 个低维转录程序（transcriptional programs），捕获基因间的协调表达变异。
- 训练**条件扩散模型**在程序激活空间（而非基因空间）中生成表达，显著降低条件生成任务的维度（K ≪ G）。
- 将基因表达重构为程序激活与固定共识基底的线性组合。

### 2.2 关键技术细节

**（1）Shifted Pearson 残差归一化**

- 采用基于负二项（NB）计数模型的 Pearson 残差来归一化原始 UMI 计数，显式考虑测序深度和均值-方差关系；
- 公式为：
  - R_ij = (X_ij − μ_ij) / √(μ_ij + μ_ij²/θ)，其中 μ_ij = n_i · p_j；
- 残差被裁剪到 [−c, c]，然后通过全局平移使其非负：X̃ = R − min(R) + ε；
- 超参数：θ = 100，c = 10，ε = 10⁻⁶。

**（2）共识 NMF（cNMF）**

- 在每一折训练数据上执行 R = 20 次独立 NMF（NNDSVDa 初始化，坐标下降，Frobenius 目标）；
- 将 20 次运行的基因载荷矩阵堆叠后进行 K-means 聚类（K 簇），簇内平均得到共识基底 W*；
- 通过非负最小二乘（NNLS）将每个 spot 投影到共识基底上，得到激活系数 H；
- K 的选择：在 K ∈ {10, 20, 40, 60, 100} 中权衡后选择 **K = 20**，兼顾重构保真度、激活稀疏性和目标维度。

**（3）程序空间条件扩散**

- 采用 DDPM 框架，ε-预测目标；
- 扩散过程在 R^K 中运行，而非 R^G；
- 前向过程：h^(t) = √ᾱ_t · h^(0) + √(1−ᾱ_t) · ε；
- 训练损失：L_diff = E[‖ε − ε_θ(h^(t), I, t)‖²]；
- 推理时通过 1000 步反向去噪，从高斯噪声生成程序激活，再通过 X̂ = ĥ·W* 重构基因表达。

1. **归一化是预测性能的一阶决定因素**：STEM 在 log 归一化下表现优于 Pearson 残差归一化（Top-M PCC 更高），但这可能部分反映了 log 变换中保留的测序深度/细胞丰度信号；采用 Pearson 残差可以更公平地评估模型能力。
2. **在固定 Pearson 归一化下，程序空间扩散优于基因空间扩散**：Ours 在几乎所有 Top-M 阈值下均一致优于 STEM 基因空间基线（如 Top-10: 47.7% vs 46.5%；Top-2000: 5.4% vs 4.8%），但提升幅度属于“modest but consistent”。
3. **更大的基因面板改善预测质量**：从 G=300 到 G=2000，Top-50 PCC 分布显著右移，且对基因空间和程序空间方法均成立。
4. **程序空间扩散具有显著的计算优势**：预测维度恒定（K=20），训练和采样时间几乎不随 G 变化；而基因空间在 G=2000 时采样 1000 步需要约 36 分钟，程序空间仅需约 4.4 秒。
5. **cNMF Oracle 分析表明**：当前预测瓶颈主要在于从组织学预测程序激活，而非基底表示能力不足（Oracle Top-10 为 75.1% vs 模型 47.7%）。
