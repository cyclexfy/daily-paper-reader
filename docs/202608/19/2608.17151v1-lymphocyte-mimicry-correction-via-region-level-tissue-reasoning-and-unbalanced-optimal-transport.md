## 摘要
细胞拟态是指不同细胞类型在形态上表现相似的现象。人类病理学家利用周围组织背景来消除这种歧义，而当前的视觉模型要么缺乏背景推理能力（如细胞基础模型），要么无法在细胞水平上操作（如病理多模态大语言模型）。我们提出了Loki-OT，它通过非平衡最优传输将区域级组织推理传播到单个细胞预测，利用基于多模态大语言模型（MLLM）的密度先验作为模糊细胞重新分配的软指导。Loki-OT的动机在于观察到预训练的细胞基础模型特征已经编码了判别性信息，包括组织背景，但标准的细胞级监督未能有效利用组织背景。生成的传输计划被蒸馏进一个轻量级的学生MLP分类器，该分类器在预训练特征空间中学习上下文感知的决策边界。在独立的TCGA-BRCA队列上，Loki-OT比完全监督的域内PanopTILs分类器实现了更低的患者级别MAE，并在上皮丰富的拟态组织中提高了F1分数，仅使用了基于通用领域细胞基础模型构建的278个弱区域级MLLM估计。代码：https://github.com/xiangli980/Lymphocyte_Mimicry_Correction_via_Loki_OT

## Abstract
Cell mimicry arises when different cell types appear morphologically similar. Human pathologists resolve this ambiguity using surrounding tissue context, whereas current vision models either lack contextual reasoning (cell foundation models) or cannot operate at the cell level (pathology MLLMs). We present Loki-OT, which propagates region-level tissue reasoning to individual cell predictions via Unbalanced Optimal Transport, using MLLM-derived density priors as soft guidance for ambiguous cell reassignment. Loki-OT is motivated by the observation that pretrained cell foundation model features already encode discriminative information, including tissue context, but standard cell-level supervision fails to use tissue context effectively. The resulting transport plan is distilled into a lightweight student MLP classifier that learns context-aware decision boundaries within the pretrained feature space. On the independent TCGA-BRCA cohort, Loki-OT achieved lower patient-level MAE than the fully supervised in-domain PanopTILs classifier and improved F1 in epithelium-rich mimicry tissues, using 278 weak region-level MLLM estimates built on a general-domain cell foundation model. ## 1. 论文的核心问题与整体含义

- **背景**：肿瘤浸润淋巴细胞（TILs）是多种癌症的重要预后和预测生物标志物，但在 H&E 染色组织上进行准确量化非常困难。不同细胞类型（如淋巴细胞与非淋巴细胞）在形态上可能非常相似，导致自动分类系统产生系统性高估，这一现象被称为**细胞拟态**（cell mimicry）。
- **现有方法的不足**：
  - 细胞分割/分类模型（如 HoVer-Net、CellViT）依赖局部细胞形态，缺乏组织背景推理能力；
  - 图模型或细胞-组织联合架构（如 OCELOT）虽引入上下文，但仍需要密集的细胞级标注；
  - 病理多模态大语言模型（MLLM）能进行区域级组织推理，却无法直接对单个细胞进行分类。
- **核心问题**：如何将区域级的生物学推理（如“上皮丰富区域淋巴细胞通常稀少”）传播到细胞级预测，从而在不依赖密集细胞级标注的情况下纠正细胞拟态造成的误分类？
- **整体含义**：本文提出一种跨尺度框架 Loki-OT，利用 MLLM 提供的弱区域级密度先验，通过非平衡最优传输（UOT）对细胞预测进行重新分配，并将结果蒸馏为轻量级分类器。实验表明，仅使用弱监督信息即可在患者级 MAE 上胜过完全监督的域内模型，说明区域级生物学先验可以有效补充甚至替代部分密集细胞标注。

## 2. 论文提出的方法论

### 核心思想
- 利用预训练细胞基础模型（CellViT++，SAM-H 骨干）提取的细胞特征中已隐含的组织背景信息，但标准细胞级监督未能充分利用这些信息。
- 将 MLLM 估计的区域淋巴细胞密度作为软生物学约束，通过 UOT 将区域级推理传播到细胞级标签，最后将 UOT 生成的软标签蒸馏进一个轻量级 MLP 分类器。

### 关键技术细节
1. **细胞表示编码**：
   - 对每个细胞 \( i \) 提取形态嵌入 \( z_i \)（最后一层 ViT token，维度 D=1280）和上下文嵌入 \( c_i \)（以该细胞为中心的 ±5 token 窗口内所有细胞特征的平均池化）。
   - 将 \([z_i; c_i]\) 拼接作为上下文增强特征；基线预测 \( a_i \)（淋巴细胞 vs 非淋巴球的概率）作为感知先验。

2. **MLLM 知识先验**：
   - 对每个（ROI，组织亚型）区域，向通用 MLLM（Claude Sonnet 4.5）查询淋巴细胞密度估计 \( b \in \Delta^K \)。
   - 使用结构化提示（包含组织类型、掩码轮廓、JSON 输出要求），仅训练阶段使用，推理时不需要 MLLM。

3. **非平衡最优传输（UOT）**：
   - 代价矩阵 \( C_{ik} = \text{Cost}^{\text{percept}}(i,k) + \text{Cost}^{\text{logic}}(i,k) \)。
   - 感知代价：\( 1 - a_{i,k} \)，保留高置信预测。
   - 逻辑代价（仅在上皮丰富组织 T1/T3/T4 中）：\( \text{ReLU}(s_i)^2 \)，其中 \( s_i = \cos(z_i, c_i) \) 表示细胞与周围环境的相似度；相似度高则增加判为淋巴细胞的代价。
   - UOT 优化目标：\( \min_{\pi \ge 0} \langle C,\pi \rangle - \epsilon H(\pi) + \tau KL(\pi\mathbf{1}\|u) + \rho KL(\pi^\top \mathbf{1}\|b) \)。
   - 熵正则化保证 Sinkhorn 高效求解；KL 惩罚允许对 MLLM 先验和均匀源分布的偏差（\( \tau=\rho=3.0, \epsilon=0.1 \)）。

4. **两阶段训练策略**（课程学习）：
   - **阶段1（区域比例监督）**：将区域平均预测 \( \bar{f}_\theta \) 拉向 MLLM 密度 \( b \)，仅当基线淋巴细胞密度超出 MLLM 估计 ≥10%（\( \Delta \ge 10\% \)）时使用单侧 hinge 损失抑制过预测；否则用 KL 保持基线预测（自蒸馏）。
   - **阶段2（UOT 教师蒸馏）**：以 UOT 传输计划 \( \pi_i \) 作为软教师目标，结合温度软化 KL（T=4）和硬标签交叉熵锚定（防止概率坍缩）。仅在 \( \Delta \ge 10\% \) 的区域使用 UOT 目标，否则回退到阶段1预测。

### 算法流程（文字说明）
1. 用冻结的 CellViT++ 提取每个细胞的形态特征和上下文特征，并获取基线分类概率。
2. 对每个组织区域，用 MLLM 获得淋巴细胞密度先验。
3. 若基线密度显著高于 MLLM 先验（≥10%），则构建代价矩阵并求解 UOT，得到软传输计划；否则保持基线自蒸馏。
4. 先以区域比例监督训练 MLP（阶段1），再以 UOT 软标签蒸馏（阶段2）。
5. 推理时仅运行蒸馏后的轻量级 MLP，无需 MLLM 或 OT 计算。

## 3. 实验设计

### 数据集
- **训练集**：TIGER 挑战数据集，135 个 ROI（1024×1024 像素，约 80K 细胞核，278 个 (ROI, 组织亚型) 区域），来自 2 家医院。
- **测试集**：TIGER 的 TCGA-BRCA 子集（1,741 个 ROI，中位 143×143 像素，64K 细胞核，124 位患者），与训练集无医院重叠。
- 训练集以 T1（浸润性肿瘤）为主，测试集以 T6（炎性间质）为主，存在组织构成偏移；但组织内淋巴密度大致可比。
- MLLM 先验：Claude Sonnet 4.5，训练集上 Pearson r=0.58，MAE=11.7%，偏差 +6.6%（相比 GT），方向性优于 Lizard。

### 对比方法
- **Lizard**：基于大规模结直肠癌细胞标签训练的 MLP，零样本应用于乳腺。
- **PanopTILs**：在 800K 域内 TCGA-BRCA 细胞级标注上重新训练的 MLP（完全监督、域内）。
- **Context-soft**：仅阶段1区域比例监督（作为阶段1消融和独立方法）。
- **OT/UOT-Teacher**：平衡/非平衡 OT 求解器输出（仅教师，不可部署）。
- **Loki-OT**：两阶段课程蒸馏后的最终可部署模型。

- 患者级：先累计每个患者的 ROI 预测/真值淋巴细胞计数，再计算绝对差值平均（MAE）。
- 消融额外指标：选择性 = FP下降百分比 / TP下降百分比。

## 6. 论文的主要结论与发现

- 粗粒度、不完美的 MLLM 区域密度先验足以纠正细胞级系统性过度计数，优于零样本 Lizard，并进一步改善患者级 MAE。
- Loki-OT 在 TCGA-BRCA 上，使用弱区域级 MLLM 估计（278 个）取得的患者级 MAE 显著低于完全监督的域内 PanopTILs 模型（MAE 46.0 vs 58.3，p=0.031），F1 也更高（0.543 vs 0.474，p<0.001）。
- UOT 蒸馏带来的是一种“定向权衡”：牺牲部分召回（抑制了一些真阳性）以换取精度和 MAE 的大幅提升；在上皮丰富组织（T1、T3、T4）中 MAE 改善最明显。
- PanopTILs 因训练分布偏向上皮组织，在淋巴细胞丰富的 T6 炎性间质中系统性欠预测，导致患者级 MAE 较高。
- 两阶段训练分别处理不同难度的拟态：阶段1去除容易的假阳性，阶段2通过 UOT 实现更难的、依赖上下文的拟态纠正；Loki-OT 的选择性优于纯 UOT-Teacher，且 TP 损失更低。
- 注意力分析显示 Loki-OT 将模型注意力从细胞核转向周围组织，证明学生分类器确实学到了上下文感知决策。

## 7. 优点

- **新颖性**：首次将区域级 MLLM 推理与细胞级预测通过 UOT 结合，解决跨尺度标签传播问题。
- **实用性**：训练时仅需弱区域级估计（每 ROI 一条文本查询），推理时只需轻量 MLP，不增加临床部署开销。
- **理论工具选择恰当**：UOT 的 KL 惩罚天然适应 MLLM 先验的不确定性，比平衡 OT 更稳健。
- **训练技巧严谨**：两阶段课程学习、选择性蒸馏阈值（基于 MLLM 误差 11.7% 设定）、软/硬标签混合损失等设计均有明确动机。
- **评估规范**：使用患者级 MAE（临床决策单位）、Bootstrap 置信区间、非参数统计检验，并公开代码。
- **上下文特征利用充分**：通过细胞特征与其邻域平均特征的余弦相似度编码组织环境，实现了无需显式组织分割的上下文感知。

## 8. 不足与局限

- **泛化性有限**：仅在乳腺癌 TIL 量化单一队列（TCGA-BRCA）上验证，未覆盖其他癌种、细胞类型或染色差异。
- **依赖 MLLM 质量**：MLLM 先验存在较大误差（MAE 11.7%、正偏差 6.6%），若 MLLM 方向性错误（如系统性低估）则矫正机制可能失效；且仅测试了一种 MLLM（Claude Sonnet 4.5）和一种提示模板。
- **不对称纠偏**：方法只抑制过度预测（通过 \( \Delta \ge 10\% \) 触发），无法处理基线欠预测的情况；当基线与 MLLM 先验一致但都错误时无法纠正。
- **性能权衡**：Loki-OT 相比 Context-soft 降低了召回率，可能漏掉部分真淋巴细胞；患者级 MAE 的改善部分来源于牺牲 T6 区域的召回（尽管仍优于 PanopTILs）。
- **消融局限**：OT/UOT-Teacher 仅能在训练集上评估（不可部署），测试集上缺乏教师输出的直接对比；训练集与测试集的组织构成差异使消融结论的推广性有限。
- **细节缺失**：未说明具体 GPU 资源与训练时间；MLLM 查询成本（每区域一次）未提及；实验中未进行多次随机种子或交叉验证以评估稳定性。
