## 摘要
肿瘤进展伴随结构、形态和微环境组织的变化，然而与进展相关的异质性在组织病理学中通常被压缩为静态的诊断类别。在此，我们提出了SpaTIE，一个子宫特异性计算病理学框架，它学习形态学感知的表征，并将空间组织病理学异质性组织为与进展相关的肿瘤状态。SpaTIE使用10,426张子宫苏木精-伊红全切片图像开发，并在TCGA-UCEC和TCGA-UCS队列中进行评估。学习到的表征形成了形态流形，支持诊断、分子和生存相关的预测任务，并将注意力定位到信息丰富的肿瘤区域。在监督预测之外，SpaTIE在没有时间或分子监督的情况下从横断面形态推断出肿瘤状态轴。这些形态衍生的状态在空间上具有连贯性，并显示与临床病理变量和生存结果的关联，同时并未简单地重现分期或诊断标签。整合性多组学分析将推断出的状态与DNA甲基化、体细胞拷贝数变异、突变、RNA-seq和RPPA谱联系起来，突出了与染色质调控、拷贝数相关结构变异、受体酪氨酸激酶信号传导、细胞粘附、细胞外基质重塑和代谢适应相关的分子程序。进展引导的虚拟扰动进一步优先考虑了与形态衍生状态组织耦合的分子特征。总之，这些发现表明子宫组织病理学包含可恢复的、与进展相关的肿瘤状态信息，并将SpaTIE确立为一个将空间形态与多组学信息化的肿瘤状态发现联系起来的框架。

## Abstract
Tumor progression is accompanied by changes in architecture, morphology and microenvironmental organization, yet progression-associated heterogeneity is usually compressed into static diagnostic categories in histopathology. Here we present SpaTIE, a uterus-specific computational pathology framework that learns morphology-aware representations and organizes spatial histopathological heterogeneity into progression-associated tumor states. SpaTIE was developed using 10,426 uterine hematoxylin and eosin whole-slide images and evaluated in TCGA-UCEC and TCGA-UCS cohorts. The learned representations formed morphology manifolds, supported diagnostic, molecular and survival-related prediction tasks, and localized attention to informative tumor regions. Beyond supervised prediction, SpaTIE inferred tumor-state axes from cross-sectional morphology without temporal or molecular supervision. These morphology-derived states were spatially coherent and showed associations with clinicopathological variables and survival outcomes, while not simply recapitulating staging or diagnostic labels. Integrative multi-omics analyses linked the inferred states to DNA methylation, somatic copy-number variation, mutation, RNA-seq and RPPA profiles, highlighting molecular programs related to chromatin regulation, copy-number-associated structural variation, receptor tyrosine kinase signaling, cell adhesion, extracellular-matrix remodeling and metabolic adaptation. Progression-guided virtual perturbation further prioritized molecular features coupled to the morphology-derived state organization. Together, these findings suggest that uterine histopathology contains recoverable progression-associated tumor-state information and establish SpaTIE as a framework for connecting spatial morphology with multi-omics-informed tumor-state discovery.

## 2. 论文提出的方法论

### 2.1 核心思想

- 将每个 WSI 视为**空间上多个共存肿瘤状态的混合**（而非一个同质疾病类别），局部组织学观测由潜在进展状态和患者特异性噪声共同生成。
- 形式上假设生成过程：x = g(t, ε)，其中 t 是潜在进展状态，ε 是噪声；观测分布为 p(x) = ∫p(x|t)p(t)dt。
- 利用自监督表征学习构建形态感知的嵌入空间，再通过图/扩散方法进行轨迹推断，从横断面形态中组织出连续的肿瘤状态轴。

### 2.2 关键技术细节

1. **预训练数据（PK3-Uter）**：收集北京大学第三医院 10,426 张子宫 H&E WSI，扫描于 80× 放大（0.105 μm/pixel），提取 20× 下的 224×224 非重叠 patch；经过肿瘤区域分类器过滤后，从约 6200 万 patch 中保留约 2400 万肿瘤富集 patch 用于自监督预训练。

2. **子宫特异性表征学习**：以通用病理基础模型 UNI（ViT-L/16，~303M 参数，基于 DINOv2 预训练）初始化，采用 **LoRA（低秩适配，rank r ≪ min(m,n)）** 仅在 transformer 注意力层的 query 和 value 投影上插入可训练低秩矩阵（W = W₀ + BA），其余参数冻结。训练目标为 **DINOv2 自监督目标**（DINO 图像级自蒸馏 + iBOT 掩码 patch 级重构 + KoLeo 均匀性损失），AdamW 优化器，学习率 1e-4，共 50 epochs。每个 patch 取最后一层 CLS token 嵌入（d = 1024）作为特征。

3. **Slide 级聚合**：注意力池化（ABMIL 方式），aᵢ = softmax(wᵀ tanh(Vzᵢᵀ))，slide 表征 Z = Σaᵢzᵢ。

4. **潜在进展状态推断**：
   - 对 slide 级特征做 PCA（保留 90% 方差），构建 KNN 图（k=10），高斯相似度核 Kᵢⱼ = exp(−‖zᵢ−zⱼ‖²/σ²)，并应用 Leiden 聚类和 PAGA。
   - 用**扩散伪时间（DPT）**从根样本出发计算 diffusion distance，得到连续状态值 tᵢ。
   - Patch 级状态通过邻域插值映射回 WSI 坐标，生成空间状态热图。
   - 强调：推断的轴是形态衍生的状态组织，**不是时间线或因果演化路径**。

5. **虚拟扰动分析**：对每个分子特征计算 KO 分数 = |ρ(t, g)| − |ρ(t_perturbed, g)|，衡量移除该特征关联成分后特征-状态关联的衰减程度，用于分子特征优先排序，而非因果验证。

## 6. 论文的主要结论与发现

1. **子宫特异性表征学习有效**：SpaTIE 在 MSQ（UCEC 45.833 / UCS 35.225）和 RE（3.958 / 3.910）指标上优于 UPFM 和 Baseline，UMAP 显示更细粒度的形态流形结构；在大多数下游任务上达到或超过 UPFM 性能。

2. **可从静态病理中恢复进展相关状态**：SpaTIE 推断的状态轴具有高稳定性（STAB 0.997/0.994）和空间一致性（SPA 0.919/0.893），状态轴是空间上连贯的、与组织形态相关的组织，而非降维伪影。

3. **状态轴的临床相关性**：UCEC 中状态值与 FIGO 分期（p=1.54×10⁻³）、FGA（ρ=−0.181, p=1.76×10⁻⁵）、肿瘤分级（p=1.14×10⁻⁷）、肿瘤侵袭百分比（ρ=−0.225, p=3.98×10⁻⁷）显著相关；UCS 中与 FGA 正相关（ρ=0.219, p=3.77×10⁻²）；在 FIGO IV、高 FGA 等亚组中显示生存分层。但状态轴并未简单复现诊断标签。

4. **状态轴具有多组学分子背景**：通路水平上，UCEC 中 PRC2/Polycomb 甲基化、MMR-SCNV、AKT-mTOR RPPA 信号有差异；UCS 中 RNA-seq 雌激素反应通路显著差异；特征水平上，UCEC 甲基化/SCNV/RPPA 层有 FDR 支持的关联。

5. **虚拟扰动识别候选分子程序**：UCEC 中优先了 PRR22（甲基化）、GPR84（突变）、FAM81A（SCNV）、RAB27B（RNA-seq）、AXL（RPPA）；UCS 中优先了 PIK3C2G、TPTE、16q23.1、UFD1L、ARHI 等。这些指向染色质调控、拷贝数结构变异、RTK/ EMT 信号、细胞粘附、ECM 重塑和代谢适应等生物主题。

## 7. 优点

- **概念创新强**：将单细胞轨迹推断思想系统性地迁移到组织病理学，并明确区分"形态衍生的状态组织"与"时间演化"，概念上严谨且可推广到其他癌种。
- **方法设计务实**：
  - 使用 LoRA 参数高效微调，在保留通用病理知识的同时实现器官特异性适配，计算资源友好；
  - 肿瘤聚焦 patch 提取显著提升预训练数据的信号-噪声比（6200万→2400万）；
  - 引入了多种无监督质量指标（MSQ、RE、STAB、SPA、FS）来量化表征与状态质量，使评估更加立体。
- **实验体系完整**：从静态表征质量到下游任务性能，再到状态推断、临床关联、生存分析、多组学整合和扰动分析，形成了"表征学习 → 状态推断 → 分子情境化"的完整链路。
- **公平性较好**：与 UPFM 和 Baseline 使用完全相同的下游管道和划分策略；按患者划分避免数据泄漏。
- **解释谨慎合理**：反复强调推断状态不是时间线、虚拟扰动不是因果证据，UCS 结果定位为探索性，避免过度声称。

## 8. 不足与局限

- **无法重建真实进化历史**：基于横断面 H&E 图像的状态轴无法确定肿瘤的时间演化顺序、克隆谱系或分支进展路径，需要纵向采样或多区域测序加以验证。
- **TCGA-UCS 样本量过小**（91 张 WSI）：多个生存亚组分析（n≈16-79）、多组学特征关联和 UCS 虚拟扰动结果的 FDR 支持不足，统计功效有限，结论泛化性受限。
- **bulk omics 的空间错配**：多组学数据是组织整体测量，无法将分子程序精确分配到驱动状态轴的空间区域；需要空间转录组、多重免疫组化或空间蛋白组学进一步验证。
- **虚拟扰动是计算推断**：KO 分数只是关联衰减的排名统计量，不等同于基因敲除实验或因果证据；需湿实验室（CRISPR、类器官、细胞系）验证。
- **外部验证不足**：PK3-Uter 为私有数据，且评估仅在 TCGA 两个队列上完成；缺少跨机构、跨扫描仪、跨染色协议的独立多中心验证。
- **基线对比有限**：仅与 UNI（UPFM）一种通用病理基础模型比较，未与 Virchow、Prov-GigaPath 等 SOTA 病理基础模型进行系统benchmark。
- **特征级转录组/突变结果较弱**：UCEC 中 RNA-seq 和突变层未达到 FDR 显著性，论文自身也承认这些结果应谨慎解释。
