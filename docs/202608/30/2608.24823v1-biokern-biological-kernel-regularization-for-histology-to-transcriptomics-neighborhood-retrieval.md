## 摘要
空间解析生物学需要保留生物邻域结构而非仅精确跨模态对应的表示。现有的组织学-转录组目标可能强调实例级匹配，即使非配对点共享分子或空间背景。我们引入了BioKERN，一种多模态空间表示学习框架，将生物结构作为显式、可学习的归纳偏置。BioKERN通过结合转录组相似性和空间邻近性构建训练时生物核，然后利用它提供分级邻域监督并正则化嵌入几何。评估使用所有方法共享的固定、模型无关的生物邻域定义。在小鼠脑Visium和人肝GSE240429上，BioKERN在单尺度和多尺度设置中均持续改善了BLEEP的生物邻域检索。受控共享架构实验表明，大部分改进来自生物核正则化而非模型容量增加。这些结果支持显式生物几何作为空间生物学多模态学习的可解释归纳偏置。

## Abstract
Spatially resolved biology requires representations that preserve biological neighborhood structure rather than only exact cross-modal correspondences. Existing histology--transcriptomics objectives can emphasize instance-level matching even when non-paired spots share molecular or spatial context. We introduce BioKERN, a multimodal spatial representation-learning framework that incorporates biological structure as an explicit, learnable inductive bias. BioKERN constructs a training-time biological kernel by combining transcriptomic similarity and spatial proximity, then uses it to provide graded neighborhood supervision and regularize embedding geometry. Evaluation uses a fixed, model-independent biological neighborhood definition shared by all methods. Across Mouse Brain Visium and Human Liver GSE240429, BioKERN consistently improves biological-neighborhood retrieval over BLEEP in both single- and multi-scale settings. Controlled shared-architecture experiments show that most of the improvement arises from biological-kernel regularization rather than increased model capacity. These results support explicit biological geometry as an interpretable inductive bias for multimodal learning in spatial biology.

## 1. 论文的核心问题与整体含义

**研究动机**：空间转录组学（Spatial Transcriptomics）测量基因表达的同时保留了组织空间位置信息，而 H&E 组织学图像是更易获取的形态学互补视图。该领域的关键多模态学习问题是：给定一个新的 H&E 图像块，从已测序的参考组织中检索对应相同生物学背景的转录组谱。

**核心问题**：现有方法（如 BLEEP）主要依赖精确的实例级匹配（image-spot 一一对应），但忽略了空间组织中更广泛的生物学邻域结构——空间相邻的点、同一组织域内的点、或转录程序相似的点，即使不是同一测量位置，也代表相关的生物学状态。仅针对实例身份优化的表示会低估这种生物学上有意义的邻域结构。

**整体含义**：论文主张在跨模态表示学习中引入**显式的、可学习的生物学几何先验**，使表示不仅保留精确跨模态对应关系，还能保留生物邻域结构，从而提升"生物邻域检索"（Biological Neighborhood Retrieval, BNR）能力。

## 2. 论文提出的方法论

### 核心思想

BioKERN（Biological Kernel Regularization）的核心思想是：在训练阶段构建一个融合**转录组相似性**和**空间邻近性**的"生物参考核"（biological reference kernel），用该核提供**分级邻域监督**（graded neighborhood supervision），并正则化嵌入几何，使 H&E 图像嵌入与转录组嵌入共享的表示空间保留生物学邻域结构。

### 技术细节

1. **多模态表示学习**：
   - 图像使用冻结的 PLIP 病理学编码器提取特征（512 维），基因表达经归一化、log1p 变换、高变基因筛选、标准化和 PCA 降维至 128 维。
   - 轻量 ResidualAdapter（线性投影 + 两层 GELU MLP + 可学习残差缩放）将两种模态投影到共享的 ℓ2 归一化 128 维空间。
   - 支持单尺度（96×96 图像块）和多尺度（96×96 + 224×224，可学习融合权重）两种图像上下文设置。

2. **可学习生物参考核**：
   - 定义转录组 RBF 核 Kgene 和空间 RBF 核 Kspat，带宽由训练集配对距离的中位数启发式确定。
   - 核心创新：通过可学习标量 α = σ(a) 融合两种信号：**K⋆ = αKgene + (1−α)Kspat**。
   - 多切片训练时，跨切片的 Kspat 置零，仅同一切片内计算空间亲和度。

3. **生物邻域监督（三种损失）**：
   - **Soft neighborhood loss（Lsoft）**：对每个锚点，选取 mini-batch 内 K⋆ 下 top-k（k=20）非自身邻居，将核亲和度归一化为分级目标，提供超越精确配对的邻域监督（排除精确配对点）。
   - **Global kernel alignment（Lglob）**：匹配融合实体表征 ze 的核 KZ 与参考核 K⋆ 的整体几何（Frobenius 范数）。
   - **Local kernel alignment（Lloc）**：仅聚焦最强生物邻域边上的局部几何匹配。
   - 完整损失：**L = Lret + λsLsoft + λgLglob + λℓLloc**，权重分别为 0.3、0.1、0.5；Lret 为双向 InfoNCE 精确匹配损失。

4. **推理**：生物核仅在训练时使用；推理时直接以余弦相似度对 H&E 查询与参考转录组嵌入进行排序。

## 6. 论文的主要结论与发现

1. **BioKERN 显著改善生物邻域检索**：在两个数据集、两种尺度设置下，Bio-mAP 全面优于所有基线。例如 Mouse Brain SS 从 BLEEP 的 0.5087 提升至 0.6190，MS 从 0.4960 提升至 0.6716。
2. **改进主要来自生物正则化而非架构**：顺序效应分解显示，生物正则化步骤贡献了总改进的约 63%–91%（各设置具体为：脑 SS 74.9%、脑 MS 63.4%、肝 SS 88.3%、肝 MS 90.6%）。
3. **分级邻域监督是最强组件**：消融显示去掉 Lsoft 导致的性能下降最大，而 Lglob 的贡献相对较小（部分设置下去掉几乎无影响）。
4. **分子-空间权重具有组织类型特异性**：Human Liver 学习到的 α 比 Mouse Brain 更偏重转录组相似性，且该权重对初始化不敏感，收敛稳定。
5. **打乱核对照验证生物学结构的重要性**：随机置换核严重破坏性能（接近或低于 Ret-only），说明有意义的生物配对结构才是关键。
6. **学习 α 不是主要增益来源**：固定 α=0.5 与学习 α 的性能几乎持平，表明主要收益来自生物邻域监督本身，α 提供的是可解释的、稳定的权重摘要。

## 7. 优点

- **显式生物归纳偏置**：将生物学知识（转录组相似性 + 空间邻近性）以核形式显式注入训练过程，比单纯依赖隐式学习更可解释、更可控。
- **可学习的融合权重**：α 通过 sigmoid 参数化端到端学习，可在不同组织类型间自适应调整分子/空间信号的相对重要性，且收敛稳定、可解释。
- **严谨的控制实验设计**：通过共享骨干（BLEEP\*）、目标函数隔离（Ret-only）、打乱核（Shuffled Kernel）、固定 α 等多个内部对照，系统性地隔离了架构、目标和生物先验各自的贡献，论证力度强。
- **评估公平性**：固定、模型无关的评估核 Keval 对所有方法一致；精确配对从生物阳性集中排除；基因预处理仅在训练集拟合；5 个随机种子报告均值±标准差。
- **实用性好**：生物核仅用于训练监督，推理时仅需余弦相似度检索，无额外推理开销；脑/肝两组数据集的结果具有一定的跨组织验证价值。

## 8. 不足与局限

- **实验覆盖有限**：仅两个单供体数据集（一个鼠脑、一个肝），Human Liver 的跨切片设置仍是同供体内部迁移，未覆盖跨供体、跨平台、疾病状态、不同组织制备方案等更现实的泛化场景。
- **生物邻域定义依赖启发式**：以转录组 RBF 相似性和空间邻近性的等权组合作为"生物学真值"，缺乏外部专家注释（如病理学家标注的组织域、细胞类型组成）的验证；带宽选择也依赖训练集距离的中位数启发式。
- **标量权重表达能力有限**：α 是全局单一标量，无法表示"不同组织区域内分子与空间信号相对重要性不同"这种区域特异性变化（如肿瘤边界 vs. 核心区）。
- **评估指标存在规模依赖**：论文自己也指出固定 top-50 阳性定义在不同画廊规模下对应不同的阳性率，Bio-mAP 绝对值不可跨数据集直接比较。
- **超参数敏感性未充分讨论**：λs 敏感性实验表明 λs 增大可进一步提升 Bio-mAP 但会降低精确配对检索，论文选择 0.3 作为保守点，但更系统的多超参联合调优与报告仍有空间。
- **计算成本未透明**：未报告训练时长、显存占用或各方法的总计算开销对比，可复现性信息不够完整。
