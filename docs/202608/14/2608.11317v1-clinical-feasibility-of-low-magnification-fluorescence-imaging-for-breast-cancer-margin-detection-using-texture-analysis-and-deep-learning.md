## 摘要
使用紫外表面激发显微镜（MUSE）可以获得未经处理的乳腺手术组织的高分辨率图像。该技术被认为是乳腺癌手术中检查手术切缘的一种有前景的方法。在本研究中，使用图块级分类方法比较了4倍和10倍放大倍数下的MUSE图像。使用了基于局部二值模式（LBP）的纹理分析（TA）和基于基础Vision Transformer（ViT）模型的深度学习（DL）方法。两种方法在两种放大倍数下都取得了相似的性能。使用DL方法，4倍和10倍放大均达到了96.30%的敏感性、100%的特异性和98.18%的准确率。使用TA方法，4倍放大获得了更好的特异性（100%对93.33%），10倍放大获得了更高的敏感性（100%对93.33%），但两者的准确率相同（96.67%）。在10倍放大下没有观察到明显的性能提升。这些结果表明，4倍成像实现了与10倍成像相同的诊断准确性。同时，4倍成像提供了更大的视野和更快的图像采集速度。因此，在MUSE系统中可以有效地使用较低的放大倍数，以实现准确且高效的术中切缘评估。

## Abstract
High-resolution images of unprocessed surgical breast tissue can be obtained using microscopy with ultraviolet surface excitation (MUSE). This technique is considered a promising method for checking surgical margins during breast cancer surgery. In this study, MUSE images at 4x and 10x magnifications were compared using patch-level classification methods. Texture analysis (TA) based on local binary patterns (LBP) and deep learning (DL) with a base Vision Transformer (ViT) model were used. Both methods achieved similar performance at both magnifications. Using DL method, both 4x and 10x magnifications achieved 96.30% sensitivity, 100% specificity and 98.18% accuracy. Using TA method, 4x achieved better specificity (100% vs 93.33%) and 10x yielded higher sensitivity (100% vs 93.33%), but both had the same accuracy (96.67%). No clear improvement in performance was observed with 10x magnification. These results show that 4x imaging achieves the same diagnostic accuracy as 10x imaging. At the same time, 4x offers a larger field of view and faster image capture. Therefore, lower magnification can be effectively used in MUSE systems for accurate and efficient intraoperative margin assessment.

## 2. 论文提出的方法论

### 总体框架

研究采用了两种互补的图块级（patch-level）分类方法，并在此基础上聚合得到切缘级（margin-level）分类结果：

- **纹理分析（TA）**：基于局部二值模式（LBP）的传统机器学习方法
- **深度学习（DL）**：基于Vision Transformer（ViT）的深度学习方法

### 图像预处理

- **染色方案**：使用碘化丙啶（PPID）标记细胞核（红色荧光）和伊红Y（EY）标记细胞质（绿色荧光）
- **图块提取**：将大型拼接MUSE图像（常超过10,000×10,000像素）划分为不重叠的图块。4×放大使用400×400像素，10×放大使用1000×1000像素，图块大小按放大倍率差（2.5倍）进行缩放，以保持相近的物理组织面积
- **信息性筛选**：提取红色通道，以强度阈值5判定有效像素，仅保留有效像素占比超过20%的图块
- **标签生成**：基于H&E金标准图像，通过半自动标注转移方法生成图块标签，并由病理学家验证

### 纹理分析（TA）方法

1. **特征提取**：对每个图块的红色通道进行Wiener滤波去噪和直方图均衡化预处理
2. **LBP特征**：使用12个邻域点（N=12）、半径3（R=3）的圆形模式提取14个LBP特征，采用线性插值和旋转不变均匀模式
3. **NC比**：计算核质比（NC ratio）作为补充特征，暗阈值设为115
4. **分类器**：使用支持向量机（SVM），采用多项式核，正则化参数C=20
5. **五折交叉验证**评估图块级分类性能

### 深度学习方法（ViT）

1. **模型架构**：采用预训练的ViT-B/16架构，通过迁移学习在MUSE图块数据集上微调
2. **图块嵌入**：将每个图块划分为N个不重叠的子图块，通过可训练的投影矩阵映射到D维嵌入空间，并添加类别令牌（class token）和位置编码

   输入序列构建方式：`h0 = [p_class, ŝ1, ..., ŝN] + E_pos`

3. **编码器处理**：经L层Transformer编码器（包含归一化、自注意力、MLP模块）处理
4. **分类输出**：最终类别令牌经归一化后通过MLP分类头预测图块标签

### 切缘级聚合策略

- **TA方法**：分别累加肿瘤预测分数和正常预测分数，通过比较肿瘤分数与阈值×正常分数的大小来判断切缘类型（公式3）
- **DL方法**：对所有有效图块的预测取平均，与阈值θ比较得到最终切缘级分类结果
- **阈值选择**：通过网格搜索在ROC曲线上选择最优二值阈值，确保两种方法在最佳工作点下进行比较

## 8. 不足与局限

### 实验覆盖不足

1. **缺乏外部验证**：模型未在独立外部数据集上进行验证，泛化性能未知
2. **仅单一数据来源**：所有数据来自威斯康星医学院的组织库，可能存在机构偏差
3. **未与其他深度学习架构比较**：未与ResNet等CNN架构进行对比，无法确定ViT在该任务上的相对优势

### 方法局限

1. **图块级分析的必要性限制**：由于GPU内存限制，无法直接在整张切缘图像上进行分类。虽然图块级分析是计算上的必要选择，但可能丢失大范围的全局组织结构信息
2. **多点拼接的上下文差异**：4×与10×图像在切缘级别比较时，每个图块捕捉到不同范围的组织上下文和结构信息，虽按倍率差缩放了图块尺寸，但并不能完全保证物理区域精确对应

### 技术局限

1. **10×景深更浅**：较高倍率下部分区域可能轻微失焦，对分类准确率有潜在影响
2. **图块级类别不平衡**：良性图块占比超过75%，恶性图块不足25%，小面积恶性区域可能被多数投票机制覆盖，导致假阴性

### 偏差风险

1. **阈值选择的过拟合风险**：通过网格搜索在测试集ROC上选择最优阈值，可能导致性能估计偏乐观
2. **图块标签的边界不确定性**：将良恶性过渡区域的图块都标记为恶性，可能引入标注噪声

### 未来工作方向（作者提出）

- 开发自适应图块尺寸方法，更好捕捉不同倍率下的组织上下文
- 进行独立外部数据集验证

- 探索加权投票机制，增强恶性图块在最终决策中的权重
- 收集更多恶性样本以平衡数据集
