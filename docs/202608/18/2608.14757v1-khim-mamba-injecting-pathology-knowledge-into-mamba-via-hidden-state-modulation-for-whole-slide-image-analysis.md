## 摘要
全切片图像分析通常被形式化为多实例学习（MIL），其中实例特征被上下文更新并聚合为幻灯片表示，这一过程我们称为幻灯片编码动态。近期，选择性状态空间模型（SSM）因其长序列建模能力和线性复杂度而成为有前景的MIL架构。然而，现有的基于SSM的MIL方法在MIL过程中仅依赖视觉特征。与此同时，在稀疏的诊断决定性区域被大量无关信息包围的大规模WSI中，这种纯视觉驱动的选择性动态可能错误分配状态更新和读出，导致不断演化的SSM状态积累与任务无关的证据，并在长扫描轨迹中稀释关键诊断线索。在这项工作中，我们提出了知识感知隐藏状态调制架构（KHiM-Mamba），该架构创新性地利用显式知识先验调节Mamba的核心选择性状态空间机制，将幻灯片编码动态引导向具有诊断意义的证据积累。具体而言，我们重新设计了原始SSM层，在隐藏状态演化过程中执行知识调制操作，从而在每个编码步骤中引导从隐藏状态中积累和检索哪些视觉证据。此外，我们还引入了一个局部自适应词汇检索模块，该模块使用大语言模型为每个病理切片分配细粒度、组织特异性的语义描述，从而在多样化任务中实现精确调制。在4个任务的11个公共基准上的实验表明，KHiM-Mamba持续实现了最先进的性能。

## Abstract
Whole slide image analysis is commonly formulated as multiple instance learning (MIL), where instance features are contextually updated and aggregated into a slide representation, a process we term slide encoding dynamics. Recently, selective state-space models (SSM) have emerged as promising MIL architectures due to their long-sequence modeling capability and linear complexity. However, existing SSM-based MIL methods rely solely on visual features during MIL. Meanwhile, in large-scale WSIs, where sparse diagnostically decisive regions are surrounded by abundant irrelevant information, such purely vision-driven selective dynamics can misallocate state updates and readouts, causing the evolving SSM state to accumulate task-irrelevant evidence and dilute critical diagnostic cues over long scan trajectories. In this work, we propose the Knowledge-Aware Hidden-State Modulation architecture (KHiM-Mamba), which innovatively regulates Mamba's core selective state-space mechanism with explicit knowledge priors, steering slide encoding dynamics toward diagnostically meaningful evidence accumulation. Specifically, we redesign the original SSM layer to perform knowledge modulation operations during the evolution of hidden states, thereby guiding what visual evidence is accumulated and retrieved from the hidden state at each encoding step. Furthermore, we additionally introduce a local-adaptive vocabulary retrieval module that uses large language models to assign each patch fine-grained, tissue-specific semantic descriptions, enabling precise modulation across diverse tasks. Experiments on 11 public benchmarks across 4 tasks show that KHiM-Mamba consistently achieves state-of-the-art performance.

## 1. 论文的核心问题与整体含义

**研究动机：**
- 全切片图像（WSI）分析通常被形式化为多实例学习（MIL）问题：先用预训练编码器提取每个patch的特征，再由slide encoder建模patch间的上下文交互并聚合为slide级表示，这一过程被作者称为“slide encoding dynamics”。
- 大规模WSI中存在大量诊断无关的信息（如染色偏差、背景组织等），而稀疏的诊断决定性区域被大量无关区域包围。纯视觉驱动的方法容易在这些无关信息上分配注意力，导致关键诊断线索被稀释。

**现有方法的局限：**
- **基于Mamba的MIL方法**（如PAM、GMMamba、M3Mamba）仅依赖视觉特征进行状态演化，SSM的隐藏状态在长序列扫描中容易积累与任务无关的证据。例如，CAMELYON数据集中肿瘤切片偏红、正常切片偏紫，这种诊断无关的染色模式可能干扰状态更新。
- **现有VLM-MIL方法**（如ViLa-MIL、FOCUS、TOP）将语言作为外部附加组件：要么在编码前用于patch选择，要么在编码后作为辅助监督。语言没有介入核心的slide编码动力学，因此无法解决上述视觉驱动状态演化的根本缺陷。

**核心贡献：**
- 提出 **KHiM-Mamba**，首次将语言知识先验直接注入Mamba的SSM层内部，通过调制隐藏状态的写入和读出过程，引导编码动力学聚焦于诊断相关证据的积累。
- 提出 **局部自适应词汇检索模块（Local-Adaptive Vocabulary Retrieval Module）**，利用LLM为每个patch动态分配细粒度、组织特异性的语义描述，提供精确且任务自适应的调制信号。

## 2. 论文提出的方法论

### 2.1 核心思想
KHiM-Mamba的核心创新在于**重新设计SSM层的信息流**，使语言知识直接干预隐藏状态ℎₜ的演化过程，而非像此前VLM-MIL方法那样仅在编码外围使用语言。

### 2.2 技术细节

**（1）SSM基础公式：**
- 连续形式：ℎ′(𝑡) = 𝐴ℎ(𝑡) + 𝐵𝑥(𝑡)，𝑦(𝑡) = 𝐶ℎ(𝑡)
- 离散化后：ℎₜ = 𝐴̄ₜℎₜ₋₁ + Δₜ𝐁ₜ𝑥ₜ，𝑦ₜ = 𝐂ₜℎₜ，其中𝐴̄ₜ = exp(Δₜ𝐴)
- Mamba的选择性机制使Δₜ、𝐁ₜ、𝐂ₜ成为输入依赖的：**𝐁ₜ**控制当前输入如何写入隐藏状态，**𝐂ₜ**控制如何从隐藏状态读取上下文。

**（2）知识感知隐藏状态调制（KHiM）：**
- 选择调制𝐁ₜ和𝐂ₜ，而非Δₜ或𝐴矩阵，理由是：调制B和C不改变SSM的时间动态或衰减行为，类似于调整线性投影，优化更稳定。
- 低秩调制机制：
  - 语言嵌入𝐞ₜ通过共享的MLP映射为低秩系数向量：[𝜶_𝐵ₜ; 𝜶_𝐶ₜ] = MLP(𝐞ₜ) ∈ ℝ²ʳ
  - 调制增量通过可学习基矩阵计算：Δ𝐵ₜ = 𝜶_𝐵ₜ𝐖_𝐵，Δ𝐶ₜ = 𝜶_𝐶ₜ𝐖_𝐶
  - 残差相加得到调制后的投影：𝐵̃ₜ = 𝐁ₜ + 𝛾·Δ𝐵ₜ，𝐶̃ₜ = 𝐂ₜ + 𝛾·Δ𝐶ₜ
  - 缩放因子𝛾初始化为小值（1×e⁻²），使训练始于接近vanilla Mamba的行为，语言影响随优化逐步增强。
- 调制后的递推公式：ℎₜ = 𝐴̄ₜℎₜ₋₁ + Δₜ𝐵̃ₜ𝑥ₜ，𝑦ₜ = 𝐶̃ₜℎₜ
  - **写入调制（ΔB）**：引导哪些视觉证据被纳入演化状态，鼓励积累诊断相关证据、抑制无关特征。
  - **读出调制（ΔC）**：控制从状态中读出的上下文内容，确保输出的patch表示强调有诊断意义的模式。

**（3）局部自适应词汇检索模块：**
- **任务特定概念集构建**：对每个下游任务，提示LLM生成与该任务最相关的组织类型集合𝒯 = {𝑇₁, …, 𝑇_𝑀}；对每个组织类型进一步生成细粒度语言描述集合𝒮_𝑚；同时维护一个粗粒度语言集合𝒮_coarse作为回退选项。
- **置信度门控路由**：使用CONCH的image和text编码器计算patch与各概念的余弦相似度𝑎ₜ,ₘ = cos(𝑣ₜ, 𝑞ₘ)，选择最大相似度的概念，仅当满足以下条件才接受分配：
  - 𝑎ₜ,ₘ\* > 𝜏_sim（相似度阈值，设为0.25）
  - 𝑎ₜ,ₘ\* − max_{𝑚≠𝑚\*} 𝑎ₜ,ₘ > 𝜏_margin（边界阈值，设为0.03）
  - 若分配被接受，使用细粒度的组织特异性语言𝒮_{𝑚\*}；否则使用粗粒度回退语言𝒮_coarse。
- **语言嵌入构建**：将选定的描述逐一用CONCH文本编码器编码，聚合形成patch级语言表示𝐞ₜ，输入低秩调制机制。

## 6. 论文的主要结论与发现

1. **KHiM-Mamba在所有四个任务上均取得SOTA性能**：
   - 癌症亚型分类：BRACS-7 ACC提升1.77%、AUC提升1.02%；BRACS-3 ACC提升2.41%、AUC提升0.97%；TCGA-BRCA ACC提升1.97%、AUC提升1.01%。
   - 生存预测：平均C-Index达0.7394，较最先进的2DMamba提升2.31%。
   - 跨中心域泛化：平均AUC 0.9184，较TransMIL提升2.27%；在染色差异最大的Center 2上提升尤为显著（+2.04%）。
   - 少样本：8-shot下ACC 81.45%、AUC 93.48%，超过最强方法MOC 4.35%/2.97%。

2. **知识调制优于外围语言使用**：相比仅用于patch选择或辅助监督的既有VLM-MIL方法（ViLa-MIL、FOCUS、TOP等），将语言注入SSM核心动力学能带来更一致且大幅度的性能提升。

3. **写入调制比读出调制更关键**：消融实验显示，仅ΔB（写入调制）比仅ΔC（读出调制）带来更大的增益；二者联合时产生协同效应（平均AUC从0.8632提升至0.9127，+4.95%）。

4. **局部自适应词汇优于固定prompt**：相比使用类标签或全局共享的手工prompt，局部自适应路由策略在不同LLM下均取得更高性能，验证了“为不同组织区域分配不同语义描述”的有效性。

5. **KHiM-Mamba在计算效率上具有竞争力**：参数量2.22M，是Mamba-based方法中最少的；推断速度与2DMamba持平，优于PAM和MambaMIL。

6. **可视化验证**：KHiM调制后的注意力与肿瘤区域高度对齐，背景和非肿瘤区域的响应被有效抑制，表明语言调制确实重塑了patch表示以聚焦病理相关证据。

## 8. 不足与局限

1. **依赖LLM外部推理**：构建任务特定词汇需要调用LLM（文中使用GPT-5.6-sol），增加了流程复杂度和对外部服务的依赖；若LLM产生不准确或幻觉性的病理描述，可能对调制产生负面影响。
2. **实验的基座模型单一**：全部实验仅使用CONCH作为视觉和文本编码器，未评估在其他病理基础模型（如PLIP、UNI、MUSK）下的兼容性，通用性有待验证。此外，路由模块和语言嵌入均依赖CONCH，存在对单一模型的过度依赖。
3. **部分对比方法复现偏差风险**：M3Mamba

## 8. 不足与局限（续）

3. **部分对比方法复现偏差风险**：M3Mamba未开源，使用的是作者自己的复现版本，可能与原始结果存在偏差。TCGA-BRCA的划分遵循GMMamba的随机划分而非官方分层划分，与其他采用不同划分的文献结果的可比性有限。

4. **计算效率评估不完整**：论文仅报告了推理阶段的参数与吞吐量，未提供训练时间、显存峰值等关键资源指标，而知识调制MLP + 路由检索在实际训练中的额外开销未得到量化说明。

5. **统计显著性的粒度不足**：配对t检验仅在整体平均指标上报告，未在每一个数据集上逐一给出置信区间与效应量，个别数据集（如KIRC、KIRP）上C-Index的提升幅度较小，显著性存疑。

6. **路由模块的级联误差风险**：词汇检索依赖CONCH图像-文本对齐得分进行置信度门控，若CONCH在该patch上的嵌入存在偏差（如罕见组织类型、严重染色失真），则可能错误分配粗粒度回退语言，使调制信号失去细粒度信息，且该误差会沿SSM序列传播累积。

## 9. 深入批判性分析

### 9.1 核心创新是否真正成立？

从方法论角度，KHiM对SSM的B和C矩阵施加语言条件残差调制，确实实现了"语言进入状态演化"这一目标。但需审慎看待以下几点：

- **语言信号在实际计算中占多大权重？** 低秩调制ΔB、ΔC由𝛾=1×e⁻²缩放，意味着在训练初期语言对状态转移的影响非常有限。虽然论文报告最终性能提升显著，但未消融𝛾的敏感性——若将𝛾调大，是否进一步提升？若调大后性能反而下降，则说明语言调制的最优强度并非越大越好，"知识先验主导"的叙事需要更细致的刻画。

- **语言是否只是隐式正则化？** 从信息论视角看，低秩调制ΔBₜ、ΔCₜ只引入了极少量额外参数（低秩系数经基矩阵映射），语言信号本质上是为每个patch提供不同的"缩放方向"。这与显式稀疏正则化、dropout或特征门控存在某种数学等价性。论文未与同为低秩门控机制但不含语言输入的基线（如随机向量调制、PCA统计量调制）对比，因此无法严格区分"语言语义带来的增益"与"低秩调制机制本身带来的增益"。

### 9.2 与已有方法的本质区别

| 维度 | FOCUS / ViLa-MIL（外围语言） | KHiM-Mamba（内部语言） |
|------|------------------------------|------------------------|
| 语言介入位置 | patch选择或最终注意力监督 | SSM的B/C投影矩阵 |
| 语言对状态演化的直接影响 | 无 | 有 |
| 语言粒度 | 全局prompt或预定义类描述 | 局部自适应、组织特异性 |
| 序列级上下文利用 | 依赖外部聚合 | 内部状态耦合 |

这一对比清晰地呈现出KHiM的差异化优势：语言不再是一个"外部监督器"而是"状态转移的控制器"。但从另一个角度看，这种设计也引入了新的耦合复杂性——语言嵌入的质量直接决定状态动力学质量，而语言嵌入由CONCH生成，CONCH本身是一个视觉-语言模型，它的文本编码空间与图像编码空间的对齐质量构成了整个方法性能的隐性上界。

### 9.3 关于"域泛化"的叙事是否存在夸大？

跨中心实验中，CAMELYON16→CAMELYON17的域偏移主要源于染色的中心差异。论文将此归功于"语言知识先验引导状态聚焦诊断相关证据"。但值得注意的是：

- CONCH本身是在包含多种染色协议的病理数据上训练的，其视觉编码器已具备一定染色鲁棒性。
- 语言调制信号（如"肿瘤细胞呈高核质比、深染"）为模型提供了一种**跨染色不变的语义锚点**，这在概念上是合理的；
- 但只报告了平均AUC（0.9184）和最佳中心（Center 2 +2.04%），未报告每个中心上相比baseline的完整增量与方差，无法排除个别中心提升有限或波动较大的情况。

### 9.4 语言知识是否可能引入偏见？

一个未被充分讨论的问题是：LLM生成的病理语义描述（如"肿瘤区域：细胞核增大，染色质粗糙"）是否可能带有**标注者的统计偏差**？如果LLM倾向于将某些染色模式（如深染）与恶性关联，而实际诊断中这一关联并非绝对，语言调制可能放大染色偏差而非消除它。论文在CAMELYON的实验中报告了提升，恰好表明在该数据上语言先验与诊断标签大体一致；但如果在染色模式与诊断标签相关性更弱的数据集上，KHiM的增益可能减弱甚至产生负迁移。

## 10. 对未来研究方向的启示

1. **多编码器验证**：将KHiM扩展到PLIP、UNI、MUSK等基础模型上，验证语言调制机制的模型无关性，并研究不同编码器特征空间中低秩基矩阵的共享与迁移可能。

2. **在线词汇更新**：当前词汇检索为静态（推理前由LLM生成），可进一步提出可学习的语义优化机制，使语言描述在训练过程中随模型诊断性能反馈动态调整，减少对LLM初始质量的依赖。

3. **训练效率优化**：探索轻量化路由策略（如仅对关键patch计算细粒度语言嵌入）、缓存机制（重复出现的组织类型共享语义嵌入），降低语言模块的推理开销。

4. **因果干预分析**：通过干预实验（如对特定patch施加强制性的"良性描述"或"恶性描述"），系统研究语言信号对状态演化的因果影响，而非仅停留在相关性提升层面。

5. **跨模态蒸馏**：KHiM的语言调制实质上形成了一种视觉-语言知识蒸馏范式，可以进一步探索将训练完成的KHiM-Mamba蒸馏回纯视觉Mamba模型，实现在无语言输入条件下保持部分知识增益的部署方案。
