## 摘要
全切片图像（WSI）分析已被广泛研究用于癌症诊断。通常，十亿像素的WSI被划分成小块，并由多实例学习（MIL）模型处理。然而，现有的MIL模型通常会处理所有小块，其中许多包含冗余或无信息量的组织模式。尽管最近的方法聚焦于实例选择以识别辨别性小块并减少冗余，但这些选择模块仍然需要额外的训练。在这项工作中，我们提出了测试时实例选择（TTIS），一个免训练、即插即用的框架，在推理过程中选择紧凑且具有代表性的小块。TTIS进一步融合了多视图集成策略，以整合组织形态的不同方面，增强鲁棒性。重要的是，TTIS可以无缝集成到现有的MIL模型中，无需重新训练或更改架构，从而支持灵活部署。在多个基准上的广泛评估表明，我们的方法在各种分类和亚型分型任务中提升或匹配了基线MIL性能。我们的实现代码可在 https://github.com/QuIIL/TTIS 获取。

## Abstract
Whole Slide Image (WSI) analysis has been widely studied for cancer diagnosis. Conventionally, a gigapixel WSI is divided into small patches and processed by Multiple Instance Learning (MIL) models. However, existing MIL models typically process all patches, many of which contain redundant or non-informative tissue patterns. Although recent approaches have focused on instance selection to identify discriminative patches and reduce redundancy, these selection modules still require additional training. In this work, we propose Test-Time Instance Selection (TTIS), a training-free, plug-and-play framework that selects compact yet representative patches during inference. TTIS further incorporates a multi-view ensemble strategy to integrate distinct facets of tissue morphology, enhancing robustness. Importantly, TTIS can be seamlessly integrated into existing MIL models without retraining or architectural changes, enabling flexible deployment. Extensive evaluations across multiple benchmarks demonstrate that our approach improves or matches baseline MIL performance across a range of classification and subtyping tasks. Our implementation code is available at https://github.com/QuIIL/TTIS

## 1. 核心问题与整体含义

### 研究动机与背景
- 全切片图像（Whole Slide Image, WSI）是计算病理学中癌症诊断、亚型分类和预后预测的核心数据，但其分辨率高达十亿像素级，单张切片常包含超过 10,000 个 patch，无法直接端到端输入深度网络。
- 多实例学习（MIL）已成为 WSI 分析的主流范式，但传统 MIL 管线在训练和推理时都会处理所有 patch。实际上，大量 patch 是冗余的、非诊断性的或信息量极弱，不仅增加聚合成本，还可能稀释稀疏的判别性信息。
- 已有实例选择方法（如 DC-WSI、MiCo、PAMoE、PANTHER）虽然可以筛选关键 patch，但通常依赖额外训练目标、可训练选择模块或训练数据，难以直接应用于已部署模型。
- 论文提出一个核心问题：**在推理阶段、不重新训练的前提下，能否通过缓解 patch 冗余来提升预测性能？**

### 整体含义
论文提出 **TTIS（Test-Time Instance Selection）**，一个免训练（training-free）、即插即用（plug-and-play）的测试时实例选择框架，能够在推理阶段仅利用输入切片的 patch 嵌入，选出紧凑且具代表性的子集，从而抑制冗余和噪声，并可与现有 MIL 模型无缝集成。

## 2. 论文提出的方法论

### 核心思想
- 核心假设：一个紧凑但多样化的 patch 子集足以保留 slide 级预测所需的关键信息，同时剔除冗余与噪声。
- TTIS 不改变 MIL 模型的训练和结构，只在推理时对 patch 集合进行选择与聚合。

### 总体流程
TTIS 分为三步：

#### （1）层次化空间-语义聚类（Hierarchical Spatio-Semantic Clustering）
- 采用两阶段 K-Means++ 聚类：
  - 第一阶段：基于 patch 的 2D 空间坐标聚成 \(K_1\) 个空间簇，保留空间组织信息；
  - 第二阶段：在每个空间簇内部，基于特征嵌入继续聚成 \(K_2\) 个子簇，捕捉局部语义异质性；
- 设置 \(K_1 = K_2 = K\)，共得到 \(K^2\) 个子簇。
- K-Means++ 提供稳健的质心初始化和更快的收敛速度。

#### （2）分层采样（Stratified Sampling）：最远点采样 FPS
- 在每个子簇中使用 **Farthest Point Sampling（FPS）** 选择代表性 patch。
- FPS 是贪心下采样算法：迭代选择距离当前选中集合最远的 patch，形式化描述为：
  \[
  q_t = \arg\max_{s \in S \setminus Q_{t-1}} \min_{q \in Q_{t-1}} \|h_s - h_q\|_2
  \]
- FPS 鼓励子簇内的广泛覆盖，避免密集区域的过度表示。

#### 起始点选择（Starting Point Selection）
FPS 对起始点敏感，论文提出三种确定性初始化策略：

1. **基于质心（Centroid-based）**：选择距离子簇质心最近的 patch 作为 FPS 起点。
2. **基于注意力（Attention-based）**：选择该子簇内注意力分数最高的 patch；若模型无显式注意力分数，则使用 softmax 归一化的 L2 范数作为伪注意力分数。
3. **类别引导（Class-guided）**：利用病理基础模型（如 TITAN、MUSK）和文本编码器，为每个类别构造文本提示的原型嵌入，然后选择与每类原型余弦相似度最高的 patch 作为类别特定起点。

#### （3）多视图测试时集成（Multi-view Test-time Ensemble）
- 每种初始化准则对应一种视图：
  - 质心：强调语义代表性；
  - 注意力：强调模型感知的重要性；
  - 类别引导：强调诊断特异性。
- 对每个准则分别得到 slide 级嵌入，再用 softmax 归一化权重进行聚合，得到最终 slide 级表示，送入分类器得到预测结果。
- 该集成策略旨在提升鲁棒性和预测一致性，避免单一准则丢弃互补信息。

## 6. 主要结论与发现

- TTIS 在多个数据集和多种 MIL 模型上，普遍**提升或保持基线性能**，说明处理全部 patch 并非最优，WSI 中存在大量冗余和非信息性 patch。
- 在 CAMELYON16 上提升最明显：相比基线，所有模型的 Accuracy 提升 0.52%–3.62%，F1 提升 0.005–0.041。
- 随机采样普遍劣于基线和 TTIS，说明“简单采样”不能替代有结构的实例选择。
- 在 TCGA-BRCA 上，TTIS 在 6 个模型中的 5 个上提升了 Accuracy 和 F1，例如 ABMIL Accuracy 提高 2.09%，WiKG F1 提高 0.036。
- 在 TCGA-ESCA 上，ABMIL 和 TransMIL 在所有指标上均有稳定提升。
- 在 TCGA-RCC 和 TCGA-NSCLC 上，TTIS 基本保持基线水平，部分模型有小幅提升。
- 消融实验表明：
  - 多视图集成通常优于任一单视图，证明不同初始化策略捕捉互补信息；
  - 层次聚类对 K 的选择不敏感，稳定性好；
  - 采样比例降至 30% 甚至 10%–20% 时仍能保持甚至提升性能，验证了冗余 patch 移除的价值。

## 7. 优点

- **真正免训练**：无需重新训练或修改 MIL 模型结构，可直接用于已部署模型。
- **即插即用**：与 ABMIL、TransMIL、CLAM-SB、WiKG、S4MIL、R2T-MIL 等多种模型兼容。
- **方法设计有层次**：空间 + 语义的两阶段聚类，兼顾组织空间结构和特征异质性；FPS 采样保证子集多样性。
- **多视图集成策略**：质心、注意力、类别引导三种视角互补，增强鲁棒性和性能稳定性。
- **大量消融实验**：对聚类数、采样率、初始化策略均做了系统分析，展示了方法的鲁棒性。
- **实用价值高**：在推理时降低输入 patch 数量，理论上可降低下游计算成本，且保持或提升预测性能。

## 8. 不足与局限

- **“免训练”并非完全零代价**：类别引导初始化依赖额外的病理基础模型（TITAN/MUSK）和文本编码器，实际部署仍需加载这些预训练组件。
- **缺少效率量化**：论文题目与动机强调高效，但没有给出相比基线节省的推理时间、FLOPs 或内存数据。
- **统计验证不足**：3 折交叉验证、固定随机种子、无显著性检验，结论的稳健性证据较弱。
- **未与训练式实例选择方法直接对比**：实验只对比了“无选择”和“随机选择”，没有对比 DC-WSI、MiCo、PAMoE 等已有方法，因此无法体现 TTIS 相对这些方法的优劣。
- **部分数据集上提升有限**：TCGA-RCC 和 TCGA-NSCLC 上多数结果与基线几乎持平，说明 TTIS 的增益可能依赖任务难度和基线饱和程度。
- **超参数需要一定调优**：默认 K=16、r=30%，ESCA 需特殊设置 K=2；论文虽显示鲁棒性，但“无需调参”的普适性仍需更多验证。
- **潜在过拟合风险模型特定**：注意力起始点依赖 MIL 模型输出的注意力分数，但很多 MIL 模型没有显式注意力，伪注意力方法的效果未单独深入分析。
