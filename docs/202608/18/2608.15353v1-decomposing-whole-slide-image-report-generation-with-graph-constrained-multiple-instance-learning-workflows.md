## 摘要
全切片图像（WSI）报告生成需要识别空间分布的病理特征，并将它们组织成连贯的诊断叙述。尽管直接的视觉到文本模型可以生成流畅的报告，但它们掩盖了视觉识别、结构化推理和语言生成的贡献和失败模式。我们提出了一个分解框架，其中冻结的Virchow2图块嵌入通过多实例学习（MIL）分类头进行聚合，这些分类头回答器官特定的诊断问题。一个器官条件图约束这些答案组装成结构化推理链，语言模型将其实现为病理报告。在包含2,028张切片的REG2026留出集上，所提出的工作流实现了chain-Jaccard得分0.702。性能下降：没有基于图的链构建时降至0.420；当器官特定图被单个器官无关图替代时降至0.398；当语言模型从MIL预测自由构建链时降至0.371。使用相同的报告生成器，图结构化链将报告得分从0.330提高到0.495。在覆盖七个REG器官的350个外部TCGA WSI上，无需微调，预期器官图在64.0%的情况下被选中，并在86.6%的情况下排名前三。提供正确的器官图将粗粒度TCGA原发诊断标签的一致性从61.8%提高到92.6%，确定器官路由是域转移下的主要瓶颈。总体而言，器官条件、图约束的链组装改善了结构化推理和报告生成，同时实现了阶段特定的错误定位。

## Abstract
Whole-slide image (WSI) report generation requires recognizing spatially distributed pathological features and organizing them into a coherent diagnostic narrative. Although direct vision-to-text models can yield fluent reports, they obscure the contributions and failure modes of visual recognition, structured reasoning, and language generation. We propose a decomposed framework in which frozen Virchow2 tile embeddings are aggregated by multiple-instance learning (MIL) classification heads that answer organ-specific diagnostic questions. An organ-conditioned graph constrains the assembly of these answers into a structured reasoning chain, which a language model realizes as a pathology report. On the REG2026 held-out set of 2,028 slides, the proposed workflow achieved a chain-Jaccard score of 0.702. Performance fell to 0.420 without graph-based chain construction, 0.398 when the organ-specific graphs were replaced by a single organ-agnostic graph, and 0.371 when the language model constructed the chain freely from MIL predictions. Using the same report generator, graph-structured chains improved the report score from 0.330 to 0.495. On 350 external TCGA WSIs spanning the seven REG organs without fine-tuning, the expected organ graph was selected in 64.0% of cases and ranked among the top three in 86.6%. Providing the correct organ graph increased agreement with coarse TCGA primary-diagnosis labels from 61.8% to 92.6%, identifying organ routing as a main bottleneck under domain shift. Overall, organ-conditioned, graph-constrained chain assembly improves structured reasoning and report generation while enabling stage-specific error localization.

## 1. 核心问题与整体含义（研究动机和背景）
- **问题背景**：全切片图像（WSI）病理报告生成需要在十亿像素级别的组织图像上识别空间分布的症状特征，并输出结构化的临床诊断叙述。
- **直接 vision-to-text 模型的缺陷**：虽然能生成流畅报告，但将“视觉识别—诊断推理—语言生成”三个阶段耦合在一起，导致出错时无法判断失败来自哪一环节，缺乏可解释性和可定位性。
- **核心动机**：将 WSI 报告生成显式拆解为视觉证据预测、图约束推理、报告实现三个独立阶段，使每一阶段的贡献和错误模式可被观测、评估和定位。
- **整体含义**：提出一种“器官条件图约束 + 多实例学习（MIL）工作流”的分解式框架，在不牺牲报告质量的前提下提高结构化推理能力和错误溯源能力。

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程
- **核心思想**：用 MIL 分类器提供视觉证据；用从病理学家推理注释中提取的器官特定诊断图（graph）来约束推理链的组装；用语言模型仅做报告文本的“实现”，而不是自由生成推理。
- **整体流程**：
  1. **Tile 编码**：将 WSI 切成 224×224 非重叠图块，过滤背景（像素平均 RGB 强度 <220 且占比 ≥50%），最多采样 128 个组织图块。使用冻结的 Virchow2 病理基础模型编码，每块得到 2560 维表示：类别 token 与剩余 patch token 平均拼接。
  2. **视觉预测**：每张 slide 表示为可变长嵌入包 \(X_s = \{x_{s,i}\}_{i=1}^{N_s}\)，使用 gated attention MIL 分别训练：
     - 一个器官分类头，用于选择器官特定图；
     - 多个“问题特定”分类头，每个分类头回答一个器官图中某个诊断问题的答案（仅在包含该问题的参考链的 slide 上训练）。
  3. **图约束推理链组装**：为每个器官构建图 \(G_o=(V_o,E_o,A_o,T_o)\)，其中 \(V_o\) 是标准问题节点，\(E_o\) 是答案条件转移，\(A_o\) 是答案词汇表，\(T_o\) 是转移函数。推理时先选器官 \(\hat{o}_s\)，再沿图从起始问题出发，每步由对应 MIL 头预测答案 \(\hat{a}_t\)，并按 \(q_{t+1}=T_{\hat{o}_s}(q_t,\hat{a}_t)\) 跳转，得到有序问答链。
  4. **报告实现**：将结构化推理链作为条件输入，用 LoRA 微调的 Qwen2.5-1.5B-Instruct 生成最终病理报告。

## 7. 优点：方法或实验设计上的亮点
- **高度可解释的分解设计**：将报告生成拆成视觉 → 推理 → 语言三个阶段，每阶段有独立可量化指标，能定位错误来源。
- **图约束是真正起作用的**：通过 Canonical 和 Shuffled 对照，证明性能增益不是单纯格式化或边缘数减少，而是图结构本身的推理价值。

- **外部域迁移和 oracle 实验设计巧妙**：用 TCGA 粗标签分离“器官路由错误”和“器官内推理错误”，揭示部署瓶颈。
