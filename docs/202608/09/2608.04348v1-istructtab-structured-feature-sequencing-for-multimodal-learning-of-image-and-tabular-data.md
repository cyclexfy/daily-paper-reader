## 摘要
图像与表格数据的多模态学习常因表示不当而受损，导致冗余、分散和泛化问题。为应对这一挑战，我们引入了图增强描述符排序（GEDS），一种基于列排列问题（CPP）原理的结构化特征排序算法。GEDS通过基于相似图的计算来细化特征的统计描述符，系统地确定有效的特征排序。我们将GEDS融入一个顺序感知的高效Transformer框架中，利用顺序感知的记忆令牌，通过专用损失函数显式遵循所导出的特征排序。跨多模态基准的实验结果表明，iStructTab有效减少了特征分散，提升了预测性能和鲁棒性，并凸显了结构化特征排序在多模态学习中的重要性。

## Abstract
Multimodal learning of images and tabular data is often impaired by ineffective representations, resulting in redundancy, dispersion, and generalization problems. To tackle this challenge, we introduce Graph-Enhanced Descriptor Sequencing (GEDS), a structured feature sequencing algorithm grounded in principles from the Column Permutation Problem (CPP). GEDS refines statistical descriptors of the features through similarity graph-based computations, systematically determining an effective feature sequencing. We incorporate GEDS within an order-aware efficient transformer framework, utilizing order-aware memory tokens that explicitly adhere to the derived feature sequencing via a dedicated loss function. Experimental results across multimodal benchmarks demonstrate that iStructTab effectively minimizes feature dispersion, improving predictive performance and robustness, and highlighting the significance of structured feature sequencing in multimodal learning.

### 1. 核心问题与整体含义（研究动机与背景）

- **研究背景**：多模态学习（特别是图像 + 表格数据的融合）在医疗、遥感、环境建模等领域日益重要。但图像具有强烈的空间结构，而表格特征本质上是**无序的（unordered）**，这种结构性不匹配导致跨模态对齐困难、特征冗余和泛化能力下降。
- **核心问题**：大多数现有的多模态融合方法（如注意力机制、对比学习、Transformer 共享编码等）都将融合后的特征视为**无序向量**，忽略了**特征排列顺序（feature ordering）** 对表示学习和预测性能的影响。
- **关键洞察**：作者将多模态特征排序问题**形式化为列置换问题（Column Permutation Problem, CPP）**，即寻求一个最优特征排列 π，以最小化特征间的分散度（dispersion），提升跨模态结构一致性。
- **整体思路**：提出 iStructTab 框架，由两大部分组成：
  1. **GEDS**：基于图增强描述符排序的特征排列算法，在融合前显式确定任务相关的特征顺序。
  2. **OEMT**：顺序感知的高效 Transformer 骨干网络，通过记忆增强池化和排序损失强制模型遵循 GEDS 给出的排列。

### 2. 方法论：核心思想、技术细节、算法流程

#### 2.1 整体架构
- **两阶段流程**：先通过 GEDS 生成特征排列 π_GEDS，再将按此排列的特征输入 OEMT 骨干进行预测。
- **特征提取**：图像特征由 ResNet（CNN）提取为 d 维向量；表格特征由 Transformer 编码为 p 维向量；两者拼接为统一特征矩阵 F ∈ R^(N×(p+d))。

#### 2.2 列置换问题（CPP）形式化
- 目标函数：min_π D(π) = Σ_{i<j} w_ij |π(i) − π(j)|
- 其中 w_ij 为特征 i 与特征 j 之间的不相似度权重，目标是找到使整体分散度最小的排列 π。CPP 是 NP-hard 问题。

#### 2.3 GEDS 算法（Algorithm 1）—— 核心步骤：
1. **统计描述符构造**：对每个特征列 f_j，计算均值 μ_j 和方差 σ²_j，构成二维描述符 d_j = [μ_j, σ²_j]^T ∈ R²。
2. **描述符归一化**：对每个描述符进行 L2 归一化，使后续相似度计算不受量纲影响。
3. **余弦相似度图构建**：计算描述符矩阵 D 的余弦相似度矩阵 A = DD^T，并加上自连接（A + I）。
4. **对称归一化**：使用度矩阵 D_deg 进行对称归一化：Â = D_deg^(-1/2)(A+I)D_deg^(-1/2)。
5. **图卷积细化**：通过一层图卷积 D' = σ(ÂDW) 对描述符进行细化，W 为可学习权重矩阵，σ 为 ReLU 激活。
6. **排序分数计算**：计算每个细化描述符的 L2 范数 s_j = ||d'_j||₂ 作为特征重要性与独特性的分数。
7. **生成排列**：按分数升序排列得到 π_GEDS = argsort(s₁, s₂, ..., s_m)。

#### 2.4 OEMT 骨干网络
OEMT 旨在高效处理有序特征序列，包含三大部分：

- **顺序感知投影**：将按 π_GEDS 排列的特征重新排列后，通过可学习投影矩阵 W_p 映射为 token 嵌入序列 T_in。
- **顺序感知池化**：通过可学习池化矩阵 W_pool 将 m 个 token 压缩为 k 个（k ≪ m）摘要 token，保留排列信息。
- **记忆增强编码**：在压缩 token 前拼接 M 个可学习的记忆 token（提供全局上下文），由 Linformer 编码器（线性复杂度注意力）处理。
- **双头输出**：
  - 分类头：对记忆 token 表示做平均池化，经全连接层输出类别预测 ŷ。
  - 排序头：从记忆 token 输出预测排序分数向量 s'。
- **损失函数**：L_total = L_CE(y, ŷ) + λ_FS · ||s' − β||²₂
  - β 为根据 π_GEDS 构造的线性目标排序向量（β_π(i) = 1 − (i−1)/(m−1)），用于显式约束模型学习遵循目标排列。

### 6. 主要结论与发现

1. **结构化特征排序具有重要意义**：在多模态融合中显式引入特征排序可减少特征分散、提升跨模态一致性，显著优于将特征视为无序集合的做法。
2. **iStructTab 综合性能最优**：在 6 个数据集上取得最低的平均秩（1.50）和最低的平均遗憾（2.21），超越了 STiL、TIP、MMCL 等强基线。

5. **消融确认关键组件**：
   - GEDS 排序和 OEMT 记忆 token 是性能的核心驱动（移除后排序列性能大幅下降 12~16 个百分点）。
   - 排序损失起到重要的正则化作用。
   - 强骨干（ResNeXt-50）不如正确的特征排序有效。
6. **模型具有良好的校准性和局部稳定性**：HAM 上 ECE = 0.103，kNN 一致性达 ~98%；对图像和表格扰动的性能退化平滑。

### 7. 优点与亮点

- **问题建模新颖**：将多模态特征排序形式化为 CPP 问题，为多模态融合提供了新的理论视角。
- **GEDS 算法简洁有效**：仅用均值/方差作为描述符 + 余弦相似度图 + 图卷积，即可生成优于随机/默认顺序的特征排列，计算开销低。
- **OEMT 设计高效**：通过顺序感知池化（m→k）和 Linformer 线性注意力，避免了对长特征序列的二次复杂度，兼顾性能与效率。
- **排序损失的显式约束**：将排列信息作为监督信号引入训练，使模型不仅是"使用"顺序，而是"学习"保持顺序一致性。
- **实验全面**：主实验 + 噪声 + 消融 + 效率 + 统计检验 + 补充诊断，覆盖了准确率、鲁棒性、效率、可解释性、OOD 等多个维度。
- **补充材料详实**：数据效率曲线、OOD 置信度、Turing 风格评估基础设施、长尾分析等，展示了对模型行为深度的刻画。

### 8. 不足与局限

- **调优公平性存疑**：iStructTab 使用 Optuna 逐数据集调优，而多个基线使用默认参数，可能造成性能差距的原因包含调优程度的差异，而不仅是方法本身的优势。
- **统计显著性有限**：论文自己指出 Nemenyi CD 值较大（CD = 7.82），由于数据集数量较少（6 个），iStructTab 与次优方法之间的差距虽在平均秩上清晰可见，但**未达到严格统计显著阈值**。
- **GEDS 的 O(m²) 图构建开销**：当特征维度 m 很大时（原始论文提到数千特征），稠密相似度矩阵的计算代价较高，作者虽提出可用 k-NN 或低秩近似缓解，但主实验中未展示大规模特征下的表现。
- **DVM 上的表格信息缺失处理复杂**：DVM 数据缺失严重，论文用 CTGAN 进行插补，这种额外预处理可能引入外部偏差。
- **t-SNE 仅为定性分析**：对融合表示质量的判断主要依赖定性可视化，缺乏更定量的表示质量指标（如线性探测对比、对齐/均匀性度量等）。
- **OOD 置信度问题**：补充材料承认在极端 OOD 输入（纯噪声/空白图像）下，模型 softmax 给出近 100% 置信度，熵趋近于零——即**过度自信问题**未解决，需要额外的 OOD 检测机制才能用于安全关键场景。
- **超参数敏感性**：λ_FS 在不同数据集上的最优值差异大（从 10⁻⁵ 到 0.18 不等），这一宽泛范围可能暗示排序损失的稳定性有待提升。
- **跨数据集泛化未验证**：所有实验均为同数据集内训练/测试，未涉及跨数据集迁移或领域泛化场景。
