## 摘要
视觉与文本表征的跨模态对齐是多模态医学图像理解的基础，但在真实临床条件下，两种模态中的不确定性仍然阻碍其发展。现有的视觉-语言分割方法依赖确定性跨模态匹配，忽略了模糊边界带来的偶然不确定性和有限训练数据带来的认知不确定性，导致在域偏移下性能脆弱。为解决此问题，我们提出了DistMedVL，一个概率性视觉-语言框架，在冻结编码器之上引入轻量级概率跨模态适配器（PCM-Adapter），显式建模表征不确定性。具体而言，PCM-Adapter由两个顺序模块组成，用于渐进式概率对齐。首先，我们设计了马氏对齐模块（MAM），将文本标记建模为高斯分布，并通过马氏距离计算补丁-文本兼容性，产生方差条件匹配，降低不可靠特征维度的权重。此外，我们设计了分布流模块（DFM），估计模态级置信参数，并对文本分布进行视觉引导的细化，以适应跨成像模态的分布变化。在八个医学分割基准上的大量实验表明，DistMedVL仅用6.3M可训练参数即可超越最先进方法，展现出优越的数据效率、扰动鲁棒性和跨数据集泛化能力。

## Abstract
Cross-modal alignment of visual and textual representations is fundamental to multimodal medical image understanding, yet remains hindered by uncertainty in both modalities under real-world clinical conditions. Existing vision-language segmentation methods rely on deterministic cross-modal matching, which overlooks aleatoric uncertainty from ambiguous boundaries and epistemic uncertainty from limited training data, leading to fragile performance under domain shift. To address this issue, we propose DistMedVL, a probabilistic vision-language framework that introduces a lightweight Probabilistic Cross-Modal Adapter (PCM-Adapter) upon frozen encoders to explicitly model representational uncertainty. Specifically, the PCM-Adapter comprises two sequential modules for progressive probabilistic alignment. We first devise a Mahalanobis Alignment Module (MAM) that models textual tokens as Gaussian distributions and computes patch-text compatibility via Mahalanobis distance, yielding variance-conditioned matching that downweights unreliable feature dimensions. Moreover, we devise a Distribution Flow Module (DFM) that estimates modality-wise confidence parameters and performs vision-guided refinement of textual distributions, accommodating distributional variation across imaging modalities. Extensive experiments across eight medical segmentation benchmarks demonstrate that DistMedVL outperforms state-of-the-art methods with only 6.3M trainable parameters, exhibiting superior data efficiency, perturbation robustness and cross-dataset generalization.

- **研究背景**：医学图像分割是计算机辅助诊断、治疗规划和手术导航的关键技术。临床中医学图像通常伴随放射学报告、诊断描述等文本信息，天然构成多模态场景，因此视觉-语言模型（VLM）被引入用于医学图像分割，通过文本语义引导视觉分割。
- **核心问题**：现有视觉-语言分割方法多依赖确定性的跨模态匹配（如余弦相似度、点对点对齐），将视觉和文本表征视为固定点嵌入，忽视了以下两类不确定性：
  - **偶然不确定性（Aleatoric Uncertainty）**：图像边界模糊、设备噪声、文本语义歧义等数据固有噪声，无法通过增加数据消除；
  - **认知不确定性（Epistemic Uncertainty）**：训练数据有限导致的模型知识不足，尤其在罕见病理和欠表示区域表现明显。
- **现有方法的不足**：确定性对齐无法评估每个特征维度的可靠性，在域偏移、数据稀缺、输入扰动等真实临床条件下性能脆弱。尽管 MedCLIPSeg 引入了概率思想，但其对齐度量将不确定性简化为标量校正项，未充分建模跨模态分布的完整结构。
- **论文的解决思路**：提出 **DistMedVL**，一个概率视觉-语言框架，在冻结的视觉-语言编码器上引入轻量级概率跨模态适配器（PCM-Adapter），显式建模表征不确定性，从而提高分割精度、数据效率和泛化鲁棒性。

## 2. 论文提出的方法论（核心思想、关键技术细节）

### 2.1 整体架构
- 基于 **CLIPSeg**（ViT-B/16 视觉编码器 + Transformer 文本编码器），冻结两个编码器。
- 在编码器第 {2, 4, 6, 8} 层插入轻量级 **PCM-Adapter**，仅适配器参数和 CLIPSeg 解码器可训练。
- 总可训练参数仅 **6.3M**。
- 训练目标 = 分割损失（BCE + Dice）+ 对比损失（CLIP contrastive），权重 λ1=0.5、λ2=0.1。

### 2.2 PCM-Adapter 结构
每个 PCM-Adapter 是一个 bottleneck 式模块，包含压缩层、两个顺序子模块、扩展层：
- 压缩/恢复：通过线性投影将双模态特征映射到共享低维空间，再恢复原维度，以降低计算开销并过滤冗余特征。

### 2.3 马氏对齐模块（MAM）
- 将文本 token 建模为**高斯分布**（估计每 token 的均值 μt 和方差 σ²t，softplus 保证方差为正）。
- 视觉侧：聚合所有 patch 得到全局视觉表征，估计图像级方差 σ²v。
- 通过可学习参数 θλ 将视觉方差与文本方差融合，得到双边方差 σ² = σ²t + sigmoid(θλ) ⊙ σ²v + ε。
- 用**马氏距离**计算 patch 与文本 token 的兼容性：
  d²M = (1/√D) Σ (Zv,d − μt,d)² / σ²d
  - 方差越大的特征维度在距离中贡献越小，从而自动降权不可靠维度。
- 距离矩阵经温度缩放 softmax 转为软分配矩阵 A，生成稠密语义先验 S，通过门控机制融入视觉特征：
  F̂v = Wo(V + g(V) ⊙ S)，其中门控可自适应吸收或绕过文本语义。

### 2.4 分布流模块（DFM）
- 解决视觉→文本方向的不对称性问题：文本 token 对密集 patch 的注意力会发散，因此采用全局语义聚合策略。
- 聚合视觉 patch 得到全局均值 μv,g 和 inter-patch 方差 σ²v,g，衡量 patch 间的语义一致性。
- 通过可靠性门 γ = sigmoid(G(σ²v,g))，抑制高方差异常视觉信号。
- 估计双模态语义强度 βv、βt，利用残差分布流更新文本语义强度 βt* = βt + MLP([βv; βt])，再投影回原特征空间得到视觉引导的文本特征 F̂t。
- 该模块确保只有可靠视觉证据参与文本分布修正，避免不可靠视觉信号污染文本表征。

### 2.5 两个模块的配合
- MAM 先产生不确定性精炼的视觉特征，DFM 再基于这些特征做全局语义对齐，形成级联式跨模态精炼，优于并行配置。

## 6. 论文的主要结论与发现

- **SOTA 性能**：在 100% 训练数据下，DistMedVL 达到 87.63% Dice、92.36% NSD，超过最佳跨模态方法 MedCLIPSeg 1.19% Dice / 1.29% NSD；仅 6.3M 可训练参数，优于所有单模态和跨模态对比方法。

- **域泛化稳健**：在三个迁移任务中均最优；域偏移越严重（TN3K→PKTN，MMD 最大），优势越明显（+2.38% Dice、+4.20% NSD），表明显式概率建模能有效缓解分布漂移下的性能崩溃。

- **不确定性校准更优**：DistMedVL 的不确定性图更集中于边界区域，前景/背景内部虚假高不确定性更少，预测概率校准更准确。

- **未与其他不确定性建模方法对比**：未与贝叶斯神经网络、MC Dropout 增强的 CLIPSeg、深度集成等经典不确定性方法进行同口径对比，使新颖性论证缺少直接对照。

## 9. 局限性与未来方向展望

- **不确定性激励机制的缺失**：作者将认知不确定性与数据比例挂钩、将偶然不确定性与扰动挂钩，但未显式设计损失函数来惩罚错误的不确定性估计，导致概率输出缺乏端到端的监督信号。未来可引入不确定性感知的损失项（如积分损失、分布匹配损失），确保不确定性与分割误差协同优化。
- **文本利用的深度仍有限**：当前文本分支仅提供语义先验，未充分利用报告中的空间关系词（如“位于左叶下极”“与包膜相邻”）生成空间线索，对长文本与多句报告的建模能力较弱。未来可引入结构化文本解析（如场景图、实体关系提取），将描述性知识与解剖位置先验结合。
- **模型可扩展方向的延伸**：当前仅基于 CLIP 双编码器，可尝试从 CLIP 切换至医学预训练视觉-语言模型（如 PubMedCLIP、MedCLIP），或扩展至分割大模型（SAM 系列）以增强掩码生成质量。同时可引入记忆库或元学习机制，将罕见病理的分布知识留存复用。
- **轻量化与实时化的工程路径**：可探索概率适配器的低秩分解、token 剪枝、知识蒸馏与量化，在保持概率对齐能力的前提下降低推理成本，推动临床落地。
- **多模态安全性与可解释性**：进一步在对抗文本干扰（恶意误导描述）和对抗图像噪声下评估模型的失效边界，结合注意力可视化和不确定性图分析模型决策依据，提升临床信任度。
- **评测维度的扩充**：引入边界不确定性分布评估（如表面 Dice 置信区间）、跨中心的真实域偏移基准，以及多标注者标注噪声建模，使偶然不确定性的估计更具临床代表性。

## 10. 总结（综合结论）

**DistMedVL 是医学图像分割领域中，将跨模态语义对齐与双类不确定性显式建模相结合的一次扎实探索。** 其核心贡献在于：将视觉-语言分割从确定性点匹配推进到分布级概率匹配，以马氏距离实现方差自适应降权的局部对齐（MAM），再以全局语义聚合与可靠性门控完成视觉到文本的残差信息流（DFM），从而在两个方向上同时实现了不确定性敏感的跨模态融合。在数据稀缺、域偏移与输入扰动三种真实挑战下，DistMedVL 均取得领先表现，且参数量仅有 6.3M，架构优雅且极具实际部署潜力。

同时，该工作也存在可复现性低、统计检验缺失、扰动对比不全面、不确定性校准缺少量化指标等明显短板，其“概率建模优于确定性对齐”的核心结论仍需更多维度与更大规模的证据支持。总体上，这是一篇方法论完整、实验设计思路清晰、在医学多模态不确定性建模方向上具有启发意义的工作，但距离临床落地和社区复用仍有相当距离。
