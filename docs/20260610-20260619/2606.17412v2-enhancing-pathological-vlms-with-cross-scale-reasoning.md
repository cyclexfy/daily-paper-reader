## 摘要
病理图像本质上是多尺度的，要求病理学家整合从低倍放大的全局组织结构到高倍放大的细胞形态的证据，以进行准确诊断。尽管现有的用于视觉语言模型（VLM）的病理数据集包含各种尺度，但它们通常缺乏明确的跨尺度推理目标。这一局限性阻碍了VLM捕获关键的跨尺度表示并学习基于证据的推理。为弥补这一差距，我们引入了第一个跨尺度训练和评估范式，将病理解释表述为多倍率推理。然而，创建这样的任务揭示了一个关键挑战：多图像视觉问答（VQA）容易受到仅文本捷径的影响，这使得模型能够利用与放大倍数相关的伪影而非视觉证据来猜测答案。为解决此问题，我们提出了一种泄漏感知的整理流程，结合了对抗性纯文本筛选与约束引导的问题设计。利用该流程，我们构建了Scale-VQA，一个高质量的基准测试，包含基于2537张多倍率病理图像的4685道多项选择题。最后，我们提出了ScaleReasoner-R1，该模型通过强化学习训练以优化跨尺度VQA任务的性能。ScaleReasoner-R1在我们的跨尺度推理基准测试上达到了最先进的性能，并在已建立的单尺度基准测试上泛化到最先进的性能。研究结果表明，即使是有限的跨尺度监督也能显著提高病理理解。代码和演示将开源。

## Abstract
Pathological images are inherently multi-scale, requiring pathologists to integrate evidence from global tissue architecture at low magnification to cellular morphology at higher magnification for accurate diagnosis. While existing pathological datasets for vision-language model (VLM) include various scales, they often lack an explicit cross-scale reasoning objective. This limitation prevents VLMs from capturing essential cross-scale representations and learning evidence-based reasoning. To bridge this gap, we introduce the first cross-scale training and evaluation paradigm that formulates pathology interpretation as multi-magnification reasoning. However, creating such a task reveals a critical challenge: multi-image visual question answering (VQA) is prone to text-only shortcuts, which allow models to guess answers using magnification-dependent artifacts rather than visual evidence. To address this, we propose a leakage-aware curation pipeline that combines adversarial text-only screening with constraint-guided question design. Using this pipeline, we construct Scale-VQA, a high-quality benchmark with 4,685 multiple-choice questions grounded in 2,537 pathology images across multiple magnification levels. Finally, we present ScaleReasoner-R1, a model trained via reinforcement learning to optimize performance on the cross-scale VQA task. ScaleReasoner-R1 achieves state-of-the-art performance on our cross-scale reasoning benchmark and generalizes to SOTA performance on established single-scale benchmarks. Findings suggest that even the limited cross-scale supervision can significantly improve pathological understanding. The code and demos will be open-sourced.

## 1. 论文的核心问题与整体含义（研究动机和背景）
- **核心问题**：病理图像诊断需要整合低倍放大的组织结构和局构成与高倍放大的细胞形态证据（跨尺度推理）。然而，现有的病理视觉语言模型（VLM）通常仅在固定放大倍数的单张图像上训练和评估，缺乏明确的跨尺度推理目标。
- **背景与动机**：
  - 病理医生在实践中会跨越多个倍数进行推理（如低倍看整体结构，高倍看细胞异型性），最终诊断来自多尺度证据整合。
  - 现有VLM数据集（如PathMMU）仅包含单张ROI或单一尺度的特征，模型无法学习层级化的跨尺度推理。
  - 构建多图像VQA时容易产生“文本捷径”问题：模型仅凭问题文本和选项就能猜出答案，而忽略部分图像证据，导致虚假的高性能。
- **整体含义**：本文提出首个针对病理VLM的跨尺度训练与评估范式，旨在让模型学会像病理医生一样进行多倍数证据整合，从而提升诊断的鲁棒性和可解释性。

## 2. 论文提出的方法论：核心思想、关键技术细节
### 核心思想
- 将病理解释形式化为多倍率推理任务，通过构建**泄漏感知的跨尺度VQA基准**（Scale-VQA）来抑制文本捷径，并利用**强化学习**（GRPO）训练模型以提升跨尺度证据整合能力。

### 关键技术细节
1. **临床标注流程**：
   - 基于177张TCGA全切片图像（WSI），15名住院病理医生（>5年经验）和5名高级病理医生（>20年经验）进行标注。
   - 在低倍（10×）、中倍（40×）、高倍（200×）下选取对应ROI，并撰写每个ROI的描述，再生成跨尺度合成描述（937条）。
2. **泄漏感知VQA整理流程**（图2a）：
   - **Step 1 尺度特征分解**：将专家标注分解为每个倍数的特征集，并定义5个跨尺度推理维度（对应、确认、定位、解释、诊断），同时建立视觉依赖、尺度依赖、维度特定三类约束。
   - **Step 2 对抗性纯文本筛选**：使用Gemini 3 Pro和Qwen3-Max作为仅文本对手，如果它们能仅凭问题和选项猜对答案，则分析泄漏原因（如语言线索、标签先验），迭代更新约束至对手无法再猜对。
   - **Step 3 跨尺度多项选择题生成与临床验证**：用精炼后的约束生成最终MCQ，每道题配多倍图、正确答案和理由，并由病理医生验证答案视觉支撑性和干扰项临床合理性。
3. **跨尺度推理优化（GRPO强化学习）**：
   - 输入多倍图像集`I = {I_10×, I_40×, I_200×}`、问题`q`、选项`O`，策略`π_θ`输出带推理（`<think>`）和答案（`<answer>`）的结构化响应。
   - 奖励函数：`R = λR_acc + (1-λ)R_form`，其中`R_acc`为答案正确得1分（否则0），`R_form`确保输出格式正确，`λ=0.8`。
   - GRPO通过每个问题采样多个响应并计算组内相对优势来更新策略，无需显式评论家网络。

## 6. 论文的主要结论与发现
- **跨尺度推理显著提升**：ScaleReasoner-R1在Scale-VQA Test上平均准确率达**82.89%**，远超第二名（GPT-5.2为58.51%），且在所有五个推理维度上均占优。
- **跨尺度监督泛化至单尺度**：在PathMMU上，ScaleReasoner-R1达到或接近专家性能（如EduContent和Atlas子集），优于所有对比的病理VLM。
- **RL优于SFT**：纯RL训练效果最好，SFT会遗忘预训练的单尺度知识（单尺度性能下降），而RL+微调可缓解但不如纯RL。支持“SFT记忆、RL泛化”的观点。
- **数据高效**：仅使用177个WSI即可实现显著提升，说明高质量的跨尺度标注比大规模数据更重要。
