## 摘要
从常规H&E染色组织学图像中表征肿瘤微环境（TME）需要同时进行细胞分割、特征提取和可解释的临床报告。我们提出了SEGTME-UNI2，一个统一框架来满足这些需求。其核心是UNI2-UPERHOVER，一个双头分割模型，将UNI2-H病理学基础模型（ViT-Giant，在来自10万张切片的超过1亿张图块上预训练）与两个并行的UperNet解码器配对：一个用于六类语义分割，另一个用于水平和垂直梯度回归，从而实现基于分水岭的细胞核实例分离。为了解决大型真实世界数据集中缺乏像素级标注的问题，UNI2-UPERHOVER经历了一个三阶段渐进式伪标签课程。每个阶段训练一个全新的模型，不进行权重迁移，完全通过提高伪标签质量来推动改进：第1阶段：使用人工标注的PanNuke（7,901张图像，189,744个细胞核，0.25微米/像素）。第2阶段：使用来自第1阶段模型的熵过滤伪标签，应用于271,711张TCGA-UT尺度0图块（0.5微米/像素）。第3阶段：使用来自第2阶段模型的伪标签，应用于全部1,608,060张TCGA-UT图块，涵盖六个分辨率尺度（0.5-1.0微米/像素）。分割输出输入到一个结构化的TME特征提取流水线，计算每个图块的20多种组成、形态、空间熵和细胞间距离指标。这些指标被编码为JSON，然后传递给微调后的NVIDIA BioNeMo GPT模型，以生成临床可解释的TME叙述。在留出的PanNuke和TCGA-UT分区上的初步验证证明了框架的可行性和内部一致性。伪标签的TCGA-UT数据集和UNI2-UPERHOVER检查点已公开发布，以支持大规模TME分析和空间生物学研究。

## Abstract
Characterising the tumour microenvironment (TME) from routine H&E-stained histology images requires simultaneous cell segmentation, feature extraction, and interpretable clinical reporting. We present SEGTME-UNI2, a unified framework addressing these requirements. Its core is UNI2-UPERHOVER, a dual-head segmentation model pairing the UNI2-H pathology foundation model (ViT-Giant, pretrained on >100M tiles from 100K slides) with two parallel UperNet decoders: one for six-class semantic segmentation and one for horizontal-vertical gradient regression enabling watershed-based nuclear instance separation. To address the lack of pixel-level annotations in large real-world repositories, UNI2-UPERHOVER undergoes a three-stage progressive pseudo-label curriculum. Each stage trains a fresh model without weight transfer, driving improvement entirely via increased pseudo-label quality: Stage 1: Uses human-annotated PanNuke (7,901 images, 189,744 nuclei, 0.25 um/pixel). Stage 2: Uses entropy-filtered pseudo-labels from the Stage 1 model on 271,711 TCGA-UT scale-0 patches (0.5 um/pixel). Stage 3: Uses pseudo-labels from the Stage 2 model on all 1,608,060 TCGA-UT patches across six resolution scales (0.5-1.0 um/pixel). Segmentation outputs feed a structured TME feature extraction pipeline computing 20+ per-patch compositional, morphological, spatial entropy, and intercellular distance metrics. These are encoded as JSON and passed to a fine-tuned NVIDIA BioNeMo GPT model to generate clinically interpretable TME narratives. Preliminary validation on held-out PanNuke and TCGA-UT partitions demonstrates framework feasibility and internal consistency. The pseudo-labelled TCGA-UT dataset and UNI2-UPERHOVER checkpoint are publicly released to support large-scale TME profiling and spatial biology research.

## 1. 论文的核心问题与整体含义（研究动机和背景）

**核心问题**：从常规 H&E 染色的组织病理学图像中表征肿瘤微环境（TME）需要同时解决三个相互耦合的任务：  
- **语义分割**（将每个像素分配给特定细胞类型类别）  
- **细胞核实例分离**（将每个细胞核分割为独立对象）  
- **临床可解释报告生成**（将定量特征转化为医生可直接理解的叙述）  

**背景与动机**：  
- 现有方法要么专注于实例分割（如 HoVer-Net）需要昂贵的人工多边形标注，泛化性差；要么专注于语义分割（如 UperNet）无法分离粘连细胞核。  
- 大规模病理图像库（如 TCGA）拥有海量无像素级标注的数据，而小规模有标注数据集（如 PanNuke，仅 7,901 张图像）覆盖的染色协议和分辨率有限。  
- 近期病理基础模型（如 UNI2）提供了强大的跨任务表征，但需设计合适的解码器适配其架构。  
- 即使提取出定量 TME 特征，临床医生也难以直接消化数字，需要借助大语言模型（LLM）生成结构化临床报告。  

**整体含义**：  
论文旨在构建一个**统一端到端框架**，从 H&E 图像出发，依次完成：  
1. **多类细胞分割**（6类：肿瘤、炎症、结缔组织、坏死、非肿瘤上皮、背景）  
2. **实例分离**（基于分水岭算法）  
3. **结构化 TME 特征提取**（20+ 个特征，包括组成、形态、空间熵、免疫-肿瘤距离等）  
4. **LLM 驱动的临床报告生成**（基于 BioNeMo GPT 微调）  

核心挑战在于如何**在无像素级标注的 TCGA 数据上训练高泛化性的分割模型**，为此提出三阶段渐进伪标签课程。

## 2. 论文提出的方法论：核心思想、关键技术细节

### 2.1 核心思想：三阶段渐进伪标签课程 + 双头分割网络 + 结构化 TME 特征 + LLM 报告

**整体流程**：  
- 使用 UNI2-H（ViT-Giant，预训练于 1 亿 + 图块）作为共享骨干，提取四尺度特征金字塔（块 5、11、17、23）。  
- 两个独立的 UperNet 解码头：语义头输出 6 类语义图，HV 回归头输出 2 通道水平-垂直梯度图（用于分水岭实例分离）。  
- 通过动态 HV 目标合成，从语义标签直接生成 HV 目标（无需实例级标注）。  
- 三阶段课程：从有标注 PanNuke 开始→在 TCGA 尺度 0 生成伪标签→扩展到 TCGA 全部六个尺度。每个阶段重置模型权重，仅利用上一阶段的伪标签质量提升。  
- 分割后，计算每张图块的 20+ 个 TME 特征，编码为 JSON，再通过规则翻译为 6 类表型标签和 11 个生物标记词。  
- 最后，将结构化 JSON 作为提示输入微调后的 BioNeMo GPT，生成临床风格描述。

### 2.2 关键技术细节

#### 2.2.1 双头解码器
- **语义头**：`num_labels=6`，输出 6 类概率图。  
- **HV 回归头**：`num_labels=2`，输出水平/垂直梯度图（无激活函数）。  
- **损失函数**：  
  - 语义损失：交叉熵（忽略忽略索引 255）。  
  - HV 损失：像素级 MSE + 梯度匹配项（权重 2）。  
  - 总损失：`L_total = L_sem + λ * L_hv`，λ=1.0。

#### 2.2.2 动态 HV 目标合成
- 从语义掩码（类别>0）通过连通域分析得到每个细胞核的质心。  
- 对每个像素计算相对于质心的归一化距离（缩放因子 10 像素），裁剪到 [-1,1] 作为 HV 目标。  
- 此过程无需实例级标注，使伪标签训练可扩展到 TCGA。

#### 2.2.3 三阶段渐进伪标签课程
| 阶段 | 数据源 | 图块数量 | 分辨率 (μm/px) | 标注类型 |
|------|--------|----------|----------------|----------|
| 1 | PanNuke | 7,901 | 0.25 | 人工标注 |
| 2 | TCGA-UT 尺度 0 | 271,711 | 0.5 | 模型 1 生成的熵过滤伪标签 |
| 3 | TCGA-UT 尺度 0-5 | 1,608,060 | 0.5-1.0 | 模型 2 生成的熵过滤伪标签 |

- 每个阶段从头初始化骨干和解码器，不权重继承。  
- 熵过滤：保留每个图块前景像素平均熵低于 70% 分位数的图块。

#### 2.2.4 TME 特征提取与翻译
- 组成特征：每类细胞计数、比例、平均核面积。  
- 临床比例：肿瘤-间质分数、免疫浸润分数。  
- 空间特征：免疫细胞到肿瘤细胞的最小/平均距离、50 像素内接触免疫细胞数、5 近邻香农熵（细胞混合度）。  
- 翻译规则：基于阈值（如免疫比例>0.3 为“免疫热”），生成 6 个表型标签和扁平生物标记词列表。

#### 2.2.5 BioNeMo GPT 微调
- 训练数据：成对的（结构化 JSON 提示 → 目标叙述）。  
- 损失：仅对叙述部分的交叉熵。  
- 推理时，输入 JSON，模型自回归生成临床描述。

## 6. 论文的主要结论与发现

1. **可行性证明**：UNI2-UPERHOVER 双头架构能在共享 UNI2-H 骨干基础上同时输出语义图和 HV 图，并通过动态目标合成实现无实例标注训练。  
2. **课程有效性**：三阶段伪标签课程可在无额外人工标注情况下，将模型从 PanNuke 泛化到 TCGA 多尺度数据，且每个阶段初始 mIoU 逐步提升（0.41→0.47→0.53），反映伪标签质量改进。  
3. **TME 管线一致性**：在 4 个不同染色/组织类型的 HNSCC 案例上，生成的 TME 表型标记词与视觉观察一致，说明特征提取和翻译规则合理。  
4. **数据集发布**：释放了目前最大的公共 TCGA 核级伪标签数据集（160 万图块）和三个阶段的模型检查点，支持大规模空间生物学研究。

## 7. 优点：方法或实验设计上的亮点

1. **创新架构**：UNI2-UPERHOVER 将基础模型（UNI2-H）与双头 UperNet 解码器结合，利用 FPN 金字塔池化自然适应多尺度（0.25-1.0 μm/px）输入，优于点式解码器。  
2. **无实例标注训练**：动态 HV 目标合成使模型可从纯语义标签学习实例分离，极大降低标注成本，这是工程上的巧妙设计。  
3. **渐进课程策略**：三阶段训练不迁移权重、仅依赖伪标签质量提升，有效避免了单步自训练中的误差积累，且每阶段从头开始保证模型不会过拟合噪声。  
4. **结构化 TME 特征管道**：详细定义了 20+ 个定量指标，并设计可解释的翻译规则（6 个表型轴+11 个标记词），结果可追踪、可审计。  
5. **LLM 接地**：使用结构化 JSON（而非图像像素）作为 LLM 输入，将生成内容锚定于可验证的数字，显著降低幻觉风险。  
6. **开放科学**：公开了最大规模的 TCGA 核级伪标签数据集和模型权重，具有较高可复现性和社区价值。

| **伪标签质量** | 未对 200 张 TCGA 图块进行人工标注以直接评估伪标签准确率（计划中）。 |
| **动态 HV 目标误差** | 对于同类别粘连细胞核，连通域分析可能无法正确分离质心，引入近似误差。论文承认这一点但未提出改进方案（计划用形态学先验或可学习模块）。 |
| **拼接伪影** | 推理时图块拼接采用 last-writer HV 图拼接，可能导致梯度不连续；建议将来使用高斯羽化混合。 |
| **阈值依赖** | 生物标记词翻译规则采用固定阈值（文献衍生），可能不适用于所有癌种；计划替换为结果监督分类器。 |
| **计算资源** | 要求高端 GPU（8×A100），对资源有限实验室复现困难。 |
| **泛化性验证** | HNSCC 定性案例仅 4 例，样本量过小，无法证明跨癌种泛化性。 |

**总体评价**：当前工作处于**初步可行性验证阶段**，核心方法具有创新性和实用潜力，但实验证据尚不充分到宣称“通用”或“SOTA”。作者明确计划在后续 Nature Methods 论文中完成严格评估，因此本文可作为技术路线和方法论的高质量预览。
