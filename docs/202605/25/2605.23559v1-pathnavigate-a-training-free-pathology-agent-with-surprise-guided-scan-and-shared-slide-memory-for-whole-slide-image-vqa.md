## 摘要
全切片图像视觉问答（WSI-VQA）将病理学建模为一个极端上下文搜索问题：为了回答一个自由格式的临床查询，系统必须首先在严格的检查预算下导航一个千兆像素切片，以定位稀疏的高分辨率证据。现有方法主要分为两种范式：i) 有监督的病理学多模态大语言模型（MLLMs）和智能体可以将定位和推理吸收到学习模块中，但它们通常将导航与任务特定的监督和重新训练耦合，限制了其实用性；ii) 无需训练的病理学智能体通过保持核心模型冻结来避免这种成本，但通常采用问题优先设计，主要从基于查询的相关性中构建初始候选集。这可能会遗漏问题中未提及的决定性形态学，并迫使进行更重的推理时辅助架构。为解决这一挑战，我们引入了PathNavigate，一种无需训练的病理学智能体，围绕扫描-搜索-读出流程构建。在问题匹配之前，PathNavigate在低放大倍数下使用共享的在线记忆模块对当前切片进行扫描，该模块基于冻结的病理学特征，生成一个特定于切片的惊奇场，标记异常区域池。然后，它仅在此池内应用基于问题的PLIP相关性来选择高放大搜索目标。最后，它提取局部高放大证据，并使用冻结的感知-判定堆栈以及相同的在线记忆作为切片级上下文来回答问题。在WSI-VQA和SlideBench-BCNB上的实验表明，所提出的扫描-搜索-读出设计提高了答案准确性，并生成了更可解释且效率更高的证据选择轨迹。代码已在线公开。

## Abstract
Whole-slide image visual question answering (WSI-VQA) frames pathology as an extreme-context search problem: to answer a free-form clinical query, a system must first navigate a gigapixel slide under a strict inspection budget to locate sparse, high-resolution evidence. Existing approaches largely fall into two paradigms: i) supervised pathology multimodal large language models (MLLMs) and agents can absorb localization and reasoning into learned modules, but they often couple navigation to task-specific supervision and retraining, limiting their practicality; ii) training-free pathology agents avoid this cost by keeping core models frozen, but often follow a question-first design, constructing the initial candidate set mainly from query-conditioned relevance. This can miss decisive morphology that is not named in the question, and force heavier inference-time scaffolding. To address this challenge, we introduce PathNavigate, a training-free pathology agent built around a scan-search-readout routine. Before question matching, PathNavigate scans the current slide at low magnification with a shared online memory module over frozen pathology features, producing a slide-specific surprise field that marks an abnormal-region pool. It then applies question-conditioned PLIP relevance only within this pool to select high-magnification search targets. Finally, it extracts local high-magnification evidence and answers with a frozen perceptor-adjudicator stack, using the same online memory as slide-level context. Experiments on WSI-VQA and SlideBench-BCNB show that the proposed scan-search-readout design improves answer accuracy and yields more interpretable evidence-selection trajectories with higher efficiency.The code is available online.

- **现有范式缺陷**：
  - **监督方法**（如SlideChat、WSI-LLaVA等）：将定位和推理学习到模型参数中，但需要任务特定重新训练，缺乏灵活性。
  - **无训练智能体**（如PathAgent）：为保持可部署性而冻结核心模型，但普遍采用“问题优先”设计——初始候选区域主要基于问题相关性检索。这容易遗漏问题未明确提及但对答案至关重要的形态特征（如分级问题中一小块高级别病灶），迫使智能体使用更长的推断链、更大的缓存或外部上下文来弥补，导致延迟和令牌消耗增加。
- **本文动机**：受病理医生先宽泛扫描全片建立“正常/典型”基线，再针对性搜索更相关证据的行为启发，提出一种**扫描-搜索-读出**流程，使无训练智能体能在问题匹配前先构建切片特异的内容先验。

## 2. 方法论（核心思想、关键技术细节、算法流程）

### 2.1 核心思想
- **扫描阶段**：在低倍率下扫描全切片，利用共享在线记忆模块计算每个图块的“惊奇分数”（surprise score），标记与切片常态偏离的异常区域，并基于阈值和距离非极大抑制（NMS）形成紧凑的兴趣区域（ROI）候选池。
- **搜索阶段**：在此候选池内，仅用问题条件相关性（PLIP相似度）重排序，筛选出高倍率搜索目标。
- **读出阶段**：提取高倍率局部证据，并结合扫描阶段产生的相同在线记忆状态（导航摘要）作为切片级上下文，供冻结的感知-裁决器输出最终答案。

### 2.2 关键技术细节
- **共享在线记忆（Shared Online Memory）**：
  - 结构：两层GELU激活的重建MLP，输入和隐藏维度均为 768（对应CONCH特征维度）。
  - 更新方式：每个切片初始化一次新鲜记忆。对每个低倍图块特征 \(z_i\)，计算预更新梯度范数作为惊奇分数 \(\sigma_i\)（若重建该图块会显著改变当前记忆，则分数高）。仅在热启动后超过阈值 \( \tau_{sur} \) 的图块执行SGD更新；其余图块采用指数衰减遗忘。
- **惊奇引导扫描**：
  - 对所有低倍图块计算惊奇分数场，应用阈值 + 距离NMS（间距依赖问题类型）得到ROI池 \( \mathcal{R}(q) \)。
- **任务条件搜索**：
  - 对池内每个ROI，计算PLIP文本-图像相似度 \( r_{PLIP} \)。
  - 归一化惊奇分数和PLIP分数，以对称权重 \( \alpha = 0.5 \) 融合，选择Top-K目标 \( \mathcal{C}(q) \)。
- **证据读出与QA**：
  - 对每个高倍目标，在其局部区域内再次启用新鲜记忆，选择Top-T高惊奇补丁作为高倍证据集 \( \mathcal{E}(q) \)。
  - 可选地检索少量参考案例（k=3）提供上下文。
  - 感知器（Patho-R1-7B）将补丁转换为证据字符串；裁决器（Qwen3.5-4B）结合证据、导航摘要和参考上下文生成最终答案。

### 2.3 算法流程（文字描述）
1. 提取低倍图块，初始化新鲜在线记忆。
2. 扫描低倍图块：对每块计算惊奇分数（重建梯度范数），热启动后仅更新高惊奇图块。
3. 阈值+NMS得到ROI池 \( \mathcal{R}(q) \)。
4. 在池内计算PLIP相关性和惊奇分数归一化融合，选择高倍搜索目标 \( \mathcal{C}(q) \)。
5. 对每个目标提取高倍局部补丁，再用新鲜记忆选出Top-T高惊奇补丁作为证据集 \( \mathcal{E}(q) \)。
6. 构建导航摘要（扫描统计信息），可选检索参考案例。
7. 感知器将证据补丁转换为文本；裁决器综合所有信息输出答案。

## 6. 主要结论与发现
- **扫描-搜索-读出设计优于问题优先设计**：通过优先建立切片特异性内容先验，再应用问题相关性，显著提高了答案准确率（WSI-VQA总准确率56.34%，比PathAgent的33.88%提升22.46个百分点；BCNB总体59.42%，比PathAgent的55.72%提升3.7个百分点）。
- **共享在线记忆有效性**：移除导航摘要或档案后准确率下降，说明扫描状态作为答案上下文有价值。
- **惊奇分数主导候选池构建**：移除惊奇（随机ROI或仅PLIP）导致大幅度下降，强调首次通过池的重要性。
- **高倍率局部证据必要**：仅使用低倍证据准确率显著降低。
- **成本和效率优势**：相比PathAgent，PathNavigate令牌消耗更低（~17K vs ~30K），离线存储极小（~4MB vs 277MB），延迟相近。
- **H&E局限性**：HER2、分级等涉及IHC或散布线索的任务仍受限，但路由改进带来实际提升。

## 7. 优点
1. **无需重新训练**：所有视觉和语言骨干保持冻结，降低部署门槛。
2. **可解释性**：提供惊奇热图、证据轨迹和导航摘要，使决策过程透明。
3. **模块化和通用性**：可轻松替换特征提取器、感知器、裁决器，不依赖任务特定训练。
4. **基于病理直觉**：模拟病理医生“先扫描再搜索”的行为，符合临床认知。
5. **低存储和低令牌消耗**：在线记忆MLP仅几MB，无需大容量缓存，实际运行令牌数较低。
6. **跨任务稳定性**：在多个子任务上表现一致优于或与最先进监督方法竞争。

## 8. 不足与局限
1. **H&E模态限制**：对于需要IHC或分子信息的子任务（如HER2表达、分子亚型），性能提升有限，即使导航更精确也无法完全补偿缺失的模态信息。
2. **仅覆盖有限疾病类型**：实验基于乳腺癌（TCGA-BRCA, BCNB），泛化到其他癌症类型（前列腺、肺等）未验证。
3. **PathMMU为弱验证**：仅作为补丁级转移测试，未在WSI-VQA级别充分证明泛化能力。
4. **无训练依赖冻结特征质量**：性能受CONCH、PLIP、Patho-R1等预训练模型质量上限制约；若特征分布偏移或遇到异常组织，惊奇分数可能失效。
5. **无训练智能体仍依赖手工规则**：如路由预算、NMS间距、融合权重α=0.5固定，这些启发式可能在不同数据集或问题类型中非最优（但有消融研究表明对称权重已接近最优）。
6. **计算资源未详细披露**：虽然无训练，但推理仍需多跳（扫描+搜索+高倍提取+感知+裁决），中等规模实验（数百个WSI）在RTX 4090上可能耗时较长，实际部署需考虑延迟。
7. **未涉及现实临床中多标签、多任务联合问答**：目前仅回答单问题，未设计多轮对话或复杂推理链。
8. **负发现未深入分析**：文中提及重建低惊奇补丁等尝试无效，但缺乏统计显著性检验。
