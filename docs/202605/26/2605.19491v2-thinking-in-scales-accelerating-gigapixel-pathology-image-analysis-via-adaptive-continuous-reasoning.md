## 摘要
传统的全切片图像（WSI）分析方法通常依赖多实例学习（MIL）范式，即在高倍率下提取斑块级特征并聚合以进行切片级预测。然而，这种穷举式的斑块级处理计算成本高昂，严重限制了WSI分析的效率和可扩展性。为应对这一挑战，我们提出了PathCTM（病理导向的连续思维模型），该模型能实现对十亿像素级WSI进行令牌高效的尺度空间连续推理。PathCTM将诊断推理构建为一种动态的序列信息追踪过程，从低倍率全局检查逐步过渡到高倍率局部检查，并在收集到足够证据以有效界定决策不确定性时自适应终止推理。具体而言，它采用条件计算实现动态尺度切换，配合注意力引导的区域剪枝，并结合了置信度感知的提前停止。大量实验表明，与基于标准MIL的方法相比，PathCTM在保持AUC不下降的同时，减少了95.95%所需的图像斑块数量，并将推理时间缩短了约95.62%。代码已公开于https://github.com/JSGe-AI/PathCTM。

## Abstract
Traditional whole slide image (WSI) analysis methods typically rely on the multiple instance learning (MIL) paradigm, which extracts patch-level features at high magnification and aggregates them for slide-level prediction. However, such exhaustive patch-level processing is computationally expensive, severely limiting the efficiency and scalability of WSI analysis. To address this challenge, we propose PathCTM (a Pathology-oriented Continuous Thought Model) that enables token-efficient scale-space continuous reasoning for gigapixel WSIs. PathCTM formulates diagnostic inference as a dynamic sequential information pursuit. It progressively transitions from low-magnification global to high-magnification local inspection, and adaptively terminates inference when sufficient evidence is gathered to effectively bound decision uncertainty. Specifically, it uses conditional computation for dynamic scale switching with attention-guided region pruning, coupled with confidence-aware early stopping. Extensive experiments demonstrate that, compared with standard MIL-based methods, PathCTM reduces the number of required image patches by 95.95% and shortens inference time by approximately 95.62%, while maintaining AUC without degradation. Code is available at https://github.com/JSGe-AI/PathCTM.

## 2. 方法论：核心思想、关键技术细节
### 2.1 核心思想
- 将WSI分析形式化为一个**动态序贯信息追求过程**，从低倍率全局特征开始，逐级向高倍率局部区域推进，在保证端到端推理连续性的同时，通过**条件计算**和**早停机制**动态控制计算资源分配。
- 核心设计包括：尺度空间连续推理、注意力引导区域剪枝、置信度感知早停。

### 2.2 关键技术细节
#### (1) 尺度空间连续推理
- **推理轨迹**：模型在每一尺度（共4个尺度，如5×、10×、20×、40×）执行固定步数（如20步）的连续动态推理，步数累计为80步。
- **状态更新**：采用循环动态系统，利用同步模块 f_θ_syn 更新潜在状态，融合当前注意力输出和历史记忆。
- **跨尺度切换**：当当前尺度的推理步数用完且预测置信度未达到阈值δ时，触发多尺度动态切换。系统会选择当前尺度中预测最置信时间步的注意力分布，作为信息密度代理进行Top-K区域选择，然后提取这些区域在下一更高分辨率下的特征继续推理。
- **跨尺度融合**：为防止上下文丢失，将当前细尺度的同步输出与先前粗尺度的最置信输出进行拼接（公式5），从而保留全局证据。

#### (2) 注意力引导区域剪枝（条件计算）
- **问题**：处理所有高倍率补丁计算不可行。
- **方法**：利用推理过程中产生的注意力分布近似局部信息密度，选择注意力权重最高的K个区域（默认K=10）进行分析，其余区域直接裁剪。这相当于一个稀疏掩码，将复杂度从O(N)降至O(K)。
- **理论依据**（Proposition 1）：在有限特征范数和加性聚合下，注意力权重是单补丁对决策损失一阶影响的替代变量，因此Top-K选择可近似基于梯度的最大影响选择。
- **联合注意校准**：在跨尺度过渡时，对所选子集S的细粒度特征重新进行联合注意力计算（公式10），这有助于消除粗粒度特征导致的假阳性区域，阻断错误传播。

#### (3) 置信度感知早停
- **置信度定义**：`C_t,L = 1 - H(ˆy_t,L) / log N`，其中H为Shannon熵，N为类别数。
- **停止准则**：当`C_t,L ≥ δ`（默认δ=0.9）时，推理立即终止并输出当前预测；否则继续推理或切换到下一更高尺度。
- **理论支撑**（Proposition 2）：基于Fano不等式，高条件熵必然对应不可忽略的分类误差下界，因此当置信度高时停止是信息论上合理的。
- **损失函数**：优化两个目标——最小化损失和最大化置信度。对每个尺度，选择最小损失时间点和最大置信度时间点，取两者交叉熵的平均（公式1-3）。

#### (4) 整体流程
1. 从WSI提取低倍率特征。
2. 在当前尺度进行n步连续推理，每一步得到预测和置信度得分。
3. 若达成δ → 停止并输出。
4. 若未达成且已到最大步数 → 触发尺度切换：取最置信时间步的注意力，选择Top-K高信息区域，提取其高倍特征，拼接跨尺度融合向量，进入下一更高尺度继续推理。
5. 若所有尺度用完仍未达到δ，则使用最终预测结果。

## 7. 优点
- **创新性**：将连续思维机（CTM）扩展至WSI分析，引入“尺度思考”维度，填补了现有方法缺乏连续多尺度推理的空白。
- **高效性**：通过条件计算（注意力引导剪枝）和早停机制，实现了接近两个数量级的加速，同时精度不降反升，解决WSI分析的核心效率瓶颈。
- **兼容性**：可无缝集成现有的病理基础模型（CONCH、UNI等），与MIL范式的分析流程兼容，无需改变特征提取器。
- **可解释性**：模型推理过程与病理学家“粗扫→细查”的工作流程高度一致，可视化呈现注意力区域的聚焦过程，有助于临床信任和理解。
- **理论支撑**：对注意力引导剪枝（Proposition 1）和早停机制（Proposition 2）提供了信息论和敏感性分析的数学证明，使方法有理论依据。
- **实验充分**：在多个数据集、多种任务类型（分类、分期、基因预测）、多个评估维度（AUC、补丁数、时间）上进行了全面比较，消融和参数分析完整。

## 8. 不足与局限
- **信息瓶颈**：硬注意力机制可能不可逆转地剪枝掉在低倍率下缺乏显著性的有效诊断区域（如微转移灶、孤立肿瘤细胞），造成信息丢失。虽然联合注意校准能拦截错误传播，但无法召回被错误丢弃的有效区域。
- **固定推理步数**：当前在每个尺度上使用固定步数（20步），未实现步数自适应，可能仍有冗余或不足。
- **早停依赖模型校准**：置信度与真实不确定性之间假定了一致性，但若模型校准不佳，早停可能不可靠（论文仅假设校准合理）。
- **临床验证不充分**：仅在公开数据集上实验，未在真实临床多中心前瞻性数据上验证，部署前需要更广泛的验证。
