## 摘要
预训练视觉-语言模型（VLM）的分类准确性依赖于文本提示的质量。手工制作的模板和大语言模型（LLM）生成的描述不仅使预测更具可解释性，还使得同一提示可在异构VLM间复用。近期工作利用少量标注图像构建任务适应的文本提示。然而，现有少样本文本提示方法在提示构建过程中未明确关注误分类样本，导致即使增加样本量也仅带来边际提升。为充分利用少样本监督，我们提出文本提示提升（TPB），一种受AdaBoost启发的框架，它将每个基于文本提示的分类器视为弱学习器，并通过显式针对难分类、误分类样本的顺序聚合，形成强集成。大量实验表明，TPB在文本空间中保留了任务固有、模型无关的线索，实现了稳健的跨模型迁移。在十一个分类基准上，TPB提升了源模型的准确率，并在迁移到更大、更强的VLM时保持了样本驱动的增益，而现有方法难以维持此类改进。

## Abstract
The classification accuracy of pretrained Vision-Language Models (VLMs) relies on the quality of the text prompts. Handcrafted templates and Large Language Model (LLM)-generated descriptions not only make predictions more interpretable, but also enable reuse of the same prompts across heterogeneous VLMs. Recent works construct task-adapted text prompts with a small number of labeled images. However, existing few-shot text prompting methods do not explicitly focus on misclassified examples during prompt construction, leading to only marginal improvements even as more shots become available. To fully exploit few-shot supervision, we propose Text Prompt Boosting (TPB), an AdaBoost-inspired framework that treats each text-prompt-based classifier as a weak learner and sequentially aggregates them into a strong ensemble by explicitly targeting hard, misclassified examples. Extensive experiments show that TPB preserves task-intrinsic, model-agnostic cues in text space, enabling robust cross-model transfer. Across eleven classification benchmarks, TPB improves accuracy on the source model and preserves shot-driven gains when transferred to larger, more capable VLMs, where existing methods struggle to sustain such improvements.

### 2. 论文提出的方法论：核心思想、关键技术细节
- **核心思想**：将每个文本提示集合（每个类一个提示库）视为弱分类器，通过AdaBoost-style的顺序boost过程，在每一轮中重点关注前一轮误分类的样本，逐步组合成强集成分类器。
- **关键技术细节**：
  - **提示池构建**：使用CLIP的80个手工模板、多个LLM生成描述（DCLIP、CuPL等）及其拼接，为每类生成一个大提示池。
  - **弱学习器：Greedy Prompt Composition (GPC)**：
    - **阶段1**：从80个模板中选出使加权分类误差最小的单一模板，作为每类初始提示（单模板初始化）。
    - **阶段2**：按类循环贪心地从提示池中选择提示（允许重复选择以近似连续权重），每次添加后计算加权误差变化，若降低则保留，直至一轮无改进。
    - 重复选择机制：通过计算翻转阈值（upside/downside flips）确定最佳复制次数d，并采用**误差变化量/复制次数**作为选择标准，鼓励多样性。
  - **集成与权重更新**：采用多类AdaBoost变体 **SAMME.R**；在每轮boost前对训练集进行图像增强（随机裁剪、水平翻转，增强因子a=4），防止过拟合；随后在原始（非增强）数据上更新样本权重，增大误分类样本权重。
  - **最终预测**：将M轮（默认50，ImageNet为30）弱分类器通过加权投票（SAMME.R的置信度加权）组合成强分类器。推理时只需一次前向（文本嵌入可预计算）。

### 6. 论文的主要结论与发现
- TPB在所有shot设置下均显著优于现有文本提示基线，源模型平均精度随shot增加稳定提升（1-shot 63.8% → 16-shot 70.3%），而ProAPO等趋于饱和。
- TPB在跨模型迁移时保持了样本驱动增益，如在ViT-L上从76.76%（零样本）提升至82.07%（16-shot），而ProAPO仅提升至80.01%。
- 梯度优化的文本提示（PEZ）虽然能在源模型上提升，但因语义不连贯，迁移后性能甚至低于零样本（从71.07%降至53.02%）。
- 图像增强对于低shot场景下的迭代boost至关重要，能防止快速过拟合并持续产生困难样本。
- 提示池的多样性（合并多个LLM描述）有益于高shot性能。

### 7. 优点
- **可解释性与可迁移性**：使用自然语言文本提示，无需模型特定连续向量，可直接在不同VLM上复用。
- **shot scalability**：通过主动关注困难样本，持续利用新增标注，避免了传统提示方法的饱和。
- **高效推理**：集成后仅需一次前向，比EFT类方法（需多次前向）更轻量。
- **实验系统全面**：覆盖多数据集、多shot数、多目标模型及多维度消融，验证了方法的稳健性。

### 8. 不足与局限
- **构建成本**：贪心搜索+多轮boost在大型数据集上非平凡（尤其是候选池较大时）。
- **噪声风险**：AdaBoost式重加权可能过度强调异常或噪声样本，影响泛化。
- **提示池固定**：从固定池中选择，对于某些细粒度或模糊类别可能不够灵活；且依赖LLM生成质量。
