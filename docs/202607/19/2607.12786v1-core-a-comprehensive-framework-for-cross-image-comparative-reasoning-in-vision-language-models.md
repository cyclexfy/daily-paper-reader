## 摘要
跨图像比较推理对视觉语言模型（VLM）仍然具有挑战性，尤其是在正确预测需要细粒度属性定位和全局一致推理时。我们提出了CoRe，一个针对该问题的统一框架。CoRe包括：（i）CoRe-20K，一个大规模三元组训练集，通过多专家协作流程从结构化视觉元数据自动构建，涵盖计数、深度、距离和空间关系；（ii）TriSR，一个结构化奖励框架，在GRPO优化下联合监督属性定位、判断对齐和三元组一致性；以及（iii）CoRe-Bench，首个专门用于细粒度跨图像比较推理的基准。实验表明，CoRe在CoRe-Bench上显著优于现有VLM，同时在标准多模态基准上保持竞争力，在部分准确性上比最强基线提高了28.2个百分点。

## Abstract
Cross-image comparative reasoning remains challenging for vision-language models (VLMs), especially when correct prediction requires fine-grained attribute grounding and globally consistent reasoning. We present CoRe, a unified framework for this problem. CoRe includes: (i) CoRe-20K, a large-scale triplet-based training set automatically constructed from structured visual metadata through a multi-expert collaborative pipeline, covering counting, depth, distance, and spatial relations; (ii) TriSR, a structured reward framework that jointly supervises attribute grounding, judgment alignment, and triplet consistency under GRPO optimization; and (iii) CoRe-Bench, the first benchmark dedicated to fine-grained cross-image comparative reasoning. Experiments show that CoRe substantially outperforms existing VLMs on CoRe-Bench while remaining competitive on standard multimodal benchmarks, achieving a 28.2-point gain in partial accuracy over the strongest baseline.

### 2. 论文提出的方法论：核心思想、关键技术细节
#### 核心思想
- 利用结构化视觉元数据自动构建三元组（triplet）训练数据，并提出一种**可验证的结构化奖励框架**，监督推理过程中的中间步骤（属性定位、判断对齐、三元组一致性），而不是仅依赖最终答案正确性。

#### 关键技术细节
- **CoRe-20K数据集构建**：
  - **多专家协作管道**：包括三个专家模块：
    - 度量提取专家：从元数据（如实例计数、深度图、3D标注、边界框）中提取每张图像的度量值。
    - 质量控制专家：通过噪声边界过滤（排除差异过小或过大的三元组）和琐碎样本排除，确保标签可靠且富有信息量。
    - 问题生成专家：基于模板库生成三元组对比问题，并随机化选项顺序以消除答案位置偏差。
  - 数据规模：20,000个三元组，各5,000个来自计数、深度、距离、空间关系四个维度。每个三元组包含三个成对比较子问题，总计60,000个QA项。
- **TriSR结构化奖励框架**：
  - 强制模型输出结构化响应：每张图像的属性估计、推理轨迹中的成对判断、最终答案。
  - 三个奖励分量：
    - **属性定位奖励（R_ag）**：评估模型估计的属性值与元数据真值之间的接近程度（指数衰减函数）。
    - **判断对齐奖励（R_ja）**：联合衡量推理判断与真值的一致性，以及推理判断与最终答案的一致性（骰子得分）。
    - **三元组一致性奖励（R_tc）**：验证三个成对判断之间的逻辑相容性（如传递性、可加性），返回+1/0/-1。
  - 最终复合奖励：R = R_task + λ_ag R_ag + λ_ja R_ja + λ_tc R_tc，超参数设λ_ag=0.2, λ_ja=0.2, λ_tc=0.3。
  - 优化算法：使用GRPO（Group Relative Policy Optimization），对每组采样G个响应，计算组归一化优势，更新策略。

### 6. 论文的主要结论与发现
1. 现有VLM在跨图像细粒度比较推理上整体表现极差（平均整体准确率<7%），而CoRe-4B-CoT达到22.2%，部分准确率54.0%，比最强基线（Qwen3-VL-4B-CoT）分别提升15.6和28.2个百分点。

4. CoRe在通用VLM基准上保持竞争力，在9个基准中5个达到开源模型最优，未出现灾难性遗忘。
5. 三元组一致性奖励（R_tc）在消融中贡献最大（下降最多），验证了全局一致性的重要性。
